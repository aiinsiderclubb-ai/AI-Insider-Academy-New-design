# Agency Proposal Template

Шаблон коммерческого предложения для AI-услуг вместе с тем, что нужно, чтобы его заполнить и защитить: руководство по ценам, описание работ, запрос на изменение и калькулятор.

## Файлы

- `proposal-template.md` — предложение из 11 разделов с примерами формулировок
- `pricing-guide.md` — три способа считать цену, ориентиры по рынку, правила скидок
- `scope-of-work.md` — описание работ с критериями приёмки — приложение к договору
- `change-request.md` — бланк запроса на изменение объёма
- `pricing-calculator.csv` — калькулятор цены и окупаемости

## С чего начать

1. Импортируйте `pricing-calculator.csv` в Google Таблицы и подставьте цифры клиента из звонка.
2. Скопируйте `proposal-template.md` в Google Docs или Notion и замените всё в [скобках].
3. Раздел «Что не входит» заполняйте так же тщательно, как «Что входит».
4. После согласования перенесите объём в `scope-of-work.md` и приложите к договору.

## Лицензия

Можно использовать в своей работе и в проектах для клиентов. Нельзя перепродавать или выкладывать набор целиком.

Шаблоны не являются юридической консультацией. Договор и приложения перед подписанием покажите юристу.
