# Agent Audit Kit

Набор для аудита AI-агентов и автоматизаций в компании: модель управления, чеклист безопасности из 48 пунктов, шаблоны трёх политик, реестр, оценка рисков, калькулятор окупаемости и шаблон отчёта. Подходит и для проверки собственных агентов, и как готовая услуга для клиентов.

## Файлы

- `governance-framework.md` — уровни автономии, классы риска, роли, цикл аудита
- `security-checklist.md` — 48 пункта в 8 разделах с правилом оценки
- `policy-templates.md` — три политики: использование AI, данные и агенты, инциденты
- `audit-report-template.md` — шаблон отчёта для клиента
- `agent-register.csv` — реестр агентов
- `risk-assessment.csv` — оценка рисков: вероятность × ущерб
- `roi-calculator.csv` — калькулятор окупаемости агента

## С чего начать

1. Прочитайте `governance-framework.md` — в нём логика всего набора.
2. Заполните `agent-register.csv`: все агенты и автоматизации с AI, даже «маленькие».
3. Пройдите `security-checklist.md` по каждому агенту, начиная с тех, у кого есть действия классов C и D.
4. Риски занесите в `risk-assessment.csv`, окупаемость посчитайте в `roi-calculator.csv`.
5. Соберите выводы в `audit-report-template.md` и адаптируйте политики.

## Лицензия

Можно использовать в своей работе и в проектах для клиентов. Нельзя перепродавать или выкладывать набор целиком.

Набор не заменяет юридическую консультацию и тест на проникновение.
