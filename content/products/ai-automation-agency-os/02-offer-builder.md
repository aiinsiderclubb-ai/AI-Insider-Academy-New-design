# Этап 2. Оффер

Оффер — одно предложение, которое клиент может пересказать коллеге. Если не может — оффера нет.

## Формула

> Мы [что делаем] для [кого], чтобы [результат в цифрах] за [срок]. Стоит [цена], окупается за [срок].

Пример: «Мы автоматизируем приём заявок для стоматологических клиник: каждая заявка получает ответ за минуту и попадает в расписание. Запуск за две недели, 2 800 €, окупается за два месяца».

## Конструктор

Заполните по строке:

| Элемент | Вопрос | Ваш ответ |
|---|---|---|
| Кто | Ниша и размер компании | |
| Процесс | Что именно автоматизируем | |
| До | Как сейчас, в цифрах | |
| После | Как будет, в цифрах | |
| Срок | Когда заработает | |
| Цена | Сколько стоит | |
| Риск | Что гарантируем | |
| Доказательство | Кейс, демо или расчёт | |

## Три пакета

| | Старт | Основной | Полный |
|---|---|---|---|
| Процессов | 1 | 2–3 | 4–6 |
| Каналов | 1 | до 3 | все |
| Обучение | видео | видео + сессия | видео + сессия + инструкции по ролям |
| Поддержка | 14 дней | 30 дней | 90 дней |
| Отчёт руководителю | — | раз в месяц | раз в неделю |
| Цена | [1 500 €] | [3 500 €] | [8 000 €] |

Основной пакет — тот, который вы хотите продать. Старт нужен, чтобы было с чем сравнить, полный — чтобы основной выглядел разумным.

## Гарантия, которую можно дать

- Срок: «если не запустим к дате — возвращаем [10%] за каждую неделю задержки по нашей вине».
- Работоспособность: «исправляем бесплатно всё, что не соответствует описанию работ, в течение срока поддержки».
- Проверка: «через 30 дней сверяем экономию с расчётом».

Не гарантируйте рост продаж и другие результаты, которые зависят не от вас.

## Проверка оффера

- Понятно ли без слов «AI», «агент», «нейросеть»?
- Есть ли цифра?
- Есть ли срок?
- Сможет ли клиент повторить его директору?
