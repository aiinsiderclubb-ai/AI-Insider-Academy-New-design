# AI Automation Agency OS

Операционная система для продажи и внедрения AI-автоматизаций: семь этапов работы с клиентом от аудита до ежемесячной поддержки. Для каждого этапа — готовый документ, для расчётов — три таблицы с формулами.

## Файлы

- `00-system.md` — как устроена система и экономика одного клиента
- `01-business-audit.md` — AI-аудит бизнеса: интервью, карта процессов, отчёт
- `02-offer-builder.md` — формула оффера, три пакета, гарантии
- `03-proposal-one-page.md` — предложение на одну страницу
- `04-service-agreement.md` — шаблон договора и приложение о поддержке
- `05-onboarding-checklist.md` — старт: чеклисты и два письма клиенту
- `06-delivery-plan.md` — план внедрения на 15 дней, статус, критерии запуска
- `07-retainer-90-days.md` — поддержка: план на 90 дней и ежемесячный отчёт
- `audit-process-map.csv` — карта процессов с расчётом приоритета
- `pricing-roi-calculator.csv` — калькулятор цены, окупаемости и дохода с клиента
- `pipeline-tracker.csv` — воронка сделок

## С чего начать

1. Прочитайте `00-system.md` — 5 минут, чтобы увидеть весь путь.
2. Импортируйте три CSV в Google Таблицы: формулы заработают сразу.
3. Проведите первый аудит по `01-business-audit.md`, даже бесплатно: он даст цифры для оффера.
4. Соберите оффер и предложение, отправьте, ведите сделку в `pipeline-tracker.csv`.
5. После подписи идите по этапам 5–7 в том же порядке.
