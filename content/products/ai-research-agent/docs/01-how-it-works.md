# Как это работает

```
задание (Telegram / вебхук)
  ─► Config ─► Guard In ── доступ, формат, запрещённые темы, лимиты, бюджет
        │
        ├─► отказ / лимит / помощь ─► ответ без модели (+ сигнал команде при отказе)
        │
        └─► «принял задание» ─► AI Agent ◄── web_search · fetch_page · handoff_to_human
                                   │
                                   ▼
                               Guard Out ── ссылки → список источников, проверка доменов и бюджета
                                   │
                                   ▼
               файл в Telegram / ответ на запрос / callback ─► лист Reports ─► сигнал команде
```

1. **Guard In** проверяет доступ (список ID в Telegram, токен у вебхука), длину задания, глубину и запрещённые темы, ведёт дневные лимиты. Для задания выдаётся номер `R-…` и бюджет по глубине: например, быстрое — до 3 поисков и 4 страниц.
2. Заказчик сразу получает «принял задание»: в Telegram — сообщение, по вебхуку — ответ `202` с номером. С `"wait": true` вебхук ждёт готовый отчёт.
3. **AI Agent** получает задание с датой и бюджетом и работает инструментами:
   - `web_search` — поиск Tavily. Результаты без запрещённых доменов, предпочтительные — первыми, у каждого код для ссылки `[s1a2b]`;
   - `fetch_page` — текст страницы без меню, скриптов и подвала, до `max_page_chars` символов. Адреса локальной сети и служебные адреса облака не открываются;
   - `handoff_to_human` — сигнал команде, если нужен человек.
4. Агент пишет отчёт в Markdown и ставит коды источников после утверждений.
5. **Guard Out** меняет коды на номера, удаляет коды источников, которых агент не видел, выбрасывает список источников модели и пишет свой — с адресами и пометкой, какой источник прочитан, а какой видели только в выдаче поиска. Считает разные домены: меньше `min_sources` — отчёт «предварительный».
6. Отчёт уходит заказчику, строка — в лист `Reports`. Если отчёт предварительный, не готов, был перерасход бюджета, сбой поиска или выдуманная ссылка — команде приходит сигнал.

## Ссылки на источники

Код источника — короткий хэш адреса, одинаковый в любом поиске. Поэтому модель не может перепутать номера между поисками, а система может проверить каждую ссылку: код из отчёта должен совпасть с кодом из результатов поиска или прочитанной страницы этого задания.

## Бюджет

- **Жёстко:** потолок шагов агента — поисков + страниц + 4. Больше инструмент вызвать нельзя.
- **Жёстко:** до `results_per_search` результатов на поиск и до `max_page_chars` символов страницы.
- **Мягко:** число поисков и страниц по отдельности указано модели в задании. Если она тратит больше, Guard Out ставит пометку `over_budget` и сообщает команде.
