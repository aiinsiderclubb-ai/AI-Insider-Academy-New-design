# Эксплуатация

## Лист Reports

Каждое задание — строка: номер, время начала и конца, заказчик, глубина, статус, задание, число источников, поисков, страниц, пометки и сам отчёт (до 45 000 символов — ограничение ячейки Google Таблиц; полный отчёт — в файле или callback).

Раз в неделю посмотрите:
- `preliminary` — каким темам не хватает источников: добавьте `preferred_domains` или поднимите глубину;
- `bad_citation`, `over_budget` — модель путается: инструкция или модель посильнее;
- `refused` — нет ли ложных отказов на рабочие задачи.

## Сигналы в чат команды

| Сигнал | Что делать |
|---|---|
| 🚫 Исследование отклонено | проверить, не ложный ли отказ; если да — ответить заказчику самим |
| 🔎 … мало источников | открыть отчёт, при необходимости дособрать вручную |
| 🔎 … превышен бюджет | норма для сложных тем; если часто — поднять бюджет глубины |
| 🔎 … сбой поиска | ключ Tavily, кредиты, доступность api.tavily.com |
| 🟡 Исследование: нужен человек | агент просит платную базу, звонок или решение специалиста |

## Неполадки

| Симптом | Причина |
|---|---|
| вебхук отвечает 401 | заглушка или неверный `agent_token` |
| бот молчит в Telegram | воркфлоу не опубликован; бот подключён к другому воркфлоу; n8n не по https |
| «нет доступа» своим | ID не в `allowed_telegram_ids` |
| все отчёты «предварительные» | поиск возвращает мало доменов: проверьте `blocked_domains`; снизьте `min_sources` для узких тем |
| `service_error` в каждом задании | ключ Tavily неверный или кончились кредиты — ответ Search API виден в выполнении узла |
| `wait: true` обрывается | прокси перед n8n закрывает долгие запросы — используйте `callback_url` |
| отчёт пустой (`failed`) | модель вернула ошибку: ключ, лимиты провайдера, слишком длинный контекст при deep — уменьшите `max_page_chars` |
