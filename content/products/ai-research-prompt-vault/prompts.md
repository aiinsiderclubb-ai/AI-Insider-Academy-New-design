# AI Research Prompt Vault

40 промптов. Текст в [квадратных скобках] замените своим.

## Рынок и спрос

Есть ли здесь деньги, сколько их и кто их уже забирает.

### 1. Размер рынка снизу вверх

```
Продукт: [что], регион: [где]. Посчитай рынок снизу вверх: сколько потенциальных клиентов, какая доля реально может купить, средний чек, частота. Покажи формулу и каждое допущение отдельной строкой. Где нужна внешняя цифра — напиши, какую искать и где.
```

### 2. Карта рынка

```
Ниша: [что]. Вот игроки, которых я знаю: [список с описаниями]. Разложи их по двум осям, которые лучше всего объясняют различия. Где скопление, а где пусто? Почему пусто — там нет спроса или туда никто не дошёл?
```

### 3. Тренды из фактов

```
Вот новости, отчёты и наблюдения по теме [тема]: [материалы]. Выдели 5 трендов. Для каждого: на каких фактах из материалов он держится, что это меняет для [мой бизнес], через какой срок это станет заметно. Тренд без опоры в материалах не включай.
```

### 4. Проверка спроса до продукта

```
Идея: [что]. Предложи 6 способов проверить спрос за две недели и почти без денег: что делаем, сколько стоит, какой результат считаем сигналом «да», какой — «нет».
```

### 5. Цепочка создания ценности

```
Отрасль: [что]. Опиши цепочку от сырья или идеи до конечного клиента: кто участвует, кто на чём зарабатывает, где самая высокая маржа и где больше всего ручной работы. Где в этой цепочке место для [мой продукт]?
```

### 6. Барьеры входа

```
Хочу выйти на рынок [что] в [регион]. Перечисли барьеры: регуляторные, технологические, по доступу к клиентам, по капиталу. Для каждого — как его обходят новые игроки и сколько это занимает.
```

### 7. Сегменты по размеру и доступности

```
Рынок: [что]. Раздели на сегменты и оцени каждый по трём параметрам: размер, готовность платить, насколько легко до них добраться. С какого сегмента начинать и почему. Какой выглядит привлекательным, но является ловушкой.
```

### 8. Сезонность и циклы

```
Бизнес: [что]. От каких циклов зависит спрос: сезон, бюджетные периоды клиентов, события отрасли. Составь календарь на год: когда покупают, когда выбирают, когда бесполезно предлагать.
```

### 9. Вопросы для экспертного интервью

```
Изучаю рынок [что]. Завтра разговор с человеком, который в нём 10 лет. Составь 12 вопросов: как устроены деньги, кто принимает решения, что изменилось за 3 года, на чём обжигаются новички. Без вопросов, на которые отвечает поиск.
```

### 10. Сводка для решения

```
Вот всё, что я собрал о рынке [что]: [материалы]. Сделай сводку на одну страницу: размер и динамика, кто платит и за что, главные игроки, три возможности, три риска. Факты отдели от моих предположений.
```

## Конкуренты

Что они обещают, чем доказывают и что у них плохо.

### 11. Профиль конкурента

```
Конкурент: [название]. Что я о нём знаю: [сайт, цены, отзывы, вакансии]. Собери профиль: кому продаёт, что обещает, модель цены, сильные стороны, слабые места, вероятный следующий шаг. Только из моих данных; чего не хватает — списком.
```

### 12. Сравнительная таблица

```
Конкуренты: [список с описаниями]. Мой продукт: [что]. Сделай таблицу сравнения по 8 параметрам, важным клиенту при выборе. Под таблицей — где я объективно слабее и что с этим делать.
```

### 13. Разбор их сайта

```
Вот текст главной страницы конкурента: [текст]. Какое главное обещание, для кого оно, чем подтверждается, какое действие просят. Что у них сделано лучше, чем у меня, и что можно сделать сильнее.
```

### 14. Анализ отзывов о конкуренте

```
Отзывы клиентов о [конкурент]: [тексты]. За что хвалят, на что жалуются, чего не хватает. Сгруппируй жалобы и посчитай частоту. Какие из них я могу закрыть своим продуктом и как об этом сказать.
```

### 15. Ценовая стратегия конкурентов

```
Цены конкурентов: [таблица]. Какие модели используют: за пользователя, за объём, пакеты, разовая оплата. Где ценовые пороги, на чём зарабатывают на самом деле. Где есть место для моей цены и почему.
```

### 16. Что они запустят дальше

```
Конкурент [название] за последний год: [запуски, новости, вакансии]. По этим следам предположи 3 направления, куда он движется. Для каждого — признак, по которому я узнаю об этом раньше анонса.
```

### 17. Заменители, а не конкуренты

```
Мой продукт решает задачу [что]. Чем люди решают её сейчас без покупки чего-либо: таблицы, сотрудник, ничего не делают. Для каждого заменителя: почему он «достаточно хорош» и что должно случиться, чтобы человек от него отказался.
```

### 18. Позиция, которую никто не занял

```
Вот обещания 6 конкурентов: [тексты]. Какие слова и выгоды повторяются у всех? Какую потребность клиента не называет никто? Предложи 3 свободные позиции и риск каждой.
```

### 19. Разбор их воронки

```
Я прошёл путь клиента у [конкурент]: [шаги: реклама, сайт, письма, звонок, оффер]. Опиши их воронку: что на каждом шаге, где сильное место, где бы я ушёл. Что из этого стоит повторить, а что сделать иначе.
```

### 20. Сводка по конкурентам

```
Профили конкурентов: [материалы]. Сделай сводку на страницу для команды: кто главный соперник в каких сделках, чем нас обходят, чем мы сильнее, три фразы для менеджеров на вопрос «а чем вы лучше».
```

## Клиенты и продукт

Что на самом деле нужно людям — из их слов, а не из наших гипотез.

### 21. Сценарий глубинного интервью

```
Хочу понять, как [кто] решает задачу [что]. Составь сценарий на 40 минут: вопросы про последний раз, когда это случилось; что делал, что мешало, чем закончилось. Без вопросов «хотели бы вы…» и «сколько бы заплатили».
```

### 22. Разбор интервью

```
Расшифровка интервью: [текст]. Вытащи: задачи, которые человек пытается решить; что уже пробовал; что его раздражает; цитаты дословно. Отдели то, что он делал на самом деле, от того, что говорит, что сделал бы.
```

### 23. Синтез нескольких интервью

```
Вот выжимки из [число] интервью: [тексты]. Найди повторяющиеся темы. Для каждой: сколько человек об этом сказали, типичная цитата, насколько это больно. Что прозвучало один раз, но заслуживает проверки.
```

### 24. Работа, для которой нанимают продукт

```
Продукт: [что]. Клиенты говорят: [цитаты]. Сформулируй 3 «работы», на которые его нанимают, по схеме: когда [ситуация], я хочу [мотив], чтобы [результат]. Какая из них главная и что продукт делает для неё плохо.
```

### 25. Опрос без наводящих вопросов

```
Хочу узнать [что] у [аудитория]. Составь опрос на 8 вопросов. Проверь каждый: нет ли в нём подсказки ответа, двух вопросов в одном, непонятных слов. Покажи исправленную версию и что изменил.
```

### 26. Анализ открытых ответов

```
Ответы на открытый вопрос [вопрос]: [тексты]. Закодируй ответы по темам, посчитай частоту, дай 2 цитаты на тему. Что неожиданного? Какие ответы не укладываются ни в одну тему?
```

### 27. Причины оттока

```
Клиенты, которые ушли, говорили: [тексты]. Раздели причины на: продукт не решил задачу, решил, но дорого, задача пропала, ушли к конкуренту. Какие из причин мы можем устранить и что именно сделать.
```

### 28. Приоритеты доработок

```
Запросы клиентов: [список]. Цель продукта: [что]. Оцени каждый запрос: сколько клиентов это затрагивает, насколько сильно, как связано с целью. Раздели на: делать, изучить глубже, отказать — с объяснением для клиента.
```

### 29. Проверка гипотезы

```
Гипотеза: [клиенты X делают Y, потому что Z]. Как её проверить? Какие данные её подтвердят, какие опровергнут. Составь план из 3 шагов и заранее запиши, какой результат заставит меня от неё отказаться.
```

### 30. Портрет на основе данных

```
Данные о клиентах: [таблица: кто, что купил, как пользуется]. Собери 3 портрета на основе поведения. Для каждого: что покупает, как часто, что его удерживает. Без возраста и хобби, если их нет в данных.
```

## Идеи, источники и выводы

Как искать, проверять и не обманывать себя.

### 31. План исследования

```
Вопрос: [что хочу узнать и зачем]. Составь план: какие подвопросы, какие источники для каждого, что можно узнать за день, а что требует интервью или данных. В каком порядке идти, чтобы рано понять, если вопрос поставлен неверно.
```

### 32. Проверка источника

```
Источник: [статья / отчёт / пост]. Утверждение: [цитата]. Оцени: кто автор и зачем это написал, на чём основана цифра, есть ли первоисточник, что могло быть искажено. Вывод: можно ли на это ссылаться.
```

### 33. Сводка нескольких материалов

```
Вот [число] материалов по теме [тема]: [тексты]. В чём они согласны, в чём расходятся, какие вопросы остались без ответа. У каждого утверждения в сводке — из какого материала оно взято.
```

### 34. Генерация идей с ограничениями

```
Задача: [что]. Ограничения: [бюджет, срок, ресурсы]. Дай 15 идей в трёх группах: очевидные, неожиданные, почти безумные. Для трёх лучших — первый шаг, который можно сделать завтра.
```

### 35. Аргументы против собственной идеи

```
Я считаю, что [утверждение]. Приведи 5 сильнейших аргументов против — таких, какие привёл бы умный оппонент. Для каждого: что должно быть правдой, чтобы он был прав, и как это проверить.
```

### 36. Аналогии из других отраслей

```
Проблема: [что]. В каких 5 других отраслях решали похожую задачу? Для каждой: как там это сделано, что можно перенести ко мне и что не перенесётся.
```

### 37. Сценарий «что если»

```
Сейчас: [ситуация]. Что если [событие]? Опиши последствия первого, второго и третьего порядка для [мой бизнес]. Какие ранние признаки покажут, что событие приближается. Что стоит подготовить заранее.
```

### 38. Отчёт об исследовании

```
Материалы исследования: [заметки, цифры, цитаты]. Собери отчёт: вопрос, метод, что узнали — по три вывода с подтверждением, чего не узнали, рекомендации. Каждый вывод — с уровнем уверенности.
```

### 39. Объяснение сложного отчёта

```
Вот фрагмент отчёта или исследования: [текст]. Объясни простыми словами: что измеряли, как, что получили, какие ограничения. Какой вывод авторы делают и следует ли он из данных.
```

### 40. Вопросы, которые я не задал

```
Я исследую [тема] и уже выяснил: [что]. Каких вопросов я не задал? Назови 7 — про то, что принимаю как данность, про тех, кого не спросил, про то, что может изменить вывод.
```
