# AI Support Automation

Набор воркфлоу n8n для службы поддержки: обращения с сайта, из Telegram и почты собираются в одну Google Таблицу, модель отвечает на типовые вопросы строго по вашему FAQ, а всё остальное приходит команде в Telegram — с готовым черновиком и кнопкой «Отправить».

## Что делает

- **Три канала — одна очередь.** Форма на сайте, Telegram-бот, почтовый ящик. Каждое обращение — строка в таблице; продолжение переписки дописывается в ту же строку.
- **Ответы только по FAQ.** База знаний — лист `FAQ` в той же таблице: вопрос и ответ. Модели прямо запрещено выдумывать факты, обещать возвраты, скидки и сроки.
- **Два режима.** Черновики: каждый ответ проверяет человек. Автоответ: бот отвечает сам, но только когда выполнены все условия — категория разрешена, уверенность высокая, клиент спокоен, вопрос не срочный, нет запрещённых тем.
- **Команда работает из Telegram.** Кнопка «Отправить» отправляет черновик клиенту туда, откуда он писал. Ответ на сообщение бота в чате команды уходит клиенту как ответ поддержки.
- **Не отвечает роботам.** Автоответы, рассылки, недоставленные письма и собственные письма игнорируются — без бесконечных переписок с почтовыми роботами.
- **Напоминает** об обращениях без ответа по срокам для каждой срочности.
- **Каждое утро — сводка**: сколько обращений, доля ответов бота, медиана первого ответа, темы, недовольные клиенты и список вопросов, которых нет в FAQ.
- **Не теряет обращение**, если таблица недоступна: оно целиком уходит команде.

## Чем отличается от шаблона из интернета

Воркфлоу запускались в n8n 2.44 на подменных Google Таблицах, модели, Telegram и почте: вопрос с сайта с автоответом, письмо с ответом «Re:», срочное сообщение в Telegram с черновиком и кнопками, нажатие «Отправить», ответ сотрудника через чат команды, напоминания и сводка. Логика узлов Code проверена 12 сценариями. Подробности — `tests/scenarios.md`.

## Что нужно

- n8n с адресом в интернете по https (Telegram отправляет обновления только на https).
- Google Таблица с листами `Tickets` и `FAQ`.
- Telegram-бот и чат команды.
- Ключ модели с OpenAI-совместимым API.
- По желанию: почтовый ящик поддержки (IMAP и SMTP).
