# Как это работает

```
Сайт ──────┐
Telegram ──┼──► Support Inbox ──► Normalize
Почта ─────┘                        │
                                    ├─ сайт без токена → 403
                                    ├─ /start в Telegram → приветствие
                                    ├─ робот, рассылка, своё письмо, чат команды → пропустить
                                    ├─ кнопка или ответ в чате команды → действие с обращением
                                    └─ сообщение клиента
                                          │
                     таблица Tickets + лист FAQ (одним запросом)
                                          │
                     то же обращение за 7 дней? → продолжение, иначе новое
                                          │
                     модель: категория, срочность, настроение, ответ по FAQ, уверенность
                                          │
                     все условия автоответа выполнены?
                        да  → ответ клиенту в его канал, команде — уведомление «Отвечено ботом»
                        нет → команде: черновик и кнопки «Отправить» / «Ответим сами»
                              или «ответа в FAQ нет — ответьте сами»
                                          │
                     запись в таблицу; сайту — ответ или «спасибо, ответим»
```

## Статусы обращения

| Статус | Что значит |
|---|---|
| `new` | Ответа нет, черновика нет — нужен человек |
| `draft_ready` | Есть черновик, ждёт решения команды |
| `answered` | Ответ отправлен (ботом или командой) |
| `closed` | Закрыто вручную. Новое сообщение клиента откроет новое обращение |

Новое сообщение клиента в отвеченном обращении возвращает его в работу.

## Где отвечает бот и команда

Ответ уходит туда, откуда клиент написал: в Telegram — в его чат с ботом, на почту — письмом «Re: тема». Клиенту с сайта бот отвечает прямо на странице; ответ команды уходит ему на почту, поэтому в форме сайта почта обязательна.

## Узлы Code

| Узел | Что делает |
|---|---|
| Config | Настройки |
| Normalize | Разбирает обращение из любого канала, отсекает роботов и чужие чаты, чистит цитаты из писем |
| Thread | Находит обращение того же клиента, читает FAQ, собирает запрос к модели |
| Decide | Проверяет ответ модели и условия автоответа, готовит запись и сообщения |
| Act on Ticket | Кнопки и ответы команды: найти обращение, отправить, отметить в таблице |
| Ticket Not Saved | Если таблица недоступна — обращение целиком в чат команды |
