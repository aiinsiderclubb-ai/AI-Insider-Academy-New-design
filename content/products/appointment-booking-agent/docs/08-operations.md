# Эксплуатация

## Журнал

Лист `Log`: время, сессия, канал, сообщение, ответ, вызванные инструменты, передача, пометки, детали (код записи). Раз в неделю смотрите:
- `book_appointment` несколько раз подряд в одном диалоге — модель не дождалась «да» или клиент не понял, что его ждут; поправьте формулировку в инструкции;
- много `check_availability` и мало записей в колонке деталей — клиентам не подходит время: возможно, стоит расширить часы;
- `handoff = да` — какие запросы чаще уходят людям;
- `service_error` — сбои календаря или Telegram.

## Память диалога

Simple Memory хранит переписку в памяти n8n: после перезапуска n8n диалоги начинаются заново (записи в календаре, конечно, остаются). В режиме очереди с несколькими воркерами замените Memory на Postgres Chat Memory или Redis Chat Memory с тем же Session Key.

## Приватность

В календарь и журнал попадают имя, контакт и комментарий клиента. В модель — сообщения клиента, услуги и свободное время, данные найденной по коду записи. Определите срок хранения журнала и укажите обработку данных в политике конфиденциальности.

## Изменения

- **Услуги, часы, буферы** — в Config, действуют сразу.
- **Инструкция** — правьте `agent/system-prompt.md`, затем перенесите в узел AI Agent → Options → System Message, не трогая ссылки на Config в двойных фигурных скобках. После правки — evals.
- **Тексты напоминаний** — узел Pick Due.

## Неполадки

| Симптом | Причина |
|---|---|
| вебхук отвечает 401 на всё | заглушка в `agent_token` или неверный токен в запросе |
| 404 на Production URL | воркфлоу не опубликован |
| агент говорит «календарь недоступен» | у Google-ключа нет права менять `calendar_id`, или неверный ID; в журнале `service_error` с текстом ошибки Google |
| свободного времени нет никогда | `hours` заданы не так, `lead_time_min` больше рабочего дня, или в календаре событие на весь день «занят» |
| время предлагается со сдвигом на час или два | неверный `timezone` в Config |
| напоминания не приходят | воркфлоу не опубликован; клиент с сайта без email или `email_reminders: false`; запись создана не агентом |
| клиент говорит «да», а записи нет | его «да» содержит слово из `deny_words` («да, но…») — модель переспросит |
