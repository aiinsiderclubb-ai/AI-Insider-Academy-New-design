# ChatGPT Prompt Vault

80 промптов. Текст в [квадратных скобках] замените своим.

## Оффер и позиционирование

Сначала понять, что вы продаёте и кому. Эти промпты идут первыми, остальные на них опираются.

### 1. Оффер в одном предложении

```
Ты маркетолог-практик. Продукт: [что это]. Аудитория: [кто]. Главная боль аудитории: [боль]. Напиши 5 вариантов оффера в одном предложении по схеме «кому — какой результат — за счёт чего». Без слов «инновационный», «уникальный», «под ключ». Формат: нумерованный список, под каждым вариантом одна строка — на какую боль он давит.
```

### 2. Портрет клиента из фактов

```
Вот что я знаю о своих клиентах: [заметки, цитаты, данные]. Собери портрет одного типичного клиента: ситуация, что он уже пробовал, чего боится, что считает результатом, какими словами описывает проблему. Используй только то, что есть в заметках. Чего не хватает — выпиши отдельным списком вопросов.
```

### 3. Чем я отличаюсь

```
Мой продукт: [описание]. Конкуренты: [2–3 названия и что они обещают]. Найди 5 отличий, которые важны клиенту, а не мне. Для каждого: в чём отличие, почему клиенту не всё равно, как это доказать одним фактом. Отличия без доказательства помечай «пока не подтверждено».
```

### 4. Разбор возражений

```
Продукт: [что]. Цена: [сколько]. Перечисли 8 возражений, которые возникнут у [аудитория], от самого частого к редкому. Для каждого: что человек думает на самом деле, какой факт или пример снимает сомнение, чего говорить нельзя. Формат: таблица.
```

### 5. Гарантия без риска для бизнеса

```
Продукт: [что], результат зависит от действий клиента: [да/нет]. Предложи 4 варианта гарантии, которые снимают страх покупки, но не разоряют меня. Для каждого: формулировка для сайта, условие, при котором гарантия действует, риск для меня.
```

### 6. Название продукта

```
Продукт: [описание], аудитория: [кто], тон бренда: [спокойный / дерзкий / экспертный]. Дай 15 названий в трёх группах: описательные, образные, составные. У каждого — одна строка, почему оно запомнится. Отметь три, которые легко произнести вслух и набрать в поиске.
```

### 7. Линейка тарифов

```
Продукт: [что]. Сейчас один тариф за [цена]. Спроектируй три: базовый, основной, расширенный. Для каждого: кому, что входит, что не входит, цена и логика цены. Основной должен выглядеть самым выгодным без искусственного ухудшения базового.
```

### 8. Проверка оффера на прочность

```
Вот мой оффер: [текст]. Прочитай его глазами скептичного клиента из [аудитория]. Что непонятно с первого прочтения? Где обещание без доказательства? Что я говорю о себе вместо клиента? Перепиши оффер, исправив только эти места, и покажи, что изменил.
```

### 9. Одна страница о продукте

```
Собери одностраничное описание продукта [что] для отправки клиенту после созвона. Блоки: проблема в двух предложениях, решение, что клиент получает по шагам, срок, цена, следующий шаг. До 250 слов, без прилагательных-оценок.
```

### 10. Кому продукт не подходит

```
Продукт: [что]. Напиши честный блок «Кому это не подойдёт» из 5 пунктов. Цель — отсеять клиентов, с которыми будет плохой результат, и повысить доверие остальных. Тон спокойный, без снобизма.
```

## Тексты для сайта и лендинга

Тексты по блокам. Каждый промпт просит один блок — так проще проверить и переписать.

### 11. Первый экран

```
Продукт: [что], аудитория: [кто], главный результат: [что получит]. Напиши первый экран лендинга: заголовок до 9 слов, подзаголовок до 20 слов, текст кнопки, одна строка под кнопкой, снимающая главный страх. Дай 3 варианта с разным углом: результат, скорость, простота.
```

### 12. Блок «Как это работает»

```
Опиши работу продукта [что] в 3–4 шага для человека, который видит его впервые. У каждого шага: глагол в заголовке, одно предложение что происходит, одно — что клиент получает на выходе. Без терминов, которые нужно гуглить.
```

### 13. Блок выгод

```
Вот характеристики продукта: [список]. Преврати каждую в выгоду по схеме «характеристика — что это значит на практике — что клиент перестаёт делать вручную». Формат: таблица из трёх колонок.
```

### 14. FAQ для лендинга

```
Продукт: [что], цена [сколько]. Напиши 8 вопросов и ответов для блока FAQ. Вопросы — реальные сомнения перед покупкой, а не «Что такое ваш продукт?». Ответы по 2–3 предложения, с конкретикой: сроки, условия, что будет, если не подойдёт.
```

### 15. Страница «О нас» без воды

```
Факты о компании: [список]. Напиши текст «О нас» до 150 слов: зачем мы существуем, для кого работаем, чем можем это подтвердить. Запрещено: «команда профессионалов», «динамично развивающаяся», «индивидуальный подход».
```

### 16. Кейс по фактам

```
Данные проекта: клиент [кто], задача [что], что сделали [шаги], результат [цифры]. Собери кейс: ситуация до, что мешало, решение по шагам, результат в цифрах, цитата клиента (оставь место, не придумывай). До 300 слов. Ни одной цифры, которой нет в данных.
```

### 17. Текст для кнопок и форм

```
Страница продаёт [что]. Напиши тексты: 5 вариантов кнопки основного действия, заголовок формы, подписи полей, текст под формой о данных, сообщение после отправки. Кнопка — глагол плюс результат, не «Отправить».
```

### 18. Страница цен

```
Тарифы: [названия, цены, состав]. Напиши страницу цен: заголовок, одну строку под ним, описание каждого тарифа в 4 пунктах, блок «что входит во все тарифы», ответ на вопрос «почему так дорого/дёшево».
```

### 19. Аудит лендинга

```
Вот текст моего лендинга: [текст]. Проверь по пунктам: понятно ли за 5 секунд, что продаётся; есть ли доказательства у каждого обещания; что мешает нажать кнопку. Дай список из 7 правок по убыванию влияния на заявки. Для каждой — как именно переписать.
```

### 20. Мета-теги страницы

```
Страница: [о чём], главный запрос: [ключ]. Напиши title до 60 знаков и description до 155 знаков в трёх вариантах. Ключ ближе к началу, в description — глагол и выгода. Без восклицательных знаков.
```

## Соцсети и контент

От идеи до готового поста. Работает лучше, если сначала дать модели пример вашего текста.

### 21. Контент-план на месяц

```
Ниша: [что], площадка: [где], цель: [заявки / охват / доверие]. Составь план на 4 недели, 3 поста в неделю. Для каждого: тема, формат, зачем он клиенту, какое действие просим в конце. Чередуй: польза, кейс, взгляд, продажа — не больше одной продажи в неделю.
```

### 22. Пост из заметок

```
Вот мои сырые заметки: [текст]. Сделай из них пост для [площадка]: первая строка, после которой хочется читать дальше, 3–4 коротких абзаца, вывод, вопрос к читателю. Сохрани мой тон и не добавляй фактов, которых нет в заметках.
```

### 23. 10 первых строк

```
Тема поста: [тема], аудитория: [кто]. Напиши 10 вариантов первой строки: по два на каждый приём — цифра, противоречие, ошибка, история, вопрос. Без кликбейта: первая строка должна быть правдой про содержание поста.
```

### 24. Один материал в пять форматов

```
Вот исходный материал: [статья / расшифровка]. Сделай из него: пост для Telegram, карусель на 6 слайдов (текст каждого слайда), короткое видео на 40 секунд (текст по секундам), письмо для рассылки, три коротких поста-цитаты. Каждый формат — со своим началом, не копируй одно вступление.
```

### 25. Сценарий короткого видео

```
Тема: [тема], длина: [секунд]. Напиши сценарий: крючок на первые 2 секунды, проблема, три шага решения, итог, призыв. У каждой реплики — что в кадре. Речь разговорная, предложения до 10 слов.
```

### 26. Ответы на комментарии

```
Под постом про [тема] пишут такие комментарии: [список]. Напиши ответ на каждый: по делу, без шаблона «Спасибо за комментарий!», до двух предложений. На негатив — спокойно, с фактом. Спам и оскорбления пометь «не отвечать».
```

### 27. Серия постов-разборов

```
Я эксперт в [тема]. Придумай рубрику из 8 постов-разборов типичных ошибок. Для каждого: ошибка одной фразой, почему её делают, как правильно, пример до и после. Заголовок рубрики — такой, чтобы её узнавали.
```

### 28. Био для профиля

```
Я: [кто, чем занимаюсь], помогаю [кому] с [что]. Напиши 5 вариантов описания профиля для [площадка] до [число] знаков. В каждом: кому полезен, чем, что сделать дальше. Один вариант — совсем без должностей и регалий.
```

### 29. Пост-продажа без нажима

```
Продукт: [что], для кого: [кто], срок предложения: [дата или нет]. Напиши продающий пост: с какой ситуации начать, что изменится, что входит, цена, как купить. Без искусственной срочности и слов «только сегодня», если это неправда.
```

### 30. Разбор, почему пост не зашёл

```
Вот пост: [текст]. Охват [число], реакции [число], обычно у меня [числа]. Предположи 5 причин, почему он сработал хуже. Для каждой: как проверить, как переписать. Не гадай про алгоритмы — смотри на текст и тему.
```

## Письма и рассылки

Письмо — это один смысл и одно действие. Промпты построены вокруг этого.

### 31. Приветственная серия

```
Продукт: [что], подписчик пришёл через [источник]. Напиши серию из 4 писем: знакомство и что будет дальше; одна быстрая польза; история или кейс; предложение. У каждого: тема до 45 знаков, первая строка, текст до 150 слов, одна ссылка.
```

### 32. Тема письма

```
Письмо о: [содержание]. Дай 12 вариантов темы до 45 знаков: 4 прямых, 4 с вопросом, 4 с цифрой или фактом. Отметь те, что не обещают больше, чем есть в письме.
```

### 33. Письмо после покупки

```
Клиент купил [что]. Напиши письмо: спасибо в одном предложении, что делать прямо сейчас по шагам, что будет дальше и когда, куда писать при проблеме. Тон тёплый, без восторгов. До 130 слов.
```

### 34. Возврат ушедших

```
Клиент пользовался [что] и перестал [срок] назад. Напиши 3 письма с интервалом в неделю: что нового, с чем можем помочь, прямой вопрос «что пошло не так». Без «мы скучаем» и скидок в первом письме.
```

### 35. Письмо с отказом

```
Нужно отказать [кому] в [что] по причине [причина]. Напиши письмо: отказ в первом абзаце, причина честно и коротко, что можем предложить вместо. Без «к сожалению, вынуждены сообщить». До 100 слов.
```

### 36. Дайджест из ссылок

```
Вот материалы за неделю: [список ссылок с описаниями]. Собери дайджест: вступление в два предложения, по каждому материалу — зачем его читать и кому. Расположи от самого полезного. Одно общее действие в конце.
```

### 37. Холодное письмо

```
Я предлагаю [что] компаниям типа [кто]. Про получателя знаю: [факты]. Напиши письмо до 90 слов: одна строка, почему пишу именно ему; проблема, которую вижу; что предлагаю; простой вопрос в конце. Без «надеюсь, это письмо найдёт вас».
```

### 38. Напоминание об оплате

```
Клиент [кто] не оплатил счёт [сумма], просрочка [дней]. Напиши три письма по нарастающей: дружеское напоминание, деловое с датой, финальное с последствиями по договору. Каждое до 70 слов, без угроз и извинений.
```

### 39. Опрос клиентов

```
Хочу узнать у клиентов [что именно]. Составь письмо-приглашение и 6 вопросов: 2 закрытых, 3 открытых, 1 про готовность рекомендовать. Вопросы без подсказки ответа. Письмо объясняет, зачем это клиенту и сколько займёт времени.
```

### 40. Разбор письма перед отправкой

```
Вот письмо: [текст]. Проверь: одна ли у него цель, понятно ли действие, нет ли фраз, которые можно вычеркнуть без потери смысла. Верни сокращённую версию и список того, что убрал.
```

## Продажи и переговоры

Подготовка к разговору и разбор после него. Скрипты — основа, а не текст для зачитывания.

### 41. Подготовка к созвону

```
Через час созвон с [кто, компания]. Что я знаю: [факты]. Подготовь: 3 гипотезы, зачем они пришли; 7 вопросов от общего к конкретному; 2 вопроса про бюджет и сроки без неловкости; чего я не должен обещать.
```

### 42. Квалификация заявки

```
Вот заявка: [текст]. Мой идеальный клиент: [описание]. Оцени заявку по четырём пунктам: задача, бюджет, срок, кто принимает решение. По каждому — «есть», «нет», «неясно» и вопрос, который это прояснит. Итог: брать, уточнять или вежливо отказать.
```

### 43. Ответ на «дорого»

```
Клиент сказал «дорого» про [что] за [цена]. Что я знаю о его ситуации: [факты]. Дай 4 варианта ответа: через стоимость бездействия, через сравнение с альтернативой, через уменьшение объёма, через вопрос. Каждый до трёх предложений, без давления.
```

### 44. Коммерческое предложение

```
Клиент: [кто], задача: [что], что обсудили: [итоги созвона]. Собери КП: их задача их словами, решение по этапам, что входит и что нет, срок, цена, следующий шаг с датой. До одной страницы.
```

### 45. Письмо после созвона

```
Созвон с [кто] закончился так: [итоги]. Напиши follow-up: что договорились, кто что делает и к какому числу, открытые вопросы, следующий контакт. До 120 слов, без «было приятно пообщаться».
```

### 46. Когда клиент пропал

```
Клиент [кто] не отвечает [срок] после [КП / созвона]. Напиши 3 коротких сообщения с интервалом в 4 дня. Первое — полезное дополнение, второе — прямой вопрос, третье — закрывающее, оставляющее дверь открытой. Без «просто хотел напомнить».
```

### 47. Разбор проигранной сделки

```
Сделка с [кто] сорвалась. Хронология: [что происходило]. Найди 3 момента, где можно было поступить иначе. Для каждого: что я сделал, что стоило сделать, какой вопрос задать в следующий раз. Без самобичевания, только действия.
```

### 48. Скрипт первого сообщения

```
Пишу [кому] в [мессенджер / соцсеть]. Повод: [что увидел у него]. Напиши 4 варианта первого сообщения до 50 слов: конкретный повод, одна мысль, лёгкий вопрос. Ни слова о продукте в первом сообщении.
```

### 49. Апсейл действующему клиенту

```
Клиент пользуется [что] уже [срок], результат: [цифры]. Хочу предложить [что ещё]. Напиши сообщение: что уже получилось, какая следующая проблема видна, как её решает предложение, цена, следующий шаг.
```

### 50. Вопросы для выявления боли

```
Я продаю [что] для [кто]. Составь 12 вопросов, которые помогают клиенту самому назвать проблему и её цену. Раздели на: про ситуацию, про последствия, про то, что уже пробовали, про желаемый результат. Без вопросов, на которые отвечают «да».
```

## Документы и рабочая рутина

То, что съедает день: письма, встречи, отчёты, инструкции.

### 51. Протокол встречи

```
Вот заметки со встречи: [текст]. Сделай протокол: о чём договорились, решения, задачи с ответственным и сроком, открытые вопросы. Не придумывай ответственных и сроки — где их нет, пиши «не указано». Решения отдели от идей.
```

### 52. Резюме длинного документа

```
Вот документ: [текст]. Мне нужно принять решение о [что]. Вытащи только то, что на это влияет: суммы, сроки, обязательства, ограничения, риски. Для каждого пункта укажи, где это в документе. Чего в документе нет — напиши прямо.
```

### 53. Инструкция для сотрудника

```
Процесс: [описание как умею]. Напиши пошаговую инструкцию для новичка: что нужно до начала, шаги с глаголами, как понять, что шаг сделан, что делать, если пошло не так. Каждый шаг — одно действие.
```

### 54. Описание вакансии

```
Ищу [кто] для [задачи]. Условия: [формат, вилка]. Напиши вакансию: что человек будет делать в первые 3 месяца, что должен уметь, что будет плюсом, чего мы не ждём. Без «стрессоустойчивость» и «многозадачность».
```

### 55. Отчёт для руководителя

```
Данные за период: [цифры и события]. Собери отчёт на одну страницу: главный итог одной фразой, 3 показателя с динамикой, что сработало, что нет, что прошу решить. Цифры только из данных.
```

### 56. Ответ на сложное письмо

```
Мне написали: [письмо]. Сначала разбери: чего человек хочет, что требуется от меня, что между строк. Потом предложи ответ: тон [спокойный / твёрдый], я хочу [согласиться / отказать / уточнить]. До 120 слов.
```

### 57. Регламент из хаоса

```
Сейчас мы делаем [процесс] так: [описание]. Проблемы: [список]. Предложи регламент: кто за что отвечает, в каком порядке, какие сроки, что считается готовым. Отметь, какие шаги можно убрать совсем.
```

### 58. План проекта

```
Проект: [что], срок: [когда], команда: [кто]. Разбей на этапы, у каждого: результат, задачи, ответственный, длительность, от чего зависит. Отдельно выпиши 5 рисков и что делаем, если каждый случится.
```

### 59. Подготовка к сложному разговору

```
Мне нужно поговорить с [кто] о [тема]. Моя цель: [что]. Его вероятная позиция: [что]. Помоги подготовиться: с чего начать, 3 возможные реакции и ответ на каждую, чего не говорить, на чём закончить.
```

### 60. Сравнение вариантов

```
Выбираю между [вариант А], [вариант Б], [вариант В] для [задача]. Важно: [критерии]. Сделай таблицу сравнения по критериям, под ней — у кого какой главный минус. Не выбирай за меня: скажи, какой вопрос решает выбор.
```

## Анализ и решения

Когда нужно подумать, а не написать. Просите модель спорить, а не соглашаться.

### 61. Разбор идеи на прочность

```
Идея: [описание]. Сыграй скептичного инвестора. Назови 5 причин, почему это не сработает, от самой серьёзной. Для каждой: как дёшево проверить за неделю. В конце — что должно оказаться правдой, чтобы идея была хорошей.
```

### 62. Анализ отзывов

```
Вот отзывы клиентов: [тексты]. Сгруппируй по темам, посчитай, сколько раз встречается каждая. Раздели: что хвалят, на что жалуются, чего просят. По каждой жалобе — цитата. Вывод: три изменения с наибольшим эффектом.
```

### 63. Разбор цифр

```
Показатели: [таблица]. Найди 3 самых заметных изменения, предложи по 2 объяснения для каждого и что посмотреть, чтобы проверить. Отдели факты от предположений. Не делай выводов из одного значения.
```

### 64. Сценарии на квартал

```
Бизнес: [что], сейчас: [цифры]. Опиши три сценария на квартал: осторожный, базовый, смелый. Для каждого: что делаем, что нужно, какой результат ждём, по какому признаку поймём через месяц, что идём не туда.
```

### 65. Приоритеты из списка задач

```
Вот задачи: [список]. Цель квартала: [что]. Оцени каждую по влиянию на цель и трудоёмкости. Раздели на: делать сейчас, запланировать, отдать, не делать. Объясни три спорных решения.
```

### 66. Вопросы эксперту

```
Мне нужно разобраться в [тема], я новичок. Завтра разговор со специалистом на 30 минут. Составь 10 вопросов, которые дадут максимум: сначала про типичные ошибки, потом про то, с чего начинают, в конце — что почитать.
```

### 67. Поиск слабого места в процессе

```
Процесс: [шаги], на него уходит [время], проблема: [что не так]. Найди, на каком шаге теряется больше всего времени или качества. Предложи 3 изменения: без денег, с небольшим бюджетом, с автоматизацией.
```

### 68. Решение с последствиями

```
Думаю [решение]. За: [аргументы]. Против: [аргументы]. Распиши последствия через месяц, полгода и два года для каждого варианта. Что из этого обратимо, а что нет? Какой информации мне не хватает, чтобы решить?
```

### 69. Конкурентный обзор

```
Мой продукт: [что]. Конкуренты: [список с описаниями]. Сравни по: кому продают, что обещают, цена, чем доказывают, что у них слабо. Используй только данные из моих описаний. Итог: свободная позиция, которую никто не занял.
```

### 70. Ретроспектива проекта

```
Проект: [что], итог: [результат], как шло: [хронология]. Разбери: что сработало и почему, что помешало, какие решения стоило принять раньше. Три правила на следующий проект — конкретных, а не «лучше планировать».
```

## Настройка ассистента под себя

Промпты, которые делают ответы точнее во всех остальных разделах.

### 71. Инструкция о себе

```
Помоги составить инструкцию для ассистента обо мне. Задай мне по очереди 8 вопросов: чем занимаюсь, для кого, какой у меня тон, что меня раздражает в текстах, какой формат ответов люблю. После ответов собери инструкцию до 150 слов, которую я вставлю в настройки.
```

### 72. Мой тон по образцам

```
Вот три моих текста: [тексты]. Опиши мой стиль в 8 правилах: длина предложений, лексика, чего я избегаю, как начинаю и заканчиваю. Потом перепиши этот абзац в моём стиле: [абзац].
```

### 73. Уточни, прежде чем делать

```
Перед тем как выполнять задачу, задай мне до 5 уточняющих вопросов, если от ответа зависит результат. Если всё ясно — не спрашивай. Задача: [задача].
```

### 74. Проверка собственного ответа

```
Выполни задачу: [задача]. Затем перечитай ответ как редактор: что неточно, что без доказательств, что можно сократить. Покажи исправленную версию и список правок.
```

### 75. Шаблон из удачного ответа

```
Этот твой ответ мне подошёл: [текст]. Преврати его в шаблон-промпт с переменными в квадратных скобках, чтобы я получал такой же результат для других случаев. Объясни, какая часть шаблона за что отвечает.
```

### 76. Строгий формат

```
Отвечай только в таком формате: [описание формата или пример]. Никаких вступлений и пояснений до или после. Если данных не хватает, в соответствующем поле пиши «нет данных». Задача: [задача].
```

### 77. Роль с ограничениями

```
Ты [роль] с опытом в [область]. Отвечай так, как ответил бы практик: с примерами из работы, с оговорками, где есть риск. Не давай общих советов. Если вопрос вне твоей области — скажи об этом. Вопрос: [вопрос].
```

### 78. Разбивка большой задачи

```
Задача: [большая задача]. Не выполняй её сразу. Сначала разбей на шаги, покажи план и спроси, с какого начать. Каждый шаг выполняй отдельно и жди моего «дальше».
```

### 79. Критик вместо помощника

```
Вот мой текст / план / идея: [материал]. Не хвали и не улучшай. Найди 5 самых слабых мест и объясни, почему каждое слабое. Только после этого — по одной правке на каждое.
```

### 80. Объяснение на трёх уровнях

```
Объясни [тема] трижды: школьнику, специалисту из смежной области, эксперту. В каждом варианте — один пример из жизни. В конце — какое распространённое упрощение на первом уровне на самом деле неверно.
```
