# Язык камеры

Камера — главный инструмент «дорогого» вида. Шаблонные AI-ролики выдают три вещи: неподвижная камера, линейная скорость и движение без причины. Здесь каждое движение — функция времени с режиссёрским смыслом и правильной кривой. Работаешь в проекте Cinematic Studio, создание проекта — в `cinematic-director`.

Код камеры — `src/three/camera.ts`, кривые — `src/lib/curves.ts`. Камера передаётся в `<Stage camera={…}>`. `Stage` сам ставит позицию, цель, угол обзора и крен на каждом кадре, а фокус держит на цели (или на `focus`).

## Что нужно на входе

- Раскадровка из `cinematic-director`: для каждого кадра — намерение («показать масштаб», «познакомить с продуктом», «удар»).
- Где стоят объекты и текст (координаты сцены).
- Длина кадра в секундах и доли музыки, если движение должно встать в такт (`cut-rhythm`).

## Порядок работы

1. **Намерение → движение.** Подбери движение по задаче кадра (таблица ниже и [references/moves.md](references/moves.md)). Одно движение на кадр. Сложные траектории собирай из двух простых через `cutBetween`.
2. **Объектив.** 35 мм — пространство и вовлечение, 50 мм — нейтрально и «продуктово», 85 мм — портрет объекта, сжатый фон, сильное размытие. Таблица — [references/lenses.md](references/lenses.md).
3. **Кривая.** Движение камеры почти всегда `silk` (по умолчанию в `dolly`, `orbit`, `crane`) или `sineInOut` для длинных облётов. Удары — `snap`. Уход в склейку — `launch` или `expoIn`. Каталог и как перенести кривую из After Effects — [references/curves.md](references/curves.md).
4. **Глубина резкости.** У `Stage` задай `focusRange` (зона резкости в единицах сцены) и, если надо, `focus={(t) => …}` — что в фокусе в момент `t`.
5. **Склейки внутри сцены.** Монтаж под бит — сменой камеры в той же сцене (`cutBetween`), whip pan — быстрым поворотом камеры. Это дороже и чище 2D-переходов. См. [references/in-camera.md](references/in-camera.md).
6. **Проверка.** Отрендерь контактный лист: начало, середина, конец каждого движения. Посмотри, что объект не выходит из кадра и что за всё движение текст хотя бы раз в фокусе.

## API за минуту

```tsx
import { locked, dolly, orbit, crane, dollyZoom, handheld, cutBetween, lens, type CameraMove } from "../three/camera";

locked([0, 0.3, 7], [0, 0, 0], 50)                                         // позиция, цель, мм
dolly({ start: 0, end: 4, from: [-1.8, 1.1, 12], to: [-0.6, 0.45, 7.6], lookFrom: [0, 0, 0], lookTo: [0, 0.2, 0], mmFrom: 40, mmTo: 50, ease: "silk" })
orbit({ start: 4, end: 8, center: [0, 0, 0], radius: 7.6, radiusTo: 6.9, height: 0.4, fromDeg: -5, toDeg: 9, mm: 50, ease: "sineInOut" })
crane({ start: 0, end: 3.2, x: 0, z: 6.2, fromY: 3.2, toY: 0.5, target: [0, 0, 0], mm: 35 })
dollyZoom({ start: 7.2, end: 12, fromDist: 7.5, toDist: 5.2, subjectZ: 0, height: 0.1 })
handheld(move, 0.03, 0.6, 7)                // амплитуда, скорость, seed: поверх любого движения
cutBetween([[0, moveA], [4.2, moveB]])      // с 4,2 с работает moveB
```

`CameraMove` — это `{ position(t), target(t), fov(t), roll?(t) }`. Любую траекторию можно написать руками через `track()` (см. moves.md).

## Задача → движение

| Задача кадра | Движение | Длительность | Кривая |
|---|---|---|---|
| Открытие, «мы входим в мир» | `dolly` издалека (d ×1,5) с лёгким подъёмом цели | 3–5 с | `silk` |
| Показать продукт со всех сторон | `orbit` 20–60° | 4–8 с | `sineInOut` |
| Раскрыть масштаб, финал | `crane` сверху вниз или снизу вверх | 2,5–4 с | `silk` |
| Напряжение, «мир сдвинулся» | `dollyZoom` | 2–5 с | `sineInOut` |
| Удар на долю | `cutBetween` + наезд `snap` с 24→32 мм | доля или такт | `snap` |
| Пауза, «дыхание» | `locked` + `handheld(…, 0.02)` | 1,5–3 с | — |
| Документальность, живость | `handheld` 0,04–0,08 поверх движения | — | — |

## Правила

- **Движение должно иметь причину:** раскрыть, приблизить, обойти, догнать. Если причину не назвать, камеру ставь `locked` с лёгким `handheld` 0,02–0,03.
- **Никакой линейной скорости.** Ни одна камера не стартует и не останавливается мгновенно, кроме склейки.
- **Перекрывай движения.** Камера начинает облёт, пока текст ещё садится (за 0,3–0,8 с до конца появления). Последовательные «сначала текст, потом камера» выглядят как слайды.
- **Скорость камеры ограничена.** На 16:9 объект в фокусе не проходит больше 1/3 ширины кадра за секунду. Быстрее — только whip pan, тогда нужен motion blur (рендер ×4 + `finish.py` в `grade-finish`).
- **Вертикаль и горизонт.** Крен (`roll`) — только от `handheld` или намеренно, до 3–4°. Завал горизонта на продуктовом кадре — брак.
- **Параллакс.** Минимум два плана на разной глубине: частицы `Dust`, кольца, пол. Без них движение камеры по пустой сцене не читается.
- **Не облетай текст сбоку больше чем на ±25°.** Буквы становятся ребром и не читаются. Если надо больше — пусть текст уйдёт до этого.
- **Хроматическая аберрация растёт со скоростью камеры** (`aberrationBoost`, по умолчанию 1). На резких наездах в `kinetic` поставь 2, в продуктовом `keynote` и в сценах с футажом — 0.

## Связанные скиллы

- `cinematic-director` — раскадровка, где решается, какой кадр каким движением снят.
- `space-type` — размеры текста на дистанции камеры.
- `vfx-toolkit` — пыль, кольца, полосы для параллакса.
- `cut-rhythm` — смена камер под доли, whip pan и match cut.
- `grade-finish` — настоящий motion blur для быстрых движений.
