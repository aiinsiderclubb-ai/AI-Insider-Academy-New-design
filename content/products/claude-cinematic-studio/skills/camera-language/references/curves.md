# Кривые движения: думать как в Graph Editor

Разница между «AI-анимацией» и работой моушн-дизайнера почти всегда в кривых. Линейное движение начинается рывком, едет как робот и останавливается ударом: глаз считывает это как «компьютер». В After Effects дизайнер открывает Graph Editor и тянет ручки. Здесь то же делают функции из `src/lib/curves.ts`: каждая берёт долю времени 0…1 и возвращает долю пути 0…1.

## Именованные кривые (`ease.*`)

| Имя | cubic-bezier | Ощущение | Где использовать |
|---|---|---|---|
| `linear` | — | Механика | Только печать HUD, бегущие строки, постоянное вращение |
| `sineInOut` | 0.37, 0, 0.63, 1 | Мягко, почти Easy Ease | Длинные облёты, дрейф, «дыхание» |
| `cubicOut` | 0.33, 1, 0.68, 1 | Быстро стартует, мягко садится | Простые появления UI |
| `cubicInOut` | 0.65, 0, 0.35, 1 | Easy Ease с влиянием ~65 % | По умолчанию у ключей `track()` |
| `quintOut` | 0.22, 1, 0.36, 1 | Резкий старт, долгая посадка | Перевороты `flip` |
| `quintInOut` | 0.83, 0, 0.17, 1 | Сильный разгон и торможение | Световые следы, перелёты между точками |
| `expoIn` | 0.7, 0, 0.84, 0 | Набирает скорость и уходит | Уходы текста, разгон перед склейкой |
| `expoOut` | 0.16, 1, 0.3, 1 | Влетает и замирает | Появления букв по умолчанию |
| `expoInOut` | 0.87, 0, 0.13, 1 | Почти мгновенный перенос с мягкими краями | Whip pan |
| `silk` | 0.45, 0, 0.1, 1 | Плавный старт, очень длинная посадка | Камера по умолчанию: «дорогой» докат |
| `snap` | 0.05, 0.9, 0.1, 1 | Удар, потом медленно оседает | Snap zoom, слово-удар |
| `launch` | 0.6, 0, 0.9, 0.3 | Разгоняется и не тормозит | Выход из кадра, падение |
| `anticipate` | 0.36, −0.35, 0.3, 1 | Замах назад, потом вперёд | Удар, прыжок, «пружина» |
| `backOut` | 0.34, 1.56, 0.64, 1 | Перелёт и возврат | `burst`, вырастание, игривые элементы |

## Перенос кривой из After Effects

Для сегмента между двумя ключами со скоростью 0 на обоих концах (обычный Easy Ease и его вариации):

```
bezier(outInfluence / 100, 0, 1 − inInfluence / 100, 1)
```

- Easy Ease (33,33 % / 33,33 %) → `bezier(0.333, 0, 0.667, 1)` ≈ `sineInOut`.
- «Долгая посадка» 10 % на выходе, 90 % на входе → `bezier(0.1, 0, 0.1, 1)`.
- `silk` — это 45 % на выходе, 90 % на входе.

Если скорость на ключе не 0 (Speed Graph показывает значение), для оси y:

```
y1 = скорость_выхода × длительность × x1 / Δзначение
y2 = 1 − скорость_входа × длительность × (1 − x2) / Δзначение
```

Любую CSS- или Lottie-кривую `cubic-bezier(a, b, c, d)` пиши как `bezier(a, b, c, d)` и передавай туда, где принимается `EaseName | Ease`: в `ease` ригов камеры, в `LetterMove.ease`, в ключи `track()`.

## Ключи — track()

```tsx
import { track } from "../lib/curves";

const y = track<number>([
  [0, -2],
  [0.8, 0, "expoOut"],    // кривая ключа формирует сегмент, КОТОРЫЙ НА НЁМ ЗАКАНЧИВАЕТСЯ
  [2.4, 0.15, "sineInOut"],
]);
const rot = track<[number, number, number]>([[0, [0, -40, 0]], [1.2, [0, 0, 0], "silk"]]);
```

До первого ключа — значение первого, после последнего — последнего. Кортежи интерполируются по компонентам.

## Физика: пружина и инерция

```tsx
import { spring, coast, lerp } from "../lib/curves";

// Пружина: 0 → 1 с перелётом. t — секунды ПОСЛЕ отпускания.
const k = spring(t - 1.2, { stiffness: 170, damping: 0.55, mass: 1 });
const scale = lerp(0, 1, k);

// Инерция: брошенный предмет катится и останавливается. Путь = v0 / friction в пределе.
const angle = coast(t - 2.0, 720, 3);   // градусов: 720 °/с, трение 3 → до 240°
```

| damping | Поведение |
|---|---|
| 0,3 | Несколько заметных отскоков — мультяшно |
| 0,55 | Один мягкий перелёт — по умолчанию, «живая» посадка |
| 0,8 | Едва заметный перелёт — премиально |
| 1 и больше | Без перелёта (критическое затухание) |

Время успокоения ≈ `4 / (damping · √(stiffness / mass))`. При 170/0,55/1 это 0,56 с. Тяжёлый объект (`mass` 3) раскачивается медленнее и дольше — так передаётся вес.

## Детерминированный шум

`noise1(x, seed)` — гладкий шум −1…1 для мерцания, дрожи, дрейфа. `rng(seed)` — генератор случайных чисел, одинаковый при каждом рендере. `Math.random()` и `Date.now()` в кадре запрещены: два рендера одного кадра должны совпадать до пикселя, иначе ломаются рендер ×4 для motion blur и повторная сборка.

## Принципы, которые отличают дизайнера

1. **Ни один объект не стартует на полной скорости.** Исключение — объект, влетевший из-за кадра: он уже двигался.
2. **Перекрывающееся действие.** Части приходят не одновременно: буквы со `stagger`, кольца с задержкой 0,15–0,2 с друг от друга, подзаголовок после заголовка.
3. **Следование (follow-through).** После резкой остановки — короткий докат: `snap`, `backOut`, пружина с damping 0,6–0,8.
4. **Контраст скоростей.** Быстрое (0,3 с) рядом с медленным (3 с). Ролик, где всё движется с одной скоростью, усыпляет.
5. **Замедление перед важным.** Speed ramp, `silk`-посадка, пауза в 0,3–0,5 с перед ударом. Удар без паузы не бьёт.
6. **Скорость камеры и объектов в одну сторону** складывается, в разные — гасит. Проверяй на контактном листе.
