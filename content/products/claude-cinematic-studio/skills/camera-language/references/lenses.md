# Объективы и глубина резкости

`lens(мм)` в `src/three/camera.ts` переводит фокусное расстояние полнокадровой камеры (кадр 36×24 мм) в вертикальный угол обзора. Все риги принимают миллиметры, а не градусы: так проще думать как оператор.

| мм | Верт. угол | Ощущение | Для чего |
|---|---|---|---|
| 18 | 67° | Широко, перспектива тянет края, близкие объекты огромные | Пролёт сквозь сцену, гиперпространство, «внутри» |
| 24 | 53° | Динамично, драматично | Спорт, удары, snap-наезды (24 → 32) |
| 28 | 46° | Широко, но без явных искажений | Пролёт над сеткой, кадр с несколькими объектами |
| 35 | 38° | Естественное «пространство», зритель в сцене | Краны, облёты, открывающие планы |
| 50 | 27° | Нейтрально, как глаз | Продукт, заголовок, большинство кадров |
| 85 | 16° | Портрет объекта, фон сжат и сильно размыт | Деталь продукта, крупный текст на размытом свете |
| 135 | 10° | Телевик: всё плоско, фон — пятна света | Макро-детали, рефлексы на металле, финальный инсерт |

Меняя объектив, сохраняй крупность: камера отъезжает пропорционально мм (50 мм на 7 = 85 мм на 11,9). Видимая высота кадра — `24 · d / мм` (таблица — в `space-type`, references/sizing.md).

Короче 28 мм крупный текст у края кадра раздувается. Держи его в центре или бери длиннее объектив.

## Глубина резкости

Пост-обработка `Stage` (эффект DepthOfField) фокусируется на точке:

```tsx
<Stage look={look} camera={camera}
       focus={(t) => [0, 0, 0]}   // мировая точка в фокусе; по умолчанию — цель камеры
       focusRange={2.5}>          // глубина резкой зоны в единицах сцены
```

- Сила размытия задана стилем: `look.post.bokeh` (keynote 3, chrome 4, neon 2,5, editorial 3,5, kinetic 0 — DOF выключен).
- `focusRange`: 1,2–2 — «объектив 85 мм», фон и передний план в кашу. 2,5–3,5 — продуктовая норма. 5–6 — почти всё резко (гиперпространство, футаж-сцены, где 3D должно совпасть с резким плейтом).
- Расстояние до фокуса `Stage` считает сам на каждом кадре. Наезд не уводит объект из фокуса.
- Пыль `Dust` перед камерой в расфокусе превращается в боке-кружки. Это самая дешёвая «киношность»: держи 300–900 частиц в объёме перед и за объектом.

## Перевод фокуса (rack focus)

Смена того, на что смотрит зритель, без склейки. Перевод занимает 0,6–1,2 с с `silk` или `cubicInOut`, а кадр держится до и после.

```tsx
import { track } from "../lib/curves";
import type { Vec3 } from "../three/camera";

// Сначала в фокусе кикер на переднем плане, потом — заголовок в глубине
const focusAt = track<Vec3>([
  [0, [0, 0.9, 1.5]],
  [2.0, [0, 0.9, 1.5]],
  [2.9, [0, 0, -1], "silk"],
]);

<Stage look={look} camera={locked([0, 0.4, 7], [0, 0.2, 0], 85)} focus={focusAt} focusRange={1.4}>
  …
</Stage>
```

Чтобы перевод читался, нужно 85 мм или длиннее и `focusRange` до 1,5. Расстояние между планами — 2+ единицы.

## Объектив и монтаж

- Подряд два кадра одним объективом с близкой крупностью дают «прыжок». Меняй мм или крупность в 1,5 раза.
- Кинетический монтаж (`KineticSpot`): каждая доля — 24 → 32 мм с наездом. Именно смена угла обзора даёт «удар», а не только движение.
- Финал и лого — 50–85 мм: стабильность, ничего не искажено.
