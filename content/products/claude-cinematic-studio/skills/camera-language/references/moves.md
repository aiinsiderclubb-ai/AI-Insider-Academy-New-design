# Движения камеры

Все риги — в `src/three/camera.ts`. У всех, кроме `locked`, есть тайминг: `start` (по умолчанию 0), `end` и `ease` (имя из `src/lib/curves.ts` или своя функция). До `start` камера стоит в начальной точке, после `end` — в конечной. Время — секунды от начала композиции, а не от начала кадра.

Сцена «смотрит» из `+z`: объекты около начала координат, камера на `z` 5–12. Ось `y` вверх.

## locked — неподвижная камера

```ts
locked(position: Vec3, target: Vec3 = [0, 0, 0], mm = 50)
```

Когда: пауза, «дыхание» после удара, кадр, где движется всё, кроме камеры (кинетический текст, взрыв частиц). Почти всегда оборачивай в `handheld(…, 0.02–0.03)`: абсолютно мёртвая камера в 3D выглядит как рендер, а не съёмка.

## dolly — тележка

```ts
dolly({ start?, end, ease? = "silk", from: Vec3, to: Vec3, lookFrom?: Vec3, lookTo?: Vec3, mmFrom? = 50, mmTo? })
```

Прямой проезд с возможным переводом прицела (`lookFrom` → `lookTo`) и зумом (`mmFrom` → `mmTo`).

- **Push-in** (наезд): `from` на 1,3–1,6 дальше, чем `to`. Это «внимание сюда», лучшая вступительная камера. 3–5 с на `silk`.
- **Pull-out** (отъезд): наоборот. Раскрывает контекст, хорош в финале. Сочетай с `intoDepth` у текста.
- **Трек вбок**: `from` и `to` отличаются по `x`, прицел фиксирован. Даёт сильный параллакс между текстом и фоном.
- **Snap zoom**: короткий наезд за долю с `ease: "snap"`, `mmFrom: 24 → mmTo: 32`. Основа кинетических роликов.
- Комбо «наезд + лёгкий подъём + зум 40→50 мм» — продуктовое открытие из `HeroTitle.tsx`.

## orbit — облёт

```ts
orbit({ start?, end, ease? = "silk", center? = [0,0,0], radius, radiusTo?, height? = 0, fromDeg, toDeg, mm? = 50 })
```

Угол 0° — камера на `+z` перед объектом, положительный — обход вправо (камера уходит к `+x`).

- Продукт: 20–60° за 4–8 с, `sineInOut`. Больше 90° за кадр зритель теряется, если сцена не симметрична.
- `radiusTo` меньше `radius` даёт облёт с наездом, «спираль». Самое «дорогое» движение для финала.
- `height` 0,3–0.8: чуть выше объекта, взгляд сверху. С высоты 0 кольца и пол схлопываются в линии.
- Облёт вокруг текста — не больше ±25° от фронта.

## crane — кран

```ts
crane({ start?, end, ease? = "silk", x? = 0, z, fromY, toY, target? = [0,0,0], mm? = 35 })
```

Камера едет по вертикали и держит цель. Сверху вниз — «спускаемся в мир», раскрытие (`OrbitType`: `fromY 3.2 → toY 0.5` за 3,2 с). Снизу вверх — величие, герой. 35 мм усиливает ощущение высоты.

## dollyZoom — вертиго

```ts
dollyZoom({ start?, end, ease? = "sineInOut", subjectZ? = 0, fromDist, toDist, height? = 0 })
```

Камера едет к объекту или от него, а угол обзора меняется так, что объект остаётся того же размера, а фон «дышит». Начальный объектив — 35 мм, `fov` пересчитывается сам. Медленно (2–5 с) — тревога, «момент истины». Наезд 7,5 → 5,2 за 4,8 с в финале `TechFilm` даёт тихое давление под логотипом. Быстрый dolly zoom меньше секунды выглядит как сбой.

## handheld — живая камера

```ts
handheld(move, amount = 0.05, speed = 0.6, seed = 7)
```

Плавный двухоктавный шум поверх любого движения: позиция по трём осям и крен. Детерминированный, одинаковый при каждом рендере.

| amount | Ощущение |
|---|---|
| 0,015–0,03 | стедикам, почти незаметно — всегда для `locked` и продукта |
| 0,04–0,06 | оператор на гимбале, «дышит» |
| 0,08–0,12 | ручная камера, репортаж, напряжение |

`speed` 0,4–0,8 — плавно; 1,2–2 — нервно (так в гиперпространстве `TechFilm`). Разные `seed` у соседних кадров, чтобы шум не повторялся.

## cutBetween — монтаж внутри сцены

```ts
cutBetween([[0, moveA], [2.5, moveB], [4.0, moveC]])
```

С момента `start` работает следующее движение. Склейка мгновенная, сцена та же: свет, частицы и текст продолжаются. Это монтаж «съёмка с нескольких камер». Каждое движение внутри получает те же абсолютные секунды, поэтому `start`/`end` у них совпадают с моментом склейки. Склейки ставь на доли (`cut-rhythm`). Пример — `KineticSpot.tsx`.

Правило 30°: соседние ракурсы отличаются минимум на 30° или в 1,5 раза по крупности. Иначе склейка выглядит как прыжок кадра.

## Своё движение через track()

Любая траектория — ключи с кривой на каждом сегменте:

```tsx
import { track } from "../lib/curves";
import { lens, type CameraMove, type Vec3 } from "../three/camera";

const pos = track<Vec3>([
  [0, [3, 1.5, 9]],
  [2.2, [0.8, 0.6, 6], "silk"],        // кривая на ключе формирует сегмент, который на нём заканчивается
  [3.0, [0.6, 0.5, 5.6], "sineInOut"], // докат
  [5.0, [-1.4, 0.2, 5.2], "cubicInOut"],
]);
const aim = track<Vec3>([[0, [0, 0.4, 0]], [3, [0, 0, 0], "silk"]]);
const mm = track<number>([[0, 35], [5, 50, "sineInOut"]]);

const custom: CameraMove = { position: pos, target: aim, fov: (t) => lens(mm(t)) };
```

`track<Vec3>` интерполирует кортежи по-компонентно. Кривые соседних сегментов не сглаживаются друг с другом. Чтобы не было «стыка» скорости, сегмент, который продолжает движение, начинай с `sineInOut` или `cubicInOut`, а не с `expoOut`.

Модификация готового движения — оборачиванием:

```tsx
// опустить прицел, когда появляется титр (OrbitType.tsx)
const aimDown = (t: number) => -0.75 * ease.silk(progress(t, 4.6, 6.4));
const camera: CameraMove = { ...base, target: (t) => { const p = base.target(t); return [p[0], p[1] + aimDown(t), p[2]]; } };
```

## Длительности по умолчанию

| Движение | Мин | Обычно | Макс без монтажа |
|---|---|---|---|
| Push-in / pull-out | 1,5 с | 3–5 с | 8 с |
| Облёт | 2,5 с | 4–8 с | 12 с |
| Кран | 2 с | 3–4 с | 6 с |
| Dolly zoom | 2 с | 3–5 с | 6 с |
| Snap zoom | 0,25 с | доля | 1 такт |

Кадр дольше 8 с без смены движения допустим, только если внутри него что-то меняется (текст, свет, частицы). Иначе разбей его `cutBetween`.
