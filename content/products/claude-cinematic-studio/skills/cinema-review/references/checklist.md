# Чек-лист финишного QC

Проходи по порядку. На каждый пункт ответ «да» или конкретная правка.

## 1. Кадр (по `contact.jpg`)

- [ ] **Глубина.** В каждом шоте минимум два плана: что-то ближе к камере (пыль `Dust`, кольца `Rings`, буква, край объекта), что-то дальше (фон, пол `GridFloor` / `MirrorFloor`, туман). Плоский кадр «текст на фоне» — главный признак шаблона.
- [ ] **Композиция.** Не всё по центру. Главный объект хотя бы в части шотов на линии третей; кадр не симметричен без причины.
- [ ] **Масштаб.** Крупности меняются: общий, средний, деталь. Пять шотов одной крупности — монотонно.
- [ ] **Свет.** Металл читается как металл: на `Type3D` и `Monolith` видны полосы бликов и края, а не ровная серая заливка. Есть контровой свет, объект отделён от фона.
- [ ] **Текст читается.** Контраст с фоном, ни одна строка не режется краем кадра или полосами `Letterbox`. В вертикали всё в безопасной зоне (`safezones.jpg`).
- [ ] **Цвет — одно решение.** Палитра стиля держится во всех шотах; нет шота «из другого ролика».
- [ ] **Чистота.** Нет пустых кадров, артефактов 3D (мерцающие грани, z-fighting, пропавшие буквы), полос в градиентах.

## 2. Движение (по `motion.svg` и просмотру)

- [ ] **Кривые, а не линии.** Всё стартует и садится с ускорением и замедлением (`ease`, `spring`). Предмет с постоянной скоростью от края до края — признак AI-видео.
- [ ] **Нет мёртвых зон.** Красные участки на графике — либо задуманный вдох с дрейфом камеры, либо брак.
- [ ] **Камера живёт.** Даже на статике есть микродрейф (`handheld` с amount 0,02–0,04) или медленный наезд.
- [ ] **Размытие движения.** На быстрых пролётах, вип-пэнах и частицах есть смаз. Ступенчатые чёткие буквы на скорости = рендер без 4× (`grade-finish/references/motion-blur.md`).
- [ ] **Движение мотивировано.** Каждый эффект (вспышка, глитч, аберрация, засвет) привязан к событию: удару, склейке, смене сцены.

## 3. Ритм (по таблице «Склейки» и графику)

- [ ] **В долю.** Сдвиг склеек от доли ±2 кадра и меньше. Склейки за пределами допуска чинить: `cut-rhythm/scripts/cutlist.py` и новые времена в композиции.
- [ ] **Разгон.** Средняя длина шотов падает к кульминации, после главного удара — длинный финальный шот.
- [ ] **Не метроном.** Длины шотов разные (жёлтые линии на графике не через равные промежутки).
- [ ] **Переходы разнообразны и редки.** Эффектных переходов не больше трети; не три вип-пэна подряд; фейды не одинаковые везде.
- [ ] **Текст успевают прочитать**: около 3 слов в секунду + 0,4 с.

## 4. Звук (раздел «Звук» отчёта и прослушивание)

- [ ] Громкость −14 LUFS ±1 (соцсети, YouTube), true peak ≤ −1 dBTP.
- [ ] Каждый удар в кадре звучит; каждый звук совпадает с событием до кадра.
- [ ] Музыка не обрывается посреди такта; конец ролика на сильной доле, хвост затухает.
- [ ] Звуковые эффекты слышны через музыку, но не громче её кульминации.

## 5. Технические условия (раздел «Площадки»)

- [ ] ✓ по каждой целевой площадке.
- [ ] yuv420p, H.264 для соцсетей; faststart для сайта.
- [ ] Частота сдачи совпадает с задуманной (30, если не договорились иначе).

## Признаки «AI-видео» и как их убрать

| Признак | Как выглядит | Правка |
|---|---|---|
| Линейное движение | Объект едет ровно, без разгона и торможения | `track()` с `ease` из `src/lib/curves.ts`: `silk` для камеры, `snap` для ударов, `expoOut` для посадок; `spring()` для пружинистой физики |
| Всё по центру и статично | Текст ровно в центре, камера стоит | Сдвинь на треть, `handheld()` поверх движения, медленный `dolly` / `orbit` |
| Одинаковые фейды | Каждый шот растворяется в следующий за 0,5 с | Склейки в долю; эффектные переходы — только на смене сцены (`Sequence2` `whip` / `zoom` / `flash`), переходы камерой |
| Эффекты без причины | Глитч и вспышки по всему ролику | Эффект только на событии: `Flash` на удар, `glitch` на HUD, аберрация — от скорости камеры (`Stage` делает это сам) |
| Нет глубины | Плоский текст на градиенте | 3D-текст `Type3D` в сцене `Stage`, передний план (`Dust`, `Rings`), глубина резкости (`focusRange` 1,5–2,5), туман стиля |
| Текст поверх, а не в сцене | Подписи «наклеены» на видео | Текст между `Plate` и `Cutout` (за объектом), `RingType` вокруг объекта, `Pinned` по трекингу |
| Нечитаемые задержки | Слово мелькает на 0,3 с или висит 4 с без движения | Время чтения по `storyboard.py`; на долгой выдержке — `wobble`, дрейф камеры, свет по металлу |
| Склейки мимо доли | «Почти в такт» | `cutlist.py`, `--lead-frames 1` для плотного монтажа |
| Нет размытия движения | Стробящие буквы на скорости | Рендер на 120 fps и `finish.py --motion-blur` |
| Полосы в градиентах | Ступеньки в тёмном фоне и свечении | `finish.py --grain 3–6`, мастер CRF 14 или ProRes |
| Плоский грейд | Серый, без контраста, «цифровой» | LUT стиля из `grade-finish/references/color.md`, mix 0,6–0,85; халация 0,2–0,3 на ярких краях |
| Пластиковый металл | Серая заливка без бликов | Стиль с `strips` ≥ 3 (`keynote`, `chrome`), камера в движении — полосы скользят; не матовый `roughness` для хрома |
| Шаблонный шрифт и раскладка | Всё одним кеглем, по центру, в одну строку | Иерархия: кикер мелко с разрядкой (`tracking` 0,3), заголовок крупно, подзаголовок; разные `reveal` для уровней |

## Как читать report.md и превращать находки в правки

| Находка в отчёте | Причина | Где чинить |
|---|---|---|
| «нет движения N с» | Статичная сцена или сцена закончилась раньше склейки | Если это вдох — добавь дрейф (`handheld`) и оставь. Иначе сократи шот или добавь движение (`cinematic-director`, `camera-language`) |
| «склейка мимо доли на +N кадр.» | Времена в композиции не совпадают с `storyboard.synced.json` | `cut-rhythm`: `cutlist.py`, перенеси `at` в `Sequence2` и `reveal.at` |
| «чёрный кадр ×1» | Дыра между `Sequence2` или незагруженный кадр футажа | Проверь `at` и `duration` переходов; для футажа — `meta.json` и число кадров в `public/footage/<name>` |
| «белая вспышка N кадров» | `Flash frames` больше 4 | `Flash frames={2–3}`, `peak` 0,4–0,6 |
| «риск полос» | Тёмный гладкий градиент в 8 бит | `grade-finish`: `--grain 3–6`, CRF 14 / ProRes |
| «громкость X LUFS, цель −14» | Звук не прошёл через финиш или пиковый материал | `grade-finish`: `finish.py --music … --sfx …`; предупреждение «could not reach» — опусти `--sfx-db` |
| «true peak > −1» | Лимитер не стоял или AAC добавил пик | Повтори финиш текущим `finish.py` (лимитер −1,5 dBFS) |
| «pix_fmt …» | Мастер не в yuv420p | Финиш без `--prores` для соцсетей |
| «moov в конце файла» | Нет faststart | `finish.py --web` или `ffmpeg -i in.mp4 -c copy -movflags +faststart out.mp4` |
| «кадр W×H, нужен 9:16» | Горизонтальный мастер для вертикальной площадки | `finish.py --crop 9x16` или вертикальная композиция |
| «нет звука» | Мастер собран без `--music` / `--sfx` | `grade-finish` |
| «средний шот < 0,6 с» | Слишком плотно | Объедини шоты, удлини вдох перед ударом |
| «средний шот > 4 с» | Медленно для рекламы | Раздели шот склейками в долю или ускорь камеру |

После правок — новый рендер и `review.py` в новую папку. Сравни разделы «Проблемы» и «Площадки» старого и нового отчёта и покажи пользователю разницу.
