# Формат раскадровки

Раскадровка — один JSON-файл. Это договор между идеей и сборкой: по нему строятся сцены, звук ставится на удары, склейки ложатся на музыку, а QC сверяет готовый ролик с замыслом. Пример — `example-storyboard.json` рядом.

Проверка и таблица шотов:

```bash
python3 scripts/storyboard.py storyboard.json --md storyboard.md
```

Ошибки останавливают работу (код выхода 1). Предупреждения — повод подумать, а не запрет.

## Верхний уровень

| Поле | Что это |
|---|---|
| `title` | Название ролика — для таблицы и отчётов |
| `look` | Стиль проекта: `keynote`, `chrome`, `kinetic`, `neon`, `editorial` |
| `format` | `16:9`, `9:16` или `1:1` |
| `fps` | Частота кадров сдачи, обычно 30 (24 — для «киношного» ритма, 60 — для спорта и интерфейсов) |
| `music` | Путь к треку или `null` |
| `shots` | Шоты по порядку, без дыр и наложений |

## Шот

| Поле | Что это |
|---|---|
| `id` | Короткий номер: `S1`, `S2`… |
| `start`, `end` | Секунды от начала ролика. Конец одного шота — начало следующего |
| `intent` | Что зритель должен почувствовать или узнать. Одна фраза. Если её не сформулировать — шот лишний |
| `breath` | `true` для намеренно медленного шота без ударов — «вдох» перед серией коротких |
| `camera.move` | `dolly`, `push`, `pull`, `orbit`, `crane`, `dollyZoom`, `locked`, `handheld`, `whip` |
| `camera.lens_mm` | Фокусное расстояние: 18–24 мм — простор и скорость, 35–50 — нейтрально, 85–135 — продукт, сжатие, малая глубина резкости |
| `camera.from`, `camera.to` | Позиции или углы — свободная форма, для сборки сцены |
| `layers` | Слои по глубине: `kind` + `what`. Минимум два — передний и задний план |
| `type` | Надписи: `text`, `reveal`, `exit`, необязательные `at` / `until` (секунды, когда надпись видна) |
| `vfx` | Эффекты шота: `bloom`, `dof`, `aberration`, `trails`, `particles`, `glow`, `lightleak`, `flash`, `grain`, `halation`, `streaks`, `distortion` |
| `transition_out` | Как шот передаёт кадр следующему: `kind` + `on` |
| `hits` | Удары внутри шота: `t` (секунды от начала ролика), `what`, `sfx` |
| `sound` | Словами: что звучит |

### Слои (`layers[].kind`)

| kind | Что это |
|---|---|
| `3d-type` | Объёмный текст в сцене (`space-type`) |
| `object` | Объект: монолит, стеклянное ядро, кольца, модель из Blender |
| `footage` | Видеоплейт (`footage-composite`) |
| `cutout` | Вырезанный по маске объект из футажа — лежит поверх текста |
| `particles` | Пыль, искры, взрыв частиц |
| `trail` | Световые трассы |
| `hud` | Интерфейс, прицелы, подписи в 3D |
| `background` | Пол, сетка, туман, фон |
| `light` | Свет как отдельный герой: пролёт полосы по металлу, луч |
| `grade` | Цвет и фактура как смысловой слой |

### Появление и уход текста

`reveal`: `riseFromDepth` (поднимается из глубины — премиальный заголовок), `flip` (переворот по горизонтали, как табло), `flyIn` (пролетает мимо камеры и садится — на удар), `swing` (разворот, как дверь), `burst` (растёт из центра — короткие слова и цифры), `none`.

`exit`: `intoDepth` (уходит в темноту), `pastCamera` (пролетает мимо камеры — под склейку), `fall` (падает с вращением), `cut` (уходит со склейкой), `none` (остаётся до конца).

### Переходы (`transition_out`)

| kind | Когда |
|---|---|
| `cut` | По умолчанию. Чистая склейка в долю почти всегда лучше любого эффекта |
| `whip` | Вип-пэн: смена места на скорости. Не больше двух подряд |
| `zoom` | Зум-сквозь: «влетаем» в следующий шот |
| `flash` | Вспышка 2–3 кадра на ударе |
| `fade` | Затемнение — смена времени или главы |
| `match` | Матч-кат: форма или движение продолжается в следующем шоте |
| `in-camera` | Переход сделан самой камерой в 3D: облёт за объект, пролёт сквозь букву |

`on`: `downbeat` — на сильную долю (смена сцены), `beat` — на любую долю (акцент), `free` — не привязывать к музыке. `scripts/cutlist.py` из `cut-rhythm` подтягивает склейки к долям по этому полю.

## Правила, которые проверяет скрипт

- Шоты идут по порядку, без дыр и наложений; шот не короче 0,4 с.
- У каждого шота есть `intent` и решение по камере.
- Удары лежат внутри своего шота.
- Надпись на экране не меньше времени чтения: около 3 слов в секунду плюс 0,4 с. Меньше 60 % — ошибка.
- Предупреждения: меньше двух слоёв; статика дольше 2,5 с, где ничего не движется; один переход на больше чем 60 % нешовных; три вип-пэна подряд; ролик длиннее 12 с без «вдоха»; все шоты одной длины; длинные строки в вертикали.
