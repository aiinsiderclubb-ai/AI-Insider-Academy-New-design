# Монтаж и ритм

Ролик выглядит дорого, когда склейки, удары и звук попадают в музыку с точностью до кадра, а ритм ведёт зрителя к кульминации. Этот скилл делает три вещи: размечает трек, подтягивает к нему раскадровку и собирает звуковой слой. Работу ведёт `cinematic-director`: он пишет раскадровку, ты превращаешь её в монтаж. Картинка собирается в проекте Remotion, звук сводится на финише в `grade-finish`.

Скрипты `beats.py`, `cutlist.py`, `sfx.py` — Python 3, только стандартная библиотека, плюс ffmpeg для чтения MP3/M4A. `match_cut.py` (подбор кадров для матч-ката) — Python + OpenCV и NumPy.

## Что нужно на входе

- Раскадровка `storyboard.json` из `cinematic-director` (формат — `cinematic-director/references/storyboard-format.md`).
- Трек и отрезок, который пойдёт в ролик. Права на музыку для коммерческого ролика — спроси явно. Нет трека — делай ритм без музыки: внутренний пульс 120 BPM (доля 0,5 с), звук целиком из `sfx.py`.

## Порядок работы

1. **Вырежи отрезок трека** — дальше всё считается от нуля ролика, без смещений:

   ```bash
   ffmpeg -ss 31 -t 15.5 -i track.mp3 -ar 48000 public/audio/cut.wav
   ```

   Бери на 0,5 с длиннее ролика — хвост уйдёт в затухание на финише.

2. **Разметь доли:**

   ```bash
   python3 scripts/beats.py public/audio/cut.wav --fps 30 --out public/data/beats.json
   ```

   В файле: `tempo`; `grid` — ровная сетка долей, подогнанная по всем ударам (темп с точностью до сотых, для склеек бери её); `beats` / `downbeats` — доли как их услышал трекер; `hits` — самые сильные всплески (сбивки, дропы); `beat_frames`, `grid.beat_frames` — те же доли в кадрах.

   Проверь темп. Детекторы часто ошибаются вдвое: быстрый трек получился 70 BPM — задай `--min-bpm 100 --max-bpm 180`. Сомневаешься — сделай щелчки и сравни на слух:

   ```bash
   python3 scripts/beats.py --make-click 128 15 click.wav
   ```

   Размер не 4/4 (вальс, 6/8) — `--meter 3`.

3. **Подтяни раскадровку к музыке:**

   ```bash
   python3 scripts/cutlist.py storyboard.json public/data/beats.json --out storyboard.synced.json --md cuts.md
   ```

   Правила: смена сцены (`transition_out.on: "downbeat"` или без `on`) уходит на ближайшую сильную долю, а если её нет в допуске — на любую долю. Акцент (`"beat"`) — на долю. `"free"` не трогается. Удары (`hits`) уходят на ближайший сильный всплеск или долю внутри своего шота. Конец ролика — на сильную долю.

   Допуск по умолчанию — полдоли. `--tolerance 0.3` — сильнее держать раскадровку. `--min-shot 0.4` — короче шот не станет. `--lead-frames 1` — склейка на кадр раньше доли: так глаз прочитает её точно в долю, для быстрого монтажа это норма.

   В таблице `cuts.md` смотри колонку «Сдвиг, кадров». Больше ±6 кадров — раскадровка спорит с музыкой: перепиши длительности, а не терпи. Строка «none in tolerance» значит, что рядом нет доли. Это допустимо только для `free`.

   Перепроверь итог: `python3 ../cinematic-director/scripts/storyboard.py storyboard.synced.json`.

4. **Перенеси времена в композицию.** В проекте всё в секундах: `Sequence2 at={…}`, `reveal={{ at: … }}`, `Flash at={…}`, `Burst at={…}`. Бери `start`/`end` и `hits[].t` из `storyboard.synced.json` как есть, без округления на глаз.

5. **Звук на переходы и удары:**

   ```bash
   python3 scripts/sfx.py --from-storyboard storyboard.synced.json --out-dir public/sfx --mix
   ```

   Получишь по файлу на каждый звук, `public/sfx/timeline.json` (где какой стоит и с каким уровнем) и `public/sfx/stem.wav` — все звуки на одной дорожке длиной в ролик. Этот стем идёт в `grade-finish/scripts/finish.py --sfx`. Какой звук куда и как сводить — [references/sound-design.md](references/sound-design.md).

   Отдельный звук под задачу:

   ```bash
   python3 scripts/sfx.py --kind whoosh --length 0.7 --pitch 1.2 --seed 4 --out public/sfx/extra-whoosh.wav
   python3 scripts/sfx.py --kind tick --count 3 --out public/sfx/hud-ticks.wav
   python3 scripts/sfx.py --all --out-dir sfx-preview/          # по одному каждого вида — послушать
   ```

   `--seed` — другой дубль того же звука: на повторных переходах меняй seed, чтобы вуши не были копиями. `--pitch 0.8` — темнее и тяжелее, `1.3` — легче и ярче.

6. **Проверь монтаж** после рендера: `cinema-review/scripts/review.py out/film.mp4 --beats public/data/beats.json` покажет, на сколько кадров каждая склейка ушла от доли.

## Приёмы монтажа

Грамматика — когда склейка, когда вип-пэн, как строить разгон к кульминации, J/L-склейки, smash cut, матч-кат, спид-рамп, переходы камерой. Всё это — в [references/editing-grammar.md](references/editing-grammar.md). Коротко о том, что есть в шаблоне:

- `Sequence2` из `src/layers/Transitions.tsx` — переход между двумя сценами: `kind` = `cut` | `whip` | `zoom` | `flash` | `fade`, `at` — середина перехода в секундах, `duration` — длина (вип 0,3–0,4 с, зум 0,35–0,5 с), `direction` — направление вип-пэна. Сцены рендерятся только в момент перекрытия, поэтому тяжёлое 3D не грузит соседние шоты.
- `speedRamp([[t, скорость, ease]…])` из `src/layers/Footage.tsx` — спид-рамп для футажа (`Plate`, `Cutout`, `Pinned` принимают его в `remap`). Есть также `freezeAt` (стоп-кадр) и `reverse`.
- `Flash`, `LightLeak` из `src/layers/Finish.tsx` — вспышка 2–4 кадра на ударе и световой засвет между сценами.
- Переход камерой — пролёт `Stage` сквозь объект или облёт за него (`cutBetween`, `orbit`, `dolly` из `src/three/camera.ts`). Это самый дорогой по ощущению переход; подробности — в `camera-language`.

## Правила

- Склейка по умолчанию — просто склейка, в долю. Эффектный переход — только там, где меняется место или энергия. Не больше трети переходов в ролике должны быть эффектными.
- Смена сцены — на сильную долю, акцент и удар текста — на долю или сильный всплеск. Мимо доли больше 2 кадров зритель чувствует как «не в такт».
- Темп монтажа растёт к кульминации: длинный первый шот (2–4 с), потом короче, серия в 1–2 доли перед главным ударом, после удара — финальный шот подольше.
- Ни один удар без звука, ни один звук без события в кадре.
- Не ставь вуш на каждую склейку — слой звука становится кашей. Чистые склейки в долю звучат музыкой.
- Если пользователь дал свой трек, не меняй его темп и не режь посреди такта: обрезай по сильным долям.
- Найденные доли и итоговый `cuts.md` покажи пользователю до финального рендера.
