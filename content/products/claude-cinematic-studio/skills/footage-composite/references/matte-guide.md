# Маски: какой режим когда

`matte.py` пишет `matte/` (серая маска) и `cutout/` (RGBA). Имя папки вырезки меняет `--out-name`: удобно, чтобы сравнить пробу с готовой вырезкой. `--frames 1-30` — пробный прогон на куске.

| Что в кадре | Режим | Ожидай |
|---|---|---|
| Съёмка на зелёном или синем фоне | `key` | лучший край, волосы и прозрачное сохраняются |
| Светлый объект на тёмном фоне (или наоборот) | `luma` | мгновенно, край по яркости |
| Человек на любом фоне | `person` + модель | силуэт людей; волосы мягкие, пальцы иногда теряются |
| Продукт, предмет, что угодно цельное | `object` + рамка | цельный силуэт, дыры заливаются; ~0,6 с на кадр 1080p |
| Тонкое, сетчатое, прозрачное без хромакея | вручную (ниже) | — |

## key — хромакей

```bash
python3 scripts/matte.py public/footage/hero --mode key --color 0,177,64 --tolerance 18 --softness 22 --choke 1 --feather 2
```

- `--color R,G,B` — цвет фона. Возьми его с кадра: пипеткой или средним цветом угла плейта.
- `--tolerance` — насколько далёкий от фона цвет ещё считается фоном (дистанция по цветности YCrCb). Видны куски фона — подними; съедает объект — опусти.
- `--softness` — ширина мягкого перехода. Для волос 25–35.
- Зелёный отсвет на краях снимается автоматически (despill).
- Синтетический тест: IoU с эталоном 0,999.

## luma — по яркости

```bash
python3 scripts/matte.py public/footage/hero --mode luma --low 0.1 --high 0.25 --keep-largest --fill-holes
```

Пиксели темнее `--low` — фон, светлее `--high` — объект, между ними мягкий переход. `--invert` — для тёмного объекта на светлом. `--keep-largest` выбрасывает блики и пятна, оставляя самое большое пятно, `--fill-holes` заливает тёмные места внутри объекта.

## object — GrabCut по рамке

```bash
python3 scripts/matte.py public/footage/hero --mode object --box 0.25,0.2,0.52,0.6 --smooth 3
python3 scripts/matte.py public/footage/hero --mode object --box 0.3,0.2,0.4,0.7 --track public/footage/hero/track-product.json
```

- `--box x,y,w,h` — рамка вокруг объекта на первом кадре, доли кадра от левого верхнего угла. Бери с запасом 5–10 %: всё, что не попало в рамку, считается фоном.
- Дальше каждый кадр начинается с маски предыдущего. Объект быстро уезжает или камера летит — дай `--track` из `track.py`, и рамка поедет за ним.
- Дыры внутри объекта заливаются всегда. Поэтому режим — для цельных предметов, не для кружева и волос.
- Демо-телефон из Blender: IoU с настоящей альфой 0,993 на 180 кадрах.

## person — люди

```bash
python3 scripts/matte.py public/footage/talk --mode person --model models/selfie_segmenter.tflite --feather 2 --smooth 5
```

Нужен файл модели MediaPipe Image Segmenter, он не входит в набор. Пусть пользователь скачает его со страницы https://ai.google.dev/edge/mediapipe/solutions/vision/image_segmenter (раздел Models):

- `selfie_segmenter.tflite` — один человек крупно, быстро;
- `selfie_multiclass_256x256.tflite` — точнее по силуэту и волосам, скрипт сам берёт «всё, кроме фона».

Положи в `models/` проекта и передай путь в `--model`. Без файла скрипт остановится и скажет, где его взять. Модель тренирована на селфи: на дальних планах и группах людей края хуже — там лучше хромакей или ручная маска.

## Края

| Что видно | Флаг |
|---|---|
| Светлая или тёмная кайма — остатки фона | `--choke 1` (2 — для сжатых видео) |
| Край рваный, «лесенка» | `--feather 2` |
| Край дрожит от кадра к кадру | `--smooth 3` (5 — для статичного объекта) |
| Рядом с объектом висят мелкие пятна | `--keep-largest` (key, luma) |
| Дыры внутри объекта | `--fill-holes` (key, luma, person) |
| Объект «похудел» | `--choke -1` расширяет маску |

`--smooth` — медиана по соседним кадрам: убирает дрожь, но на быстром движении край отстаёт. Больше 5 не ставь.

После скрипта смотри его вывод. Строка «largest frame-to-frame change» больше 2 % кадра — там маска сломалась. Открой этот кадр в `matte/`.

## Когда маску рисовать руками

Скрипт не справится, если:

- волосы на пёстром фоне без хромакея, мех, дым, стекло, вода;
- объект сливается с фоном по цвету и яркости;
- нужна маска только части объекта (одна рука, крышка, а не вся бутылка).

Тогда предложи пользователю ротоскоп в After Effects (Roto Brush), DaVinci Resolve (Magic Mask) или Runway. Попроси экспорт — PNG-секвенцию с альфой. Положи её как `public/footage/<name>/cutout/frame_00001.png` с теми же номерами, что у плейта, — композиция примет её без правок.
