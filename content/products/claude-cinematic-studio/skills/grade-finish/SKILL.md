# Грейд и финиш

Здесь рендер становится мастером. Три вещи чаще всего отличают кадр Remotion от кадра студии: размытие движения, цвет и плёночная фактура. Ещё одна — звук, сведённый в громкость площадки. Всё это делает `scripts/finish.py` одной командой. Каждый шаг — фильтр ffmpeg, а скрипт печатает точную команду, чтобы проход можно было повторить или подправить руками.

Работу ведёт `cinematic-director`. Сюда приходит готовая композиция и звуковой стем из `cut-rhythm`, отсюда мастер уходит в `cinema-review`.

Python 3, только стандартная библиотека; нужны ffmpeg и ffprobe.

## Порядок работы

1. **LUT-ы для проекта** — один раз:

   ```bash
   python3 scripts/make_luts.py --out luts/
   python3 scripts/make_luts.py --out luts/ --preview out/still.png   # до/после на кадре ролика
   ```

   Кадр для превью: `npx remotion still TechFilm out/still.png --frame=150`. Какой LUT под какой стиль и в какой силе — [references/color.md](references/color.md). `--list` — описание всех шести. `--size 65` — сетка мельче, для сильных градиентов.

2. **Финальный рендер на учетверённой частоте** — для настоящего моушн-блюра (подробно — [references/motion-blur.md](references/motion-blur.md)):

   ```bash
   npx remotion render TechFilm out/tech@120.mov --props '{"fps":120}' --codec=prores --prores-profile=hq
   ```

   Любая композиция проекта читает частоту из `props.fps` (через `calculateMetadata`), а время в сценах задано в секундах, поэтому фильм рендерится на 120 без правок. Стоит это вчетверо дольше, поэтому сначала утверди черновик на 30 fps.

   Нет времени на 4× — рендер на 30 и финиш без `--motion-blur`.

3. **Финиш:**

   ```bash
   python3 scripts/finish.py out/tech@120.mov --motion-blur --target-fps 30 --shutter 180 \
     --lut luts/cyber-cool.cube --lut-mix 0.8 --halation --grain 4 --vignette 0.4 \
     --music public/audio/cut.wav --sfx public/sfx/stem.wav --duck \
     --out out/tech-master.mp4 --web --crop 9x16 --focus 0.5
   ```

   Что получится:
   - `tech-master.mp4` — H.264 High, CRF 14, yuv420p, faststart;
   - `tech-web.mp4` — CRF 21, до 8 Мбит/с, для сайта и Telegram;
   - `tech-9x16.mp4` — 1080×1920.

   Мастер для монтажки или эфира — `--prores` (ProRes 422 HQ, 10 бит, .mov).

   Проверить заранее, что запустится: `--dry-run` печатает команды и ничего не делает.

4. **Звук** считается сам, если дан `--music` и/или `--sfx`:
   - отдельные уровни: `--music-db` (по умолчанию −3) и `--sfx-db` (0);
   - `--duck` — музыка проседает под ударами;
   - `--keep-audio` — оставить звук самого рендера;
   - итог приводится к `--lufs` (−14) с потолком true peak −1 dBTP.

   В ответе — замер до и после. Предупреждение «could not reach» значит, что материал слишком пиковый: громкость упёрлась в лимитер. Опусти `--sfx-db` на 2–3 dB или возьми трек со сжатой динамикой.

5. **Проверка** — обязательно, перед тем как показать: `cinema-review/scripts/review.py out/tech-master.mp4 --beats public/data/beats.json`.

## Шаги finish.py

| Флаг | Что делает | Стартовое значение |
|---|---|---|
| `--motion-blur --target-fps 30 --shutter 180` | Усредняет подкадры, пока «открыт затвор» | 180° — норма кино |
| `--lut FILE --lut-mix 0.8` | 3D LUT, смешанный с оригиналом | 0,6–0,85 |
| `--halation --halation-strength 0.35` | Тёплый красно-оранжевый ореол вокруг ярких краёв, как на плёнке | 0,2–0,4 |
| `--glow --glow-strength 0.25` | Нейтральное свечение ярких мест | Только для футажа, у 3D свой bloom |
| `--grain 6` | Зерно по яркости, меняется каждый кадр, повторяемо (`--seed`) | 3–8 |
| `--vignette 0.4` | Затемнение углов, радианы | 0,3–0,5 |
| `--letterbox 2.39` | Чёрные полосы под киноформат | Не если в композиции уже есть `Letterbox` |
| `--crop 9x16 / 1x1 / 4x5 --focus 0.5` | Копии под соцсети, центр кадра 0–1 | По главному объекту |

Порядок внутри фильтра фиксированный и правильный: блюр → LUT → халация → свечение → виньетка → зерно → полосы → yuv420p.

## Что уже есть в кадре из шаблона

Композиции проекта уже накладывают часть финиша, и дважды его делать нельзя:

- **Bloom, глубина резкости, хроматическая аберрация, виньетка, тональная кривая AgX** — внутри `Stage` (`src/three/Stage.tsx`), сила задаётся стилем в `src/lib/looks.ts`. `--glow` поверх 3D-сцены не нужен.
- **Зерно** — `Grain` из `src/layers/Finish.tsx`, сила `look.post.grain` (0,05–0,12). На финише добавляй к нему не больше `--grain 4`; для композиций с футажом (`FootageFX`) — 6–8, чтобы склеить 3D и видео одной фактурой.
- **Кашетирование** — `Letterbox` в `HeroTitle` (2.39) и `TechFilm` (2.2). Для них `--letterbox` не задавай.
- **Вспышки и засветы** (`Flash`, `LightLeak`) — часть монтажа, не финиша.

## Кропы

Вертикаль из горизонтального мастера — компромисс: текст на краях обрежется. Если ролик главным образом для Reels и TikTok, собирай вертикальную композицию (`KineticSpot`, `FootageFX` — 1080×1920) и финишируй её отдельно. Кроп из 16:9 годится для вторичных площадок. `--focus` ставь по главному объекту: 0,5 — центр, 0,35 — левее. С `--letterbox` кропы получают полосы, и скрипт об этом предупредит. Для соцсетей сделай второй проход без `--letterbox`. Спецификации площадок — [references/delivery.md](references/delivery.md).

## Правила

- Мастер делай только с финального рендера, утверждённого по черновику. Финиш не исправляет монтаж.
- Не перезаписывай прошлый мастер: `tech-master-v2.mp4`.
- Grain и halation в меру: если пользователь замечает эффект, значит перебор. Цель — «как снято», а не «с фильтром».
- LUT подбирай на кадре ролика (`--preview`), а не на тестовой таблице. Один LUT на весь ролик.
- Размытие движения только из рендера на 4×. Не имитируй его `tblend` или `minterpolate` по 30 fps: получатся двоения.
- Громкость не правь на слух — только по замеру скрипта и `cinema-review`.
- Покажи пользователю кадр «до/после» грейда и итог замера громкости.
