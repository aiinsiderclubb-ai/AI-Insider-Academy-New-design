# Типографика в пространстве

Текст здесь — не наклейка поверх видео, а объект сцены: у него есть толщина, фаска, материал, он отражает студийный свет, попадает в глубину резкости и закрывается предметами, которые стоят ближе к камере. Работаешь в проекте Cinematic Studio; если его нет — сначала шаг «Проект» скилла `cinematic-director`.

Компоненты лежат в `src/three/`: `Type3D.tsx` (выдавленный текст, побуквенная анимация), `RingType.tsx` (текст по кольцу), подписи HUD — через `Type3D` моноширинным шрифтом. Всё это ставится только внутрь `<Stage>` (`src/three/Stage.tsx`).

## Что нужно на входе

- Текст: заголовок, подзаголовок, подписи. Решай иерархию до анимации.
- Стиль (look) — из `cinematic-director`: `keynote`, `chrome`, `kinetic`, `neon`, `editorial`. Он задаёт шрифты и материал букв.
- Формат кадра (16:9 или 9:16) и расстояние камеры — от них зависит размер букв ([references/sizing.md](references/sizing.md)).
- Музыка с долями, если удары текста должны попадать в такт (скилл `cut-rhythm`).

## Порядок работы

1. **Иерархия.** Максимум три уровня в кадре: кикер (мелко, разрядка), заголовок (крупно), подзаголовок (средне, текстовым шрифтом). Заголовок — 1–3 слова.
2. **Размер от камеры, а не на глаз.** Посчитай видимую высоту кадра на дистанции текста: `h = 24 · d / мм` (для `lens(мм)` в `src/three/camera.ts`). Высота прописных заголовка — 9–16 % высоты кадра 16:9. В 9:16 решает ширина: строка занимает 70–85 % ширины кадра. Широкий `unbounded-800` в вертикали почти всегда надо делать в 2 раза мельче, чем кажется. Таблицы и метрики шрифтов — [references/sizing.md](references/sizing.md).
3. **Движение.** Выбери пресет из `REVEALS` / `EXITS` и подправь одно-два поля. Каталог и когда что — [references/type-moves.md](references/type-moves.md).
4. **Время.** Каждая строка должна простоять в кадре после появления не меньше `0,4 с + 1 с на 3 слова`. Подсчитай до рендера.
5. **Пространство.** Поставь текст на свою глубину: заголовок в фокусе, кикер чуть ближе или дальше, объекты проходят перед и за ним. Готовые сборки — [references/recipes.md](references/recipes.md).
6. **Проверка кадрами.** Отрендерь 3–4 стоп-кадра с `--scale=0.5` на ключевых моментах (середина появления, удержание, уход) и посмотри на них, прежде чем рендерить ролик:

   ```bash
   npx remotion still HeroTitle out/check-60.png --frame=60 --scale=0.5
   ```

## Type3D — что можно настроить

```tsx
import { Type3D, REVEALS, EXITS } from "../three/Type3D";

<Type3D
  text={"НОВАЯ ЭРА"}          // "\n" — новая строка, строки центрируются
  look={look}
  font={look.font.display}    // ключ из src/lib/fonts.ts; по умолчанию display стиля
  size={0.56}                 // кегль в единицах сцены (em)
  depth={0.26}                // толщина выдавливания
  bevel={0.025}               // фаска; 0 — без фаски
  tracking={0.01}             // разрядка в долях кегля
  lineHeight={1.15}
  position={[0, 0, 0]}
  rotation={[0, 0, 0]}        // градусы
  reveal={{ at: 0.6, ...REVEALS.riseFromDepth, stagger: 0.06 }}
  exit={{ at: 6.8, ...EXITS.intoDepth }}
  wobble={0.01}               // тихое «дыхание» букв после посадки
  maxWidth={5.4}              // самая длинная строка не шире этого (единицы сцены): длинный текст ужмётся
  // переопределения материала стиля:
  color="#ffffff" emissive="#38f0ff" emissiveIntensity={0.4} metalness={1} roughness={0.2}
/>
```

Каждая буква — отдельный меш с центром в себе, поэтому буквы вращаются и летят по отдельности. Буква с прозрачностью < 0,001 не рисуется.

**`maxWidth` ставь всегда, когда текст приходит от пользователя.** Это ширина видимой части кадра на дистанции текста минус поля: для 16:9 — `h · 16/9 · 0,8`, для 9:16 — `h · 9/16 · 0,85`, где `h` — видимая высота из шага 2. Длинное слово или широкий шрифт тогда ужмётся и не вылезет за край — ни при одной правке текста. В шаблоне: HeroTitle 5,4, TechFilm 5–5,2, KineticSpot 2,2–2,3, FootageFX 2,4.

### Толщина и фаска: дорого или дёшево

| Роль | `size` | `depth` | `bevel` | `tracking` |
|---|---|---|---|---|
| Герой-заголовок | 0,5–1,0 | 0,4–0,5 × size | 0,04–0,05 × size | −0,02…0,02 |
| Слово-удар (kinetic) | 0,8–1,1 | 0,5 × size | 0,03 | −0,01 |
| Подзаголовок | 0,16–0,24 | 0,01 | 0 | 0,02–0,06 |
| Кикер капсом | 0,12–0,18 | 0,01 | 0 | 0,25–0,4 |
| HUD / моно | 0,05–0,2 | 0,002–0,004 | 0 | 0–0,3 |

Дёшево выглядят: толщина больше кегля («кирпичи»), фаска больше 6 % кегля (буквы «надуваются»), мелкий текст с толщиной (боковины шумят), разрядка у крупного заголовка больше 0,05.

### Материал

Материал по умолчанию берётся из стиля (`look.type`): titanium в `keynote`, зеркальный хром в `chrome`, матовый в `kinetic`, светящийся край в `neon`, золото в `editorial`. Металл читается только благодаря отражениям студийных полос, которые `Stage` двигает по сцене (`stripSweep`). Поэтому:

- Не делай металлический текст строго анфас и неподвижным — поверни на 5–15° (`rotation`) или дай камере сдвинуться: блик должен пройти по буквам.
- Акцентное слово выделяй цветом (`color={look.accent}`), а не другим шрифтом.
- Светящиеся подписи (HUD): `color="#000000"`, `emissive={look.accent}`, `emissiveIntensity` 1,5–2,5. Свечение даёт bloom, не белая краска.
- В `neon` у букв уже есть слабое собственное свечение (0,18). Не поднимай выше 0,4 у заголовка — пропадёт объём.

## Шрифты

В проекте пять шрифтов, все с кириллицей, все ставятся через npm (лицензия SIL OFL — можно в коммерческих роликах):

| Ключ | Шрифт | Для чего |
|---|---|---|
| `inter-tight-800` | Inter Tight ExtraBold | Чистый продуктовый заголовок, Apple-подобный |
| `inter-tight-500` | Inter Tight Medium | Подзаголовки, кикеры |
| `unbounded-800` | Unbounded ExtraBold | Широкий гротеск: техно, спорт, бренды |
| `jetbrains-500` | JetBrains Mono Medium | HUD, цифры, подписи интерфейса |
| `playfair-900` | Playfair Display Black | Кино, редакционный стиль, люкс |

Новый шрифт:

1. Только статический TTF или OTF нужного начертания: у вариативного шрифта загрузчик возьмёт начертание по умолчанию. Проверь, что лицензия разрешает коммерческое использование и что в шрифте есть кириллица.
2. Из npm: `npm install --save-exact @expo-google-fonts/<семейство>@<версия>`. В пакете файлы лежат по пути `<вес>/<Имя>_<вес>.ttf`.
3. Свой файл: положи в `src/fonts/` и импортируй так же.
4. Добавь ключ в `src/lib/fonts.ts`:

   ```ts
   import manrope800 from "@expo-google-fonts/manrope/800ExtraBold/Manrope_800ExtraBold.ttf";
   // …
   export const FONTS = { /* … */ "manrope-800": manrope800 } as const;
   ```

   Тип `FontName` обновится сам, после этого `font="manrope-800"` работает в `Type3D` и `RingType`.

Кернинг из TTF не применяется: буквы ставятся по ширине глифа. В крупных заголовках проверяй пары вроде «ГА», «ТА», «AV», «LT». Если зазор режет глаз, уменьши `tracking` или перепиши слово.

## RingType — текст по кольцу

```tsx
<RingType text="ИСКУССТВЕННЫЙ ИНТЕЛЛЕКТ" look={look} radius={2.3} size={0.3} speed={22}
          tilt={[12, 0, -8]} appear={0.4} glow={0.35} />
```

`repeat="auto"` (по умолчанию) берёт целое число копий текста, ближайшее к длине окружности, и выравнивает шаг: кольцо замыкается без дыры и без наезда. Не ставь `repeat` вручную больше, чем помещается: буквы налезут друг на друга, и сквозь ближнюю дугу станет видна зеркальная дальняя. Ближняя дуга читается слева направо, кольцо крутится как бегущая строка. Буквы дальней дуги закрывает сам объект — это и есть кадр «текст уходит за предмет», без масок. Второе кольцо: моноширинный шрифт, `size` 0,12–0,16, обратная `speed`, наклон в другую сторону.

## Правила

- Один герой на кадр. Два крупных 3D-слова одновременно — только если это приём (контраст «ДО / ПОСЛЕ»).
- Каждая буква появляется со сдвигом (`stagger` 0,03–0,07 с). Целый блок, появившийся одним кадром, выглядит как шаблон.
- Удержание живое: `wobble` 0,005–0,015, движение камеры или бликов. Полностью неподвижный текст дольше 1,5 с — признак «AI-видео».
- Уход обязателен и короче появления (0,5–0,8 с против 0,9–1,2 с). Текст, который просто исчезает на склейке, — ошибка, кроме намеренного smash cut.
- Подзаголовок появляется через 0,6–2,5 с после заголовка, не одновременно с ним.
- Капс — у заголовков и кикеров. Подзаголовок пиши строчными, предложением.
- Текст в 9:16 держи в центральных 80 % ширины и вне нижних 20 % высоты (там интерфейс Reels/TikTok).
- Точка в конце заголовка не ставится.

## Типичные ошибки «AI-вида» и что делать

| Ошибка | Исправление |
|---|---|
| Все буквы плавно проявляются по прозрачности | Появление через глубину или поворот (`riseFromDepth`, `flip`), прозрачность — только вспомогательная |
| Линейное движение | Пресеты уже на `expoOut` / `snap` / `silk`. Не ставь `ease: "linear"`, кроме печатной машинки HUD |
| Белый плоский текст без света | Металл или матовый материал стиля, поворот к свету, движение бликов |
| Текст размером «во весь кадр» без воздуха | Поля минимум 8 % ширины по бокам |
| Текст не взаимодействует со сценой | Кольца и частицы проходят перед буквами, объект закрывает часть надписи, буквы в фокусе, фон размыт |
| Одинаковое появление у всех строк | Заголовок — `riseFromDepth`, кикер — простой подъём, подзаголовок — `flip` с малым углом |

## Связанные скиллы

- `cinematic-director` — бриф, стиль, раскадровка и сборка целиком.
- `camera-language` — как камера двигается вокруг текста.
- `vfx-toolkit` — кольца, частицы, свечение вокруг букв.
- `footage-composite` — текст за человеком или предметом на реальном видео.
- `cut-rhythm` — удары слов в доли музыки.
