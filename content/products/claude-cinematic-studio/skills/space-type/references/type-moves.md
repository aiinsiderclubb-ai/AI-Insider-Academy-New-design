# Движения букв: пресеты и свои

Все движения описываются одним типом `LetterMove` из `src/three/Type3D.tsx`:

```ts
interface LetterMove {
  at: number;                 // секунда начала (для первой буквы в порядке order)
  duration?: number;          // длительность движения одной буквы, по умолчанию 1
  stagger?: number;           // задержка между буквами, по умолчанию 0.04
  order?: "left" | "right" | "center" | "edges" | "random";
  ease?: EaseName | Ease;     // по умолчанию "expoOut"
  pose: Partial<Pose>;        // откуда буква приходит (reveal) или куда уходит (exit)
}

interface Pose { x; y; z; rx; ry; rz; scale; opacity }   // смещения от места покоя; углы в градусах
```

- В `reveal` буква начинает в `pose` и приходит в покой.
- В `exit` буква уходит из покоя в `pose`.
- `reveal` и `exit` складываются: можно уйти, ещё не до конца прилетев. Не делай так без умысла.
- Порядок: `left` — слева направо; `right` — справа налево; `center` — от середины к краям; `edges` — от краёв к середине; `random` — случайно, но одинаково при каждом рендере.
- Полное время появления слова = `duration + stagger × (букв − 1)`. Для слова из 9 букв с `riseFromDepth` и `stagger: 0.06` это 1,1 + 0,48 ≈ 1,6 с. Учитывай при расчёте удержания.

## Появления (REVEALS)

| Пресет | Параметры | Ощущение | Когда | Когда нет |
|---|---|---|---|---|
| `riseFromDepth` | 1,1 с, stagger 0,045, expoOut; z −2,5, y −0,4, rx 55°, opacity 0 | Буквы всплывают из темноты и ложатся на место. Дорого, спокойно | Герой-заголовок, продуктовый запуск, финальный титр | Быстрый монтаж под бит |
| `flip` | 0,9 с, 0,05, quintOut; rx −100°, y 0,25 | Табло-перекидка в 3D. Механично, точно | Цифры, названия функций, подзаголовки (тогда угол меньше: rx −30…−45) | Длинные строки — вращение рябит |
| `flyIn` | 0,7 с, 0,03, random, snap; z +6, scale 1,6 | Буквы прилетают из-за камеры и врезаются в кадр | Удар на долю, спорт, «вау»-слово | Спокойные стили (`editorial`, `keynote`) |
| `swing` | 1 с, 0,04, silk; ry −80°, x −0,3 | Буквы поворачиваются, как двери | Переход от одной мысли к другой, второй заголовок | Если камера тоже орбитит в ту же сторону — движения гасят друг друга |
| `burst` | 0,8 с, 0,035, center, backOut; scale 0 | Вырастает от центра с лёгким перелётом | Короткие слова, логотип-надпись, финальный бренд | Слова длиннее 8 букв |

## Уходы (EXITS)

| Пресет | Параметры | Когда |
|---|---|---|
| `intoDepth` | 0,8 с, 0,03, expoIn; z −4 | Конец спокойного кадра, перед затемнением или новым титром |
| `pastCamera` | 0,6 с, 0,02, center, expoIn; z +7, scale 1,4 | Перед склейкой на долю: последняя буква проходит сквозь камеру, склейка в момент, когда кадр заполнен |
| `fall` | 0,9 с, 0,035, random, launch; y −3, rx 70° | Разрушение, «ломаем старое», ироничный уход |

Уход начинай за `duration` до склейки. Для `pastCamera` перед склейкой на 7,2 с: `at = 7.2 − 0.6 = 6.6`.

## Свои движения

Распакуй пресет и поменяй одно-два поля. Так ритм остаётся профессиональным:

```tsx
// Подзаголовок: тот же flip, но мягче и быстрее
reveal={{ at: 3.4, ...REVEALS.flip, duration: 0.7, stagger: 0.02, pose: { rx: -35, y: 0.12, opacity: 0 } }}

// Слово падает сверху с инерцией и раскачкой: своя кривая
import { bezier } from "../lib/curves";
reveal={{ at: 1.2, duration: 0.9, stagger: 0.05, ease: bezier(0.2, 1.4, 0.4, 1), pose: { y: 2.2, rz: -12, opacity: 0 } }}

// Выход в разные стороны от центра: разные z по порядку не нужны — order "edges" + сильный z
exit={{ at: 5.1, duration: 0.5, stagger: 0.025, order: "edges", ease: "expoIn", pose: { z: 5, scale: 1.3, opacity: 0 } }}

// HUD-печать: линейно и очень коротко, буква за буквой
reveal={{ at: 2.3, duration: 0.05, stagger: 0.03, ease: "linear", pose: { opacity: 0 } }}
```

Ориентиры для своих значений:

- `stagger`: 0,02–0,03 — быстро, единым жестом; 0,04–0,06 — читается волна; больше 0,08 — каждая буква отдельно, только для 2–5 букв.
- `duration` одной буквы: 0,3–0,5 — удар; 0,7–1,2 — премиальная посадка; больше 1,4 — вязко.
- Расстояние: z до −3 от покоя — приход из глубины; больше −4 — буквы долго «невидимы», кажется, что ничего не происходит.
- Угол: 30–60° для поворотов. Около 90° буква становится ребром и пропадает. Это хорошо для `flip`, плохо для `swing` у узких букв.

## Ритм внутри титра

- Кикер появляется первым (0,3 с), заголовок — через 0,2–0,4 с после него, подзаголовок — когда заголовок полностью сел (+1,5–2,5 с).
- Уходят в обратном порядке или все разом, но короче, чем приходили.
- Под музыку: начало заголовка (`at`) ставь на долю, а не его окончание. Последняя буква садится на следующую долю, если `duration + stagger × n` ≈ длина доли.
