# Скорость рендера

3D-кадр с пост-обработкой стоит в десятки раз дороже 2D-кадра Remotion. Ролик на 12 с при 30 к/с — 360 кадров, при рендере ×4 для motion blur — 1440. Планируй, во что обходится каждый эффект, и делай черновики дёшево.

## Замерь, а не гадай

```bash
time npx remotion render TechFilm out/probe.mp4 --frames=60-89 --scale=0.5
```

30 кадров при половинном размере: делишь время на 30, умножаешь на ~3 (полный 1080p) и на число кадров ролика. Сборка бандла (первые 5–15 с) в каждый запуск — не путай её с рендером.

## Относительная стоимость эффектов

Отсчёт от пустого `Stage` со светом и всей пост-обработкой стиля (1×):

| Элемент | Цена | Почему |
|---|---|---|
| `Type3D` заголовок (10–15 букв) | +0,1× | Геометрия строится один раз, дальше дёшево |
| `RingType` | +0,2× | 40–80 мешей |
| `Rings`, `GridFloor`, `Streaks`, `LightTrail`, `HudReticle` | +0,05–0,15× | Линии и простая геометрия |
| `Dust` 900, `Burst` 300 | +0,1× | Точки, но позиции считаются каждый кадр на CPU |
| `MirrorFloor` | +0,6× | Сцена рендерится второй раз для отражения |
| `GlassCore` | +1–1,5× | Сцена рендерится в буфер для преломления, 6 сэмплов |
| `Model` | от +0,1× до +2× | Зависит от полигонов: держи меньше 300–500 тыс. |
| DepthOfField | ~0,3× | Отключается при `bokeh: 0` |
| Окружение `Environment` (frames = ∞) | ~0,3× | Кубическая карта переснимается каждый кадр, чтобы полосы двигались |

Тяжёлая пара — `GlassCore` + `MirrorFloor` в одном кадре: рендер ×3. Выбери одно.

## Черновики

- Проверка кадра: `npx remotion still <Comp> out/x.png --frame=N --scale=0.5`.
- Черновик движения: `--scale=0.5`, 30 к/с, только нужный кусок: `--frames=90-180`.
- Контактный лист для показа — `cinema-review`.
- Финал: полный размер, затем рендер ×4 для motion blur (`--props='{"fps":120}'`) и `grade-finish`.

## Настройки рендера (remotion.config.ts)

- `Config.setChromiumOpenGlRenderer("angle")` — WebGL на видеокарте под macOS и Windows. На Linux-сервере без GPU поставь `"swangle"`: программный рендер работает, но в 5–20 раз медленнее. Тяжёлые сцены (стекло, зеркальный пол) лучше рендерить на машине с видеокартой.
- `Config.setConcurrency(2)` — две вкладки делят одну видеокарту. На мощной карте попробуй 3–4 и замерь. Больше вкладок, чем «тянет» GPU, только замедляет из-за переключения контекстов.
- `Config.setVideoImageFormat("png")` — без JPEG-артефактов на свечении и тёмных градиентах. Чуть медленнее, оставь.

## Контексты WebGL

Каждый `<Stage>` — отдельный WebGL-контекст с собственной пост-обработкой. Браузер держит ограниченное число контекстов (около 16) и при переполнении молча теряет самый старый — кадр становится чёрным.

- Сцены монтируй через `Sequence2` или `<Sequence>` Remotion: в каждый момент существуют только кадры на экране, а во время перехода — два.
- Не ставь несколько `Stage` одновременно ради «слоёв». Всё 3D одного кадра — в один `Stage`. Исключение — прозрачный `Stage` над футажом.
- Несколько камер в одной сцене — `cutBetween`, а не несколько `Stage`.

## Если кадр рендерится больше 10 секунд

1. Убери `GlassCore` или `MirrorFloor` из кадров, где их почти не видно.
2. Уменьши `Dust` до 400–500 и `Burst` до 150–200.
3. Упрости модель клиента в Blender (Decimate до 200–300 тыс. полигонов).
4. Для кадров без металла уменьши `look.light.strips` в копии стиля.
5. Длинный статичный 3D-фон можно отрендерить один раз роликом и подложить как футаж (`footage-composite`), а живой оставить только передний план.
