# Claude Motion Studio

Восемь скиллов для Claude Code, Claude Cowork и Codex и готовый проект Remotion. Вместе они делают моушн-дизайн кодом: кинетическую типографику, промо по скриншотам, анимированные графики, субтитры по словам, анимацию логотипа — и монтируют под музыку.

## Как это работает

Remotion собирает видео из React-компонентов: каждый кадр — функция времени, рендер одинаковый при каждом запуске. В наборе — проект, где уже написаны сцены, движения и восемь стилей. Агент не рисует анимацию с нуля: он выбирает стиль, пишет раскадровку, заполняет props сцены своими текстами и данными, рендерит черновик и смотрит на кадры, прежде чем показать вам.

Скрипты на Python делают то, в чём модель ошибается:

- цифры для графика читаются и считаются из CSV, а не перепечатываются;
- время слов в субтитрах берётся из расшифровки;
- доли и темп музыки находятся по звуку;
- время на чтение каждой надписи проверяется до рендера;
- готовый ролик проверяется на кодек, громкость и безопасные зоны Reels, TikTok и Shorts.

Скрипты — Python 3 без сторонних библиотек.

## Что внутри

| Скилл | Что делает | Скрипт |
|---|---|---|
| `motion-director` | Бриф → стиль → раскадровка → сборка → проверка. Создаёт проект из шаблона | Новый проект; проверка тайминга и привязка к долям |
| `kinetic-type` | Вертикальный текстовый ролик: подъём строк, удар слова, разрядка, эхо, печать, плашка | — (тайминг из `motion-director`) |
| `product-promo` | Промо сайта по настоящим скриншотам: окно, курсор, наезд, выноски | Скриншоты через установленный Chrome |
| `data-story` | График из таблицы: столбцы или линия, счётчик, скобка изменения | Чтение и проверка CSV, шкала, факты |
| `captions-explainer` | Субтитры по словам поверх видео, картинки или графики | SRT / VTT / JSON → тайминг по словам |
| `logo-sting` | Интро и аутро: логотип прорисовывается, рядом поднимается название | Подготовка SVG |
| `beat-sync` | Монтаж под музыку | Темп, доли, сильные доли |
| `render-review` | Рендер, копия для сайта, проверка | Рендер; контактный лист, кадры, кодек, громкость, безопасные зоны |

Подробно о каждом, с примерами запросов, — в `SKILLS.md`. Установка — в `INSTALL.md`.

## Проект Remotion

Лежит в `skills/motion-director/template/` и копируется скриптом `new_project.py`.

- **Семь композиций:** `KineticType` и `Captions` (1080×1920), `ProductPromo`, `DataStory` (столбцы), `DataStoryLine` (линия), `LogoSting`, `StyleBoard` (1920×1080).
- **Восемь стилей**, каждый — палитра, шрифты с кириллицей, кривые движения, фактура: Signal, Swiss Grid, Editorial, Terminal, Bold Kinetic, Data Noir, Print Riso, Quiet Line. Стиль меняется одним полем в props.
- **Библиотека движений:** маски, плашки, удар, разрядка, печать, счётчик, столбцы, линия, окно браузера, телефон, курсор, выноски, субтитры, шторки, зерно, сетка.
- Версии закреплены: Remotion 4.0.546, React 19.2.9, TypeScript 5.9.3.

Примеры роликов, сделанных этим проектом без правок кода, — на странице продукта.

## С чего начать

1. Установите по `INSTALL.md` — 5 минут вместе с Node.js и ffmpeg.
2. Попросите агента: «Сделай рилс на 10 секунд из этого текста: …». Он создаст проект, предложит стиль и раскадровку.
3. Посмотрите контактный лист черновика, который он покажет, и скажите, что поменять.

## Требования

- Claude Code, Claude Cowork или Codex — любой агент, который понимает формат Agent Skills и может запускать команды. Для рендера нужен компьютер, а не только чат: в облачной среде без Node.js видео не соберётся.
- Node.js 18 или новее и около 1 ГБ на диске (пакеты Remotion и Chrome для рендера).
- ffmpeg — для проверки, копий для сайта и чтения музыки не в WAV.
- Python 3.8+.
- Интернет при первом рендере: шрифты загружаются с Google Fonts.

## Лицензия Remotion

Remotion — сторонняя библиотека со своей лицензией. Она бесплатна для частных лиц, некоммерческих организаций и компаний до трёх человек. Компаниям от четырёх человек нужна лицензия Remotion (remotion.pro) — её покупают у Remotion, она не входит в этот набор.

## Чего скиллы не делают

- Не генерируют видео нейросетью и не снимают людей: всё в кадре — шрифт, графика, ваши скриншоты, ваше видео.
- Не распознают речь: для субтитров нужна расшифровка (как её получить — в скилле `captions-explainer`).
- Не подбирают музыку и не проверяют права на неё.
- Не публикуют ролики.
- Не обещают охватов.

## Язык

Инструкции — на русском. Тексты в роликах — на любом языке; шрифты стилей содержат латиницу и кириллицу.
