# Монтаж в ритм

## Что на что ставить

| Событие в видео | Куда | Поле beats.json |
|---|---|---|
| Смена сцены, новая карточка | сильная доля (первая в такте) | `downbeats` |
| Удар слова, вспышка, толчок масштаба | доля | `beats` |
| Мелкий акцент: моргание курсора, засечка | всплеск между долями | `onsets` |
| Финальный кадр | сильная доля перед концом фразы музыки | `downbeats` |

## Плотность

| Темп | Склейка | Сколько на чтение |
|---|---|---|
| 70–90 BPM | каждая доля или две | 0,7–1,7 с |
| 90–130 BPM | раз в такт (4 доли) | 1,8–2,7 с |
| 130–180 BPM | раз в такт или в два | 1,3–3,7 с |

Ускорение к кульминации: последние 2–3 склейки — вдвое чаще. Затем пауза на сильной доле с финальным кадром.

## Пульс

```ts
import { beatFrames, pulse } from "../lib/motion";

const beats = beatFrames(props.beats, fps);
const kick = pulse(frame, beats, 8); // 1 на доле, 0 через 8 кадров
const scale = 1 + kick * 0.03;      // едва заметный толчок
```

Толчок 2–4 % — чувствуется, но не трясёт. Больше 6 % читается как дрожание камеры.

## Частые ошибки

- **Сдвиг на кадр.** Склейка на кадр позже доли кажется опозданием. Скрипт даёт доли с точностью около 23 мс — меньше кадра при 30 к/с; если всё равно чувствуется опоздание — сдвинь склейки на кадр раньше.
- **Отрезок не тот.** Доли считались с 0:00, а звук в ролике с 0:31. Считай `--start` тем же числом, что `trimBefore`.
- **Двойной темп.** Удары вдвое чаще музыки — укажи `--max-bpm` ниже найденного темпа.
