# Субтитры и explainer

Композиция `Captions` (1080×1920, 30 к/с). Субтитры стоят между 55 % и 72 % высоты — выше подписи и кнопок Reels, TikTok и Shorts. Работаешь в проекте Motion Studio; если его нет — шаг 1 скилла `motion-director`.

## Что нужно на входе

- **Текст с таймингом**: SRT, VTT или JSON по словам. Где взять — [references/transcripts.md](references/transcripts.md). Скилл сам речь не распознаёт.
- **Фон**: видео (`public/…mp4`), картинка или «графика» — без съёмки.
- Для графики — главы: время и название.

## Порядок работы

1. **Тайминг по словам**:

   ```bash
   python3 scripts/srt_to_timeline.py voice.srt --max-words 3 --out public/data/captions.json
   ```

   Пример входа — [assets/sample.srt](assets/sample.srt). Из SRT и VTT время слов оценивается по длине слова внутри фразы — скрипт так и напишет (`word_times`). JSON с временем каждого слова (Whisper с `--word_timestamps True`) точнее — бери его, если есть.

   Смотри на `warnings`: больше 20 символов в секунду или меньше полсекунды на странице — читать не успеют. Сократи текст в SRT или увеличь `--max-words`.

2. **Props** в `props/captions.json`:

   ```json
   {
     "style": "signal",
     "background": { "type": "video", "src": "talk.mp4" },
     "timeline": { "…": "содержимое captions.json" },
     "chapters": [{ "at": 0, "title": "Зачем субтитры" }, { "at": 4.6, "title": "Как их сделать" }],
     "mode": "pop",
     "label": "Подкаст — 9:16"
   }
   ```

   - `background.type`: `video` — субтитры поверх вашего видео (кладёшь файл в `public/`, звук идёт из него); `image` — картинка с медленным наездом; `graphic` — номера глав, заголовки и индикатор голоса.
   - `mode`: `pop` — слова появляются по мере речи, текущее на плашке; `karaoke` — вся страница видна, текущее слово подсвечено. Для длинных роликов `karaoke` спокойнее.

3. **Длина** — конец последней страницы, округли вверх; поправь `durationInFrames` у `Captions` в `src/Root.tsx`. Для видео — длина видео.

4. **Звук.** Фон `video` играет звук своего файла. Для `graphic` и `image` добавь голос через `<Audio>` в `src/compositions/Captions.tsx` (как — в references/remotion-basics.md скилла `motion-director`).

5. **Проверка** — скилл `render-review`: обязательно `safezone` на нескольких моментах и контактный лист. Сверь пару страниц со звуком: слово должно загораться, когда его произносят. Расходится на всём ролике одинаково — сдвинь `--offset`.

## Правила

- 2–4 слова на странице. Одна строка лучше двух.
- Не исправляй речь говорящего в субтитрах, кроме явных оговорок, — спроси, если сомневаешься.
- Числа — цифрами («12 часов»), так быстрее читать.
- Мат и имена третьих лиц — уточни у пользователя, оставлять ли.
- Субтитры на видео с собственными надписями — проверь, что они не перекрываются.
