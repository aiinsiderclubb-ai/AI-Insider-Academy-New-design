# Где взять текст с таймингом

Скилл не распознаёт речь — он раскладывает готовую расшифровку по словам и кадрам. Варианты, от точного к простому:

## Whisper на своём компьютере — время каждого слова

```bash
pip install -U openai-whisper
whisper voice.mp3 --language ru --word_timestamps True --output_format json
```

Получится `voice.json` с `segments[].words[]` — скрипт читает его как есть. Нужен Python и ffmpeg; на обычном ноутбуке модель `small` (`--model small`) обрабатывает минуту речи за минуту-две.

## Сервисы и редакторы

- **CapCut, Premiere, DaVinci Resolve** — автосубтитры, экспорт в SRT.
- **YouTube Studio** — для загруженного видео: Субтитры → скачать .srt.
- **Сервисы расшифровки** с экспортом в SRT или VTT.

Из SRT тайминг слов оценивается внутри каждой фразы — на коротких фразах это почти незаметно, на длинных слова могут «уезжать». Делай фразы в SRT короче 2–3 секунд.

## Текст без таймингов

Есть только текст и звук — попроси пользователя сделать SRT любым способом выше. Расставлять время на слух скилл не берётся: ошибка в полсекунды видна сразу.

## Проверка

```bash
python3 scripts/srt_to_timeline.py voice.srt --report
```

Покажет число страниц и слов, длительность и предупреждения — без записи файла.
