# История в цифрах

Композиция `DataStory` (1920×1080, 30 к/с, 8 с): слева — вывод и цифра, справа — график. Работаешь в проекте Motion Studio; если его нет — шаг 1 скилла `motion-director`. Цифры в кадре люди примут за факт, поэтому их считает скрипт, а не модель.

## Что нужно на входе

- Таблица: CSV, Excel (сохрани как CSV) или цифры в сообщении — тогда собери CSV сам и покажи пользователю.
- Что из неё следует — одна мысль. Если пользователь не сформулировал, предложи по `facts` из скрипта.
- Источник данных — для подписи внизу кадра.

## Порядок работы

1. **CSV**: первая колонка — подписи (месяцы, товары), остальные — числа, в первой строке названия. Образец — [assets/hours-sample.csv](assets/hours-sample.csv).
2. **Проверь и посчитай**:

   ```bash
   python3 scripts/csv_to_chart.py data.csv --highlight last --delta first:last --unit " ч"
   ```

   Скрипт читает «12 500,5», «12,500.5», «€1 200», «35%»; ячейку, которая не число, показывает в `warnings`, а строку пропускает — сообщи об этом пользователю, не исправляй молча. В ответе:
   - `chart` и `delta` — готовые поля для props;
   - `facts` — первое и последнее значение, изменение, процент, максимум, минимум. Цифру для заголовка бери отсюда.
3. **Тип графика.** Сравнение категорий или до 12 периодов — `bar`. Тренд, много точек, несколько серий — `line` (`--kind line`). Правила — [references/chart-rules.md](references/chart-rules.md).
4. **Props** в `props/chart.json`:

   ```json
   {
     "style": "signal",
     "kicker": "Данные · кейс клиента",
     "title": "Часы на ручную рутину каждую неделю",
     "highlight": [2],
     "number": { "value": 29, "decimals": 0, "prefix": "−", "suffix": " ч", "label": "в неделю вернули команде за полгода" },
     "chart": { "…": "из csv_to_chart.py" },
     "delta": { "from": 0, "to": 5, "label": "−76%", "at": 4.2 },
     "source": "Источник: учёт времени команды, янв–июн 2026"
   }
   ```

   `number.value` — из `facts` (здесь 38 − 9 = 29). `highlight` — номера слов заголовка с нуля для плашки.
5. **Сверка перед рендером.** Каждая цифра в `title`, `number`, `delta.label` должна совпадать с `facts`. Перечисли их пользователю в ответе.
6. **Черновик и проверка** — скилл `render-review`.

## Правила

- Столбцы всегда от нуля — скрипт так и делает. Линия может начинаться не с нуля, но тогда шкала видна в кадре.
- Одна серия в столбцах; несколько — только линией.
- Акцент — на одном столбце или одной линии: том, о котором заголовок.
- Подписи под столбцами — до 8 символов: «Янв», а не «Январь 2026».
- Не округляй «для красоты»: 41,7 % не превращается в «почти 50 %».
- Нет источника — пиши «Источник: данные компании» или «пример данных», но не выдумывай организацию.
- Вертикальная версия для Reels — отдельная композиция с графиком под заголовком; горизонтальную не растягивай.
