# Кинетическая типографика

Композиция `KineticType` (1080×1920, 30 к/с): последовательность карточек. Карточка — одна фраза и одно движение. Работаешь в проекте Motion Studio; если его нет — сначала шаг 1 скилла `motion-director`.

## Что нужно на входе

- Текст или мысль, из которой его сделать.
- Стиль (по умолчанию `signal`) — см. `motion-director`, references/styles.md.
- Музыка, если есть, — тогда сначала `beat-sync`.
- Длина. По умолчанию 10 с, 5–7 карточек.

## Порядок работы

1. **Сократи текст до ударных фраз.** Каждая карточка — 1–4 слова, крупно. Правила и примеры — [references/writing.md](references/writing.md).
2. **Назначь движения** по [references/moves.md](references/moves.md). Чередуй: плотный подъём строк → одно слово ударом → пауза разрядкой. Подряд две одинаковые — только если это приём.
3. **Расставь время** (`at`, секунды) и проверь:

   ```bash
   python3 ../motion-director/scripts/timing.py props/reel.json --duration 10
   ```

   Есть `beats.json` — добавь `--beats public/data/beats.json --write props/reel.json`: склейки сдвинутся на ближайшие доли.
4. **Запиши props** в `props/reel.json`:

   ```json
   {
     "style": "signal",
     "kicker": "Имя — тема",
     "signature": "N°012",
     "beats": [],
     "cards": [
       { "mode": "rise", "at": 0, "text": "Видео,\nкоторое\nне стыдно\nпоказать.", "highlight": [2, 3] },
       { "mode": "slam", "at": 2.2, "text": "РИТМ", "note": "Монтаж — в долю такта" }
     ]
   }
   ```

   `\n` — перенос строки. `highlight` — номера слов карточки с нуля, считая все строки; вся строка в `highlight` ложится на одну плашку. `beats` — доли в секундах из `beats.json` (поле `beats`): на них «дышит» карточка `slam`.
5. **Длина композиции.** Если ролик не 10 с, поменяй `durationInFrames` у `KineticType` в `src/Root.tsx` (секунды × 30).
6. **Черновик и проверка** — скилл `render-review`: контактный лист, безопасная зона Reels, чтение каждой карточки.

## Правила

- Карточка `rise` и `marker` — не больше 4 строк; `slam`, `echo` — одно слово; `track` — до трёх слов.
- Текст в кадре — без точки в конце, если это не законченное предложение для эффекта («Меньше хайпа.»).
- Важный текст не заходит в колонку кнопок справа: композиция держит правое поле 150 px. Не уменьшай его для текста, который надо прочитать.
- Акцент — одна плашка на карточку.
- Последняя карточка — вывод или призыв, держится не меньше 1,5 с.
- Капс — только в стиле `bold-kinetic` или для одного слова в `slam`/`echo`.
