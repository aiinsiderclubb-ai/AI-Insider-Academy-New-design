# Движения карточек KineticType

| mode | Что происходит | Текст | Время на экране |
|---|---|---|---|
| `rise` | Строки по очереди поднимаются из-под маски, каждая во всю ширину; слова из `highlight` ложатся на плашку; в конце строки уходят вверх | 2–4 строки по 1–2 слова | 1,8–2,5 с |
| `slam` | Слово приземляется с большого размера, фон становится акцентным, под словом прочерчивается линия, `note` — подпись моно-шрифтом | одно слово | 1–1,5 с |
| `track` | Разрядка букв сжимается от широкой к плотной, сверху и снизу прочерчиваются линии; `note` — надпись над ними | 1–3 слова | 1,2–1,6 с |
| `echo` | Слово повторено пять раз контуром, третье — залито акцентом | одно короткое слово | 1,4–1,8 с |
| `type` | Команда печатается моно-шрифтом, ниже заполняется прогресс-бар из символов, затем `note` | команда, адрес, промпт | 1,6–2 с |
| `marker` | Две строки поднимаются, вторая ложится на плашку | «тезис. / вывод.» | 1,6–2 с |

## Сочетания, которые работают

- **Манифест:** rise → slam → track → echo → marker.
- **Цифра:** rise («Мы теряли») → slam («12 ЧАСОВ») → marker («каждую неделю. / Теперь — 2.»).
- **Продукт:** rise (боль) → type (как это делается) → marker (результат) → slam (название).
