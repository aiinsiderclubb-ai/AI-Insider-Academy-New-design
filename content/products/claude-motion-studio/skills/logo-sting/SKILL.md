# Анимация логотипа

Композиция `LogoSting` (1920×1080, 30 к/с, 5 с). Работаешь в проекте Motion Studio; если его нет — шаг 1 скилла `motion-director`.

## Что нужно на входе

- Логотип в SVG (не PNG: растр нельзя прорисовать линией). Как подготовить — [references/logo-prep.md](references/logo-prep.md).
- Название бренда и подпись (до трёх слов) — если не входят в сам знак.
- Цвета: свои у логотипа или цвета стиля (`monochrome`).

## Порядок работы

1. **Подготовь SVG**:

   ```bash
   python3 scripts/svg_prepare.py logo.svg --out public/data/logo.json
   ```

   В ответе — число путей и `warnings`. Текст, растр, градиенты, маски и CSS-классы в анимацию не попадут — каждое предупреждение объясняет, что сделать в редакторе. Не продолжай с предупреждением про `<text>`: буквы названия пропадут.

2. **Props** в `props/logo.json`:

   ```json
   {
     "style": "signal",
     "logo": { "…": "содержимое public/data/logo.json" },
     "name": "Insider",
     "tagline": "Motion Studio",
     "monochrome": false
   }
   ```

   `monochrome: true` — первый путь закрашивается акцентом стиля, остальные — цветом текста на акценте. Нужно, когда цвета логотипа спорят с фоном стиля.

3. **Если название уже внутри знака** (логотип-надпись), оставь `name` пустой строкой и `tagline` по желанию — знак не будет сдвигаться.

4. **Проверка** — скилл `render-review`: контактный лист на 8 кадров. Смотри на момент заливки (около 1,1 с): контур и заливка должны совпасть, без зазора.

## Правила

- Пути прорисовываются в порядке SVG: первым — самый нижний слой. Порядок не тот — поменяй слои местами в редакторе. Контуры без заливки рисуются последними, поверх залитых.
- Логотип из сотни мелких путей (гравюра, сложная иллюстрация) прорисовывается кашей — предложи пользователю упрощённую версию знака.
- Длина 3–5 с. Интро длиннее 5 секунд в рилсе пролистывают.
- Логотип клиента — только с его разрешения на использование в ролике; меняй его цвета только с согласия.
