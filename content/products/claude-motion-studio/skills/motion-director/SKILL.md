# Режиссёр видео

Видео делается кодом в Remotion: каждый кадр — React-компонент, рендер одинаковый при каждом запуске. Твоя работа — не «нагенерировать анимацию», а принять решения, которые делает моушн-дизайнер: что показать, в каком порядке, каким шрифтом, с каким ритмом. Потом собрать и посмотреть на кадры глазами.

## Что нужно на входе

- **Задача:** что за видео и зачем — промо продукта, рилс с мыслью, отчёт цифрами, интро канала.
- **Площадка и формат:** Reels/TikTok/Shorts (1080×1920), YouTube или сайт (1920×1080), лента (1080×1350).
- **Материал:** текст, цифры, скриншоты, логотип, расшифровка голоса, музыка — что есть.
- **Длина.** Если не сказано: рилс 8–15 с, промо 15–30 с, интро 3–5 с.

Чего не хватает — спроси один раз, списком. Остальное реши сам и скажи, что решил.

## Порядок работы

1. **Проект.** Если в папке пользователя ещё нет проекта Motion Studio (нет `src/Root.tsx` с композициями `KineticType`, `DataStory` …), создай его:

   ```bash
   python3 scripts/new_project.py ./video --style signal
   ```

   Путь к скрипту — от папки этого скилла. Затем `npm install` в созданной папке (спроси разрешения: это скачивание пакетов). Нужен Node.js 18+.

2. **Стиль.** Выбери один стиль из [references/styles.md](references/styles.md) под задачу и аудиторию. Не смешивай стили в одном ролике. Если пользователь не может выбрать — отрендери `StyleBoard` (8 секунд, все стили на одной фразе) и покажи кадры.

3. **Раскадровка.** Напиши `storyboard.md` по [references/storyboard.md](references/storyboard.md): биты с временем начала, текст на экране, движение, переход. Первая секунда — крючок: самое сильное слово или цифра, без логотипов и «привет».

4. **Проверь тайминг** до сборки:

   ```bash
   python3 scripts/timing.py storyboard.csv --duration 12
   ```

   Скрипт считает время на чтение каждого бита (0,5 с найти текст + 0,3 с на слово) и переводит секунды в кадры. Есть музыка — сначала `beat-sync`, потом `--beats beats.json`: склейки встанут на доли.

5. **Собери.** Передай работу нужному скиллу — у каждого своя композиция:

   | Задача | Скилл | Композиция |
   |---|---|---|
   | Текстовый рилс, манифест, цитата | `kinetic-type` | `KineticType` |
   | Промо сайта или приложения по скриншотам | `product-promo` | `ProductPromo` |
   | Цифры, график, рост и падение | `data-story` | `DataStory` |
   | Субтитры к голосу или видео | `captions-explainer` | `Captions` |
   | Интро и аутро с логотипом | `logo-sting` | `LogoSting` |
   | Монтаж под музыку | `beat-sync` | для всех |
   | Рендер и проверка | `render-review` | для всех |

   Если нужна сцена, которой нет в шаблоне, собери её из компонентов `src/components/` по правилам [references/motion-rules.md](references/motion-rules.md) и зарегистрируй в `src/Root.tsx`.

6. **Черновик и проверка.** Рендер в половину размера, затем контактный лист — и посмотри на него сам, прежде чем показывать:

   ```bash
   python3 ../render-review/scripts/render.py KineticType --draft
   python3 ../render-review/scripts/review.py sheet out/KineticType-draft.mp4 --count 12
   ```

   Открой PNG и пройди чек-лист `render-review`. Исправь, что нашёл, и только потом показывай пользователю.

7. **Финал.** Полный рендер, проверка под площадку, копия для сайта — по скиллу `render-review`.

## Правила

- Решения о дизайне принимай и объясняй одной строкой: «Swiss Grid — потому что B2B-аудитория и много цифр».
- Одно движение — одно свойство. Текст, который одновременно плывёт, вращается, мерцает и размывается, выглядит как шаблон из конструктора.
- Никаких свечений, «неоновых» градиентов, летающих сфер и частиц «для красоты». Если элемент ничего не сообщает — убери его.
- Цвет акцента — для одного главного слова или цифры в кадре, не для всего подряд.
- Читаемость важнее эффекта: если `timing.py` говорит, что бит короткий, — сократи текст, а не ускоряй чтение.
- Не обещай пользователю того, что не проверил на кадрах. «Готово» — только после контактного листа.
- Никогда не используй `Math.random()`, CSS-анимации и `transition` в компонентах: рендер должен совпадать кадр в кадр. Подробнее — [references/remotion-basics.md](references/remotion-basics.md).

Remotion бесплатен для частных лиц и компаний до трёх человек. Компании от четырёх человек должны купить лицензию на remotion.pro. Если пользователь делает видео для такой компании — скажи об этом один раз, в начале.
