# Раскадровка

Раскадровка — таблица битов. Бит — одна мысль на экране между двумя склейками. Сохраняй её как `storyboard.md` для пользователя и как `storyboard.csv` (колонки `at,text`) для `timing.py`.

## Шаблон

```markdown
# <название видео>

Площадка: Reels, 1080×1920, 30 к/с · Длина: 12 с · Стиль: signal
Музыка: track.mp3, 0:31–0:43, 118 BPM (beats.json)
Композиция: KineticType

| # | Начало, с | На экране | Движение | Переход |
|---|---|---|---|---|
| 1 | 0,0 | «Вы теряете 12 часов в неделю» | подъём строк, плашка на «12 часов» | склейка в долю |
| 2 | 2,0 | РУТИНА | удар во всю ширину, фон — акцент | склейка |
| … | | | | |

Крючок: цифра «12 часов» в первые полсекунды.
Финал: призыв + адрес, держится не меньше 1,5 с.
```

## Правила

- **Первая секунда решает.** Самое сильное слово, цифра или картинка — сразу. Логотип в начале рилса съедает крючок; ставь его в конец.
- **Одна мысль на бит.** Две мысли — два бита.
- **Текст сокращай до предела.** На экране не предложение из поста, а его ударная часть: «12 часов в неделю — на рутину», а не «Знаете ли вы, что в среднем…».
- **Ритм.** Чередуй длинные и короткие биты, плотные и пустые кадры. Три одинаковых бита подряд — это слайд-шоу.
- **Финал держится.** Последний кадр с призывом — не меньше 1,5 с, иначе его не успеют прочитать до повтора.
- **Звук.** Если ролик будут смотреть без звука (лента), всё важное должно быть в тексте на экране.

## Длительности, с которых начинать

| Что | Сколько |
|---|---|
| Одно слово во весь экран | 0,8–1,2 с |
| Строка из 3–5 слов | 1,5–2 с |
| Цифра с подписью | 2–2,5 с |
| График | 4–6 с |
| Скриншот с наездом и подписью | 3–4 с |
| Финальный кадр | 1,5–2,5 с |

Точное время на чтение считает `timing.py`. Если он говорит «мало» — режь текст.
