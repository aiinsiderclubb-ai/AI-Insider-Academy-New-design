# Промо продукта по скриншотам

Композиция `ProductPromo` (1920×1080, 30 к/с). Одно окно браузера остаётся в кадре, внутри меняются страницы. Работаешь в проекте Motion Studio; если его нет — шаг 1 скилла `motion-director`.

## Что нужно на входе

- Адреса страниц (2–4) или готовые скриншоты.
- Что главное на каждой странице — одна выгода, которую назовёт выноска.
- Финальный кадр: фраза из двух строк и адрес.

## Порядок работы

1. **Скриншоты.** Публичные страницы сними скриптом — он использует установленный Chrome, Chromium или Edge:

   ```bash
   python3 scripts/capture.py https://site.com https://site.com/pricing --out public/shots
   ```

   Окно 1440×900, плотность 2x — чёткость при наезде. Скрипт ждёт 8 секунд, пока страница догрузится; анимации на сайте медленные — дай `--wait 12`. Открой каждый PNG и проверь: нет ли баннера cookies, всплывающего окна, пустого экрана. Маленький файл скрипт помечает — это часто ошибка 404 или вход.

   Страницы за логином скрипт не снимет. Попроси пользователя прислать скриншоты (1440×900 или больше) и положи их в `public/shots/`.

2. **План кадров** — по [references/shot-list.md](references/shot-list.md): для каждой страницы — где курсор, куда нажимает, где наезд, что в выноске. Координаты — доли скриншота: (0, 0) левый верхний угол, (1, 1) правый нижний. Найди их по скриншоту: элемент на 300 px от левого края при ширине 2880 px → `x: 0.104`.

3. **Props** в `props/promo.json`:

   ```json
   {
     "style": "signal",
     "brand": "Бренд — Promo",
     "shots": [
       {
         "src": "shots/home.png", "url": "site.com", "at": 0, "label": "Главная",
         "cursor": [{ "x": 0.62, "y": 0.96, "at": 1.0 }, { "x": 0.085, "y": 0.64, "at": 2.0 }],
         "clicks": [2.2],
         "zoom": { "x": 0.27, "y": 0.42, "scale": 1.4, "at": 2.6, "hold": 1.3 },
         "callout": { "x": 0.535, "y": 0.43, "text": "Оффер — сразу", "at": 3.1 }
       }
     ],
     "end": { "at": 8.7, "title": "Готовые AI-системы.", "marked": "Без воды.", "url": "site.com" }
   }
   ```

   `at` везде — секунды от начала ролика. Курсор и выноска следуют за наездом камеры: координаты всегда в долях скриншота.

4. **Длина:** последний `end.at` + 1,3 с. Поправь `durationInFrames` у `ProductPromo` в `src/Root.tsx`.

5. **Проверь выноски на кадрах.** Отрендери кадр в момент выноски и посмотри, не уходит ли надпись за край кадра и не закрывает ли важное:

   ```bash
   python3 ../render-review/scripts/render.py ProductPromo --props props/promo.json --still 110
   ```

   Уходит за правый край — поставь `"side": "left"`, уменьши наезд (`scale` 1.3–1.5) или укороти текст.

6. **Черновик, контактный лист, финал** — скилл `render-review`.

## Правила

- Скриншоты — настоящие и свежие. Не рисуй интерфейс, которого нет у продукта: зритель придёт на сайт и не найдёт его.
- Выноска — выгода словами клиента, 2–4 слова: «Оплата за минуту», а не «Удобная система оплаты».
- Одна страница — одна мысль, 3–4 секунды. Больше четырёх страниц — уже обзор, а не промо.
- Наезд 1,3–1,7. Сильнее — скриншот размывается.
- Персональные данные на скриншотах (имена, почты, суммы клиентов) — замажь до рендера или возьми демо-аккаунт.
- Без своих скриншотов композиция показывает схематичные экраны из `public/shots/demo-*.svg` — только для проверки, не для публикации.
