# Чек-лист по контактному листу

Пройди по каждому пункту. Ответ «не знаю» = открой кадр целиком (`review.py frames`).

## Текст

- [ ] Каждое слово читается на телефоне: высота строчных не меньше 40 px в 1080×1920, 28 px в 1920×1080.
- [ ] Нет обрезанных букв: хвосты «у», «р», «д», точки над «ё» и «й».
- [ ] Нет висящих предлогов и одиночных слов в последней строке.
- [ ] Нет опечаток. Прочитай текст в кадре вслух по буквам — проверка орфографии кадров не видит.
- [ ] Шрифт тот, что задуман, а не запасной (Arial/Times вместо фирменного — шрифт не загрузился).

## Композиция

- [ ] Левый край текста один и тот же от кадра к кадру.
- [ ] В вертикальном видео текст внутри безопасной зоны (`review.py safezone`).
- [ ] Один акцент в кадре.
- [ ] Ничего не прилипло к краю кадра ближе, чем на 4 % ширины, если это не задумано.

## Движение и время

- [ ] Первый кадр не пустой и не чёрный: первая секунда — крючок.
- [ ] Каждый бит стоит не меньше, чем считает `timing.py`.
- [ ] Ничего не исчезает посреди движения на склейке.
- [ ] Финальный кадр держится не меньше 1,5 с.
- [ ] Есть музыка — склейки на долях (`beat-sync`).

## Данные и факты

- [ ] Каждая цифра в кадре совпадает с `facts` из `csv_to_chart.py` или с исходником.
- [ ] Подпись источника есть, если в кадре данные.
- [ ] Скриншоты без чужих персональных данных.

## Техника

- [ ] `review.py probe` — пустой `problems`.
- [ ] `review.py loudness` — в пределах цели, если есть звук.
- [ ] Размер файла подходит месту публикации.
