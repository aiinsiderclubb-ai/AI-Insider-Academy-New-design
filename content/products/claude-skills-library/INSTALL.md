# Установка

Распакуйте архив. Получится папка `claude-skills-library` — в ней `skills/` с одиннадцатью скиллами и служебная папка `.claude-plugin/`.

Служебная папка начинается с точки, поэтому в Finder и Проводнике она скрыта. Это нормально.

## Claude Code

### Способ 1. Как плагин — все скиллы сразу

В терминале, из папки, где лежит распакованный архив:

```bash
claude plugin marketplace add ./claude-skills-library
```

```bash
claude plugin install insider-business-skills@ai-insider-academy
```

Перезапустите Claude Code. Скиллы появятся в меню по `/` с префиксом: `/insider-business-skills:offer-builder`.

Папку после установки не удаляйте и не переносите: плагин загружается из неё.

### Способ 2. Отдельные скиллы — без префикса

Скопируйте нужные папки из `skills/` в свою папку скиллов:

```bash
cp -R claude-skills-library/skills/* ~/.claude/skills/
```

Так скиллы доступны во всех проектах и вызываются коротко: `/offer-builder`. Чтобы скилл работал только в одном проекте, копируйте в `.claude/skills/` внутри проекта.

### Проверка

Откройте Claude Code и наберите `/` — в списке должны быть скиллы. Или просто попросите: «подготовь отчёт клиенту по этой таблице» — агент подключит `weekly-client-report` сам.

## Claude Cowork и приложение Claude

Скиллы загружаются по одному, каждый — отдельным архивом.

1. Заархивируйте папку нужного скилла, например `skills/offer-builder`, в ZIP. В архиве должна лежать сама папка с файлом `SKILL.md` внутри.
2. В приложении откройте настройки, раздел со скиллами, и загрузите архив.
3. Включите скилл в списке.

Названия пунктов меню в приложении меняются от версии к версии; ищите раздел «Скиллы» или «Skills».

Скрипты выполняются в среде выполнения кода Claude. `seo-geo-audit` обращается в сеть: если доступ в интернет в вашей среде закрыт, используйте вариант с сохранённой страницей.

## Codex

Codex ищет скиллы в папке `.agents/skills`.

Для всех проектов:

```bash
mkdir -p ~/.agents/skills && cp -R claude-skills-library/skills/* ~/.agents/skills/
```

Для одного репозитория — скопируйте в `.agents/skills/` в его корне.

Codex подхватывает изменения сам; если скиллы не появились — перезапустите. Вызов: `/skills` или `$offer-builder`.

## Другие агенты

Формат — открытый стандарт Agent Skills: папка с файлом `SKILL.md`. Если ваш агент его поддерживает, скопируйте папки из `skills/` туда, где он ищет скиллы.

## Python

Скриптам нужен Python 3.8 или новее. Проверка:

```bash
python3 --version
```

На Windows команда может называться `python` — агент подставит нужную сам. Сторонние библиотеки не требуются.

Если Python нет, скиллы всё равно работают: агент выполнит проверки вручную по тем же правилам и скажет, что автоматическая проверка не запускалась.

## Разрешения

При первом запуске скрипта агент спросит разрешение на выполнение команды. Скрипты только читают указанные вами файлы и печатают результат; `page_audit.py` дополнительно открывает страницу, которую вы назвали. Ничего не отправляют и не удаляют.

Чтобы не подтверждать каждый раз в Claude Code, разрешите запуск Python в настройках проекта.

## Обновление и удаление

Обновление: замените папку новой версией. Для плагина — затем:

```bash
claude plugin marketplace update ai-insider-academy
```

Удаление плагина:

```bash
claude plugin uninstall insider-business-skills@ai-insider-academy
```

Для скопированных скиллов — удалите их папки.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| Скиллов нет в меню `/` | Перезапустите агента. Проверьте, что в папке скилла есть `SKILL.md` |
| Агент не подключает скилл сам | Вызовите явно: `/offer-builder`. Или назовите задачу словами из описания скилла |
| «python3: command not found» | Установите Python 3 или попросите агента использовать `python` |
| Скрипт не найден | Скилл скопирован без папки `scripts/` — скопируйте папку скилла целиком |
| `seo-geo-audit`: ошибка 403 | Сайт блокирует запросы скриптов. Сохраните страницу как HTML и дайте агенту файл |
| Не видно папки `.claude-plugin` | Она скрыта. В Finder: Cmd+Shift+точка. Для установки показывать её не обязательно |
