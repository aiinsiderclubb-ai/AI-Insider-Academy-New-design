# Insider Business Skills

Одиннадцать скиллов для Claude Code, Claude Cowork и Codex. Они закрывают путь от первого сообщения клиенту до ежемесячного отчёта: оффер, аутрич, разбор звонка, предложение, контент, аудит, отчёт.

## Чем скилл отличается от промпта

Промпт вы вставляете каждый раз заново. Скилл устанавливается один раз, и агент сам подключает его, когда вы просите о подходящей задаче. Внутри — не один абзац, а порядок работы, справочные материалы и скрипты.

Скрипты — главное отличие этого набора. Девять скиллов из одиннадцати проверяют свою работу программой, а не «на глаз»:

- проценты в отчёте считает скрипт, а не модель;
- цитаты в постах сверяются с расшифровкой видео — выдуманная цитата не пройдёт;
- письмо с незаполненной `[подстановкой]` не будет сдано;
- ключ, забытый в воркфлоу n8n, будет найден.

Скрипты написаны на Python 3 без сторонних библиотек: ставить ничего не нужно.

## Что внутри

| Скилл | Что делает | Скрипт |
|---|---|---|
| `offer-builder` | Три варианта оффера с оценкой и текст лендинга по блокам | — |
| `cold-outreach` | Персональные письма и сообщения по списку лидов | Проверка длины, спам-слов, подстановок |
| `call-debrief` | Разбор звонка: факты, цена проблемы, оценка готовности, письмо | Расчёт цены проблемы и оценки |
| `proposal-writer` | Предложение с тремя пакетами и описание работ | Расчёт цены и окупаемости |
| `content-repurposer` | Из расшифровки видео — клипы, посты, письмо, статья, план | Разбор субтитров, сверка цитат, проверка клипов |
| `short-video-script` | Сценарий Reels или Shorts с тремя хуками | Длительность по секундам |
| `seo-geo-audit` | Аудит страницы для поиска и AI-ответов | Сбор фактов о странице и robots.txt |
| `competitor-research` | Профили конкурентов с источниками и сравнение | — |
| `n8n-workflow-review` | Проверка воркфлоу n8n перед запуском | Поиск секретов и ошибок надёжности |
| `weekly-client-report` | Отчёт клиенту на одну страницу из таблицы показателей | Расчёт изменений и статуса целей |
| `brand-voice` | Карточка голоса по образцам и проверка текстов | Проверка текста по карточке |

Подробно о каждом, с примерами запросов, — в `SKILLS.md`.

## С чего начать

1. Установите по `INSTALL.md` — это 2 минуты.
2. Попробуйте скилл, которому не нужны ваши данные: попросите агента «проверь страницу https://ваш-сайт для поиска и AI-ответов».
3. Дальше идите по цепочке: `offer-builder` → `cold-outreach` → `call-debrief` → `proposal-writer`. Каждый следующий скилл умеет читать файл, который создал предыдущий.

## Как скиллы связаны

```
offer-builder ──> offer.md ──> cold-outreach
                                    │
                              (звонок с клиентом)
                                    │
call-debrief ──> call-debrief.md ──> proposal-writer ──> proposal.md
                                                              │
                                                       (проект идёт)
                                                              │
                                    weekly-client-report ──> report.md
```

`brand-voice` даёт карточку голоса, которой пользуются `content-repurposer` и `short-video-script`.

## Требования

- Claude Code, Claude Cowork или Codex — любой агент, который понимает формат Agent Skills.
- Python 3.8 или новее для скриптов. Без Python скиллы работают, но проверки выполняются вручную, и агент об этом скажет.
- Для `seo-geo-audit` и `competitor-research` — доступ агента в интернет. Без него аудит можно провести по сохранённой странице.

## Чего скиллы не делают

- Не отправляют письма и сообщения: пишут и проверяют, отправка за вами.
- Не обещают результатов, которые от них не зависят: места в поиске, рост продаж.
- Не заменяют юриста: шаблоны предложений и описаний работ перед подписанием покажите специалисту.
- Не выдумывают факты. Где данных не хватает, скилл оставит пометку `[нужно: …]` и спросит.

## Язык

Инструкции и материалы — на русском. Агент отвечает на том языке, на котором вы к нему обращаетесь; если нужен результат на другом языке — скажите об этом в запросе.
