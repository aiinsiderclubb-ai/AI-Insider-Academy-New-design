# Профиль конкурента

Один профиль — одна компания. Каждая строка в разделах «Факты» заканчивается источником в скобках: адрес страницы и дата просмотра. Нет данных — «не найдено».

- Примеры клиентов, если названы: (источник)
- Признаки по косвенным данным — язык сайта, валюта, кейсы: (источник)

### Что обещает

- Какое действие просит совершить: (источник)

### Продукт

- Срок запуска или доставки, если назван: (источник)

### Цена

- Модель: разово / подписка / за пользователя / за объём / по запросу: (источник)
- Тарифы и цены: (источник, дата)
- Что платно дополнительно: (источник)
- Пробный период, возврат, гарантии: (источник)

Если цены скрыты — так и напиши. «По запросу» — тоже информация: значит, продажа идёт через менеджера.
