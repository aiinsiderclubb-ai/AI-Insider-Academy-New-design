# Проверка качества

Проходится перед каждой отправкой клиенту. Каждое «нет» исправляется до отправки.

## Факты — для всех текстов

- [ ] Все цифры есть в расшифровке.
- [ ] Цитаты дословные.
- [ ] Имена, названия компаний и продуктов написаны верно и одинаково.
- [ ] Нет обещаний, гарантий и цен, которых автор не называл.
- [ ] Нет упоминаний людей, которых нельзя упоминать по анкете.
- [ ] Прогон промпта `07-quality` не дал находок или они исправлены.

## Голос

- [ ] Обращение совпадает с анкетой.
- [ ] Нет слов из списка запрещённых.
- [ ] Текст, прочитанный вслух, звучит как клиент.
- [ ] Нет штампов: «в современном мире», «не секрет, что», «давайте разберёмся».

## Короткие видео — каждое из пяти

- [ ] Понятно без остального видео.
- [ ] Первые три секунды — хук, а не разгон.
- [ ] Фраза не обрывается в начале и в конце.
- [ ] Субтитры вычитаны: нет ошибок и расхождений с речью.
- [ ] Субтитры не закрыты интерфейсом платформ.
- [ ] Лицо в кадре, ничего важного не обрезано.
- [ ] Звук ровный, музыка тише голоса.
- [ ] 1080×1920, имя файла по шаблону.
- [ ] Есть название и подпись.
- [ ] У гостя есть согласие на публикацию.

## Посты — каждый из трёх

- [ ] Первая фраза работает без заголовка.
- [ ] Одна мысль.
- [ ] Не длиннее 1 000 знаков.
- [ ] Одно действие в конце.
- [ ] Три поста разные по типу.

## Письмо

- [ ] Тема до 45 знаков, три варианта.
- [ ] Одна мысль, одна ссылка.
- [ ] Ссылка рабочая.
- [ ] Есть постскриптум с вопросом.

## Статья

- [ ] Понятна человеку, который не видел видео.
- [ ] Заголовки разделов отражают содержание.
- [ ] Есть вывод с шагами.
- [ ] Есть описание для поисковиков до 155 знаков.
- [ ] Нет повторов абзацев и мыслей.

## План публикаций

- [ ] Не больше двух публикаций в день на канал.
- [ ] Каждая единица ведёт туда, куда указано в анкете.
- [ ] Учтены требования по маркировке рекламы, если они есть.

## Комплект

- [ ] Всё лежит в папке недели.
- [ ] Одна ссылка на тексты, одна — на видео.
- [ ] Статус в трекере обновлён.
