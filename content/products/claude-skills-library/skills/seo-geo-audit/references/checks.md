# Как читать вывод скрипта

Для каждого поля — что считать нормой и что проблемой.

## Доступность

| Поле | Норма | Проблема |
|---|---|---|
| `status` | 200 | Любой другой код |
| `redirected` | `false` или редирект на ту же страницу с другим слешем или протоколом | Редирект на другую страницу — аудит идёт не той страницы |
| `meta_robots` | пусто или `index, follow` | `noindex` — страница не попадёт в выдачу. Критично, если это не намеренно |
| `x_robots_tag` | пусто | `noindex` в заголовке ответа — то же самое |
| `canonical` | адрес этой же страницы | Пусто — желательно добавить. Другой адрес — критично: поисковик считает главной другую страницу |
| `rendering.likely_client_rendered` | `false` | `true` — в исходном HTML почти нет текста, он появляется после выполнения скриптов. Многие боты, включая большинство AI-ботов, скрипты не выполняют и увидят пустую страницу |

## Заголовок и описание

| Поле | Норма | Проблема |
|---|---|---|
| `title.length` | 30–60 знаков | Пусто — критично. Длиннее 60 — обрежется в выдаче. Короче 20 — обычно только название бренда |
| `title.text` | Содержит то, что ищут, ближе к началу; отличается от других страниц сайта | Только название компании; одинаковый на всех страницах |
| `meta_description.length` | 110–160 знаков | Пусто — поисковик возьмёт случайный фрагмент. Длиннее 160 — обрежется |
| `meta_description.text` | Отвечает, что человек получит на странице; есть конкретика | Набор ключевых слов; общие слова |

Описание не влияет на позицию напрямую, но влияет на то, кликнут ли по результату.

## Структура

| Поле | Норма | Проблема |
|---|---|---|
| `h1` | Ровно один, про тему страницы | Нет h1; несколько h1; h1 — слоган без ключевого смысла |
| `headings` | h2 делят страницу на смысловые части, по ним можно понять содержание | Заголовки вроде «Подробнее», «Наши преимущества» без содержания; заголовков нет вовсе |
| `heading_levels_skipped` | пусто | Переход h2 → h4: не ошибка для поиска, но признак, что заголовки ставили ради размера шрифта |
| `question_headings` | Есть на информационных страницах | Нет ни одного — см. раздел про AI-ответы |

## Содержание

| Поле | Норма | Проблема |
|---|---|---|
| `words` | Достаточно, чтобы полностью ответить на запрос. Страница услуги — обычно от 300, статья — от 800 | Меньше 150 слов на странице, которая должна отвечать на вопрос |
| `first_200_chars` | Сразу понятно, о чём страница и для кого | Меню, cookie-баннер или лозунг вместо сути. Проверь, не съедает ли начало навигация |
| `lang` | Соответствует языку текста | Пусто или не тот язык |
| `hreflang` | Есть, если у страницы есть версии на других языках | Версии есть, а `hreflang` нет |

Число слов — не цель. Длинная страница без ответа хуже короткой с ответом.

## Изображения и ссылки

| Поле | Норма | Проблема |
|---|---|---|
| `images.without_alt` | 0 | У содержательных изображений нет `alt`: их не поймут ни поиск, ни программы чтения с экрана |
| `images.empty_alt` | Допустимо для декоративных | Пустой `alt` у фото товара, схемы, скриншота |
| `links.internal` | Есть ссылки на связанные страницы сайта | 0–2 — страница изолирована |
| `links.external` | Есть ссылки на источники там, где приводятся факты | Нет ни одной при наличии цифр и утверждений |

## Разметка и превью

| Поле | Норма | Проблема |
|---|---|---|
| `structured_data.types` | Тип соответствует странице: `Organization`, `LocalBusiness`, `Product`, `Article`, `FAQPage`, `Course`, `BreadcrumbList` | Нет разметки — желательно добавить. Тип не соответствует содержимому — убрать |
| `structured_data.invalid_blocks` | 0 | Больше 0 — блок JSON-LD с ошибкой, поисковик его не прочитает |
| `open_graph` | `og:title`, `og:description`, `og:image` | Нет — ссылка в мессенджерах и соцсетях выглядит пустой |
| `viewport` | Есть | Нет — страница не адаптирована под телефон |

Разметка должна описывать то, что реально есть на странице. Разметка отзывов без отзывов или вопросов без вопросов — нарушение правил поисковых систем.

## robots.txt и карта сайта

| Поле | Норма | Проблема |
|---|---|---|
| `robots_txt.found` | `true` | `false` — не критично, но карту сайта указать негде |
| `robots_txt.sitemaps` | Указана карта сайта | Пусто и `sitemap_xml_at_default_path` — `false` |
| `robots_txt.ai_bots` | Соответствует решению владельца | См. раздел про AI-ответы |

## Чего скрипт не видит

Назови это в отчёте в разделе «Что не проверялось»:

- скорость загрузки и показатели Core Web Vitals;
- ссылки на сайт с других сайтов;
- текущие позиции и трафик;
- дубли страниц и структуру всего сайта;
- как страница выглядит после выполнения JavaScript;
- что о компании говорят на других сайтах.
