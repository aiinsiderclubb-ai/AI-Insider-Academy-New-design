# Content Automation

Набор воркфлоу n8n, который ведёт контент-план за вас: каждую неделю придумывает темы под ваши рубрики, пишет черновики в голосе бренда под формат каждого канала, присылает их на одобрение в Telegram и публикует в назначенное время. Контент-план — обычная Google Таблица, которую можно править руками.

## Что делает

- **План на неделю.** В воскресенье вечером бот смотрит расписание слотов (например, Telegram — пн, ср, пт; блог — сб) и предлагает тему и бриф на каждый свободный слот: по рубрикам, без повторов недавних тем.
- **Черновики под канал.** Пост для Telegram, деловой пост для LinkedIn, статья для блога — у каждого канала свой формат и предел длины. Факты, цифры, отзывы модель не выдумывает.
- **Одобрение в Telegram.** Черновик приходит в чат с кнопками **Опубликовать / Переписать / Пропустить**. Ответ «Переписать: короче и с примером» — новый вариант с замечанием. Ответ своим текстом — ваш текст публикуется вместо черновика.
- **Публикация по расписанию.** Telegram-канал (с картинкой или без), WordPress (Markdown превращается в HTML), любой сервис через вебхук: Make, Zapier, Buffer, свой сервер.
- **Без дублей и опозданий.** Перед публикацией строка помечается — пост не выйдет дважды, даже если запуск оборвётся. Пост, который опоздал больше чем на 12 часов (n8n был выключен), не выходит задним числом.
- **Всё видно в таблице.** Статус каждой публикации, кто одобрил, ссылка на пост, причина сбоя.

## Чем отличается от шаблона из интернета

Воркфлоу запускались в n8n 2.44 на подменных Google Таблицах, модели, Telegram, WordPress и вебхуке: план недели, повторный план без дублей, черновик и кнопки, ответ своим текстом, публикация в канал, блог и вебхук, отказ сервиса, защита от двойной публикации. Логика узлов Code проверена 9 сценариями, включая часовые пояса и летнее время. Подробности — `tests/scenarios.md`.

## Что нужно

- n8n с адресом в интернете по https (для кнопок Telegram).
- Google Таблица с листом `Plan`.
- Telegram-бот и чат для одобрения. Для публикации в Telegram-канал бот должен быть администратором канала.
- Ключ модели с OpenAI-совместимым API.
- По желанию: WordPress с паролем приложения; вебхук Make, Zapier или другого сервиса для LinkedIn, Instagram, Facebook и остальных площадок.
