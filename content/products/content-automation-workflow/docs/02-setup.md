# Установка

## Импорт

1. В n8n: Workflows → Import from File. Импортируйте файлы по одному:
   - `workflows/content-weekly-plan.n8n.json` — каждое воскресенье: темы и брифы на свободные слоты следующей недели
   - `workflows/content-drafts.n8n.json` — каждые 15 минут: черновик под формат канала и отправка на одобрение
   - `workflows/content-approvals.n8n.json` — кнопки и ответы в чате одобрения
   - `workflows/content-publisher.n8n.json` — каждые 5 минут: публикация в Telegram, WordPress или через вебхук
   - `workflows/error-alert.n8n.json` — сообщение в Telegram о любом сбое
2. После импорта узлы, которым нужны учётные данные, подсвечены красным — их нужно выбрать (раздел ниже).
3. Откройте каждый воркфлоу → Settings → Error Workflow → выберите «Error Alert». Без этого о сбое вы узнаете от клиента.
4. Включите воркфлоу переключателем Active (Publish) вверху справа. Используйте Production URL, а не Test URL.

Воркфлоу проверены на n8n 2.44. На более старых версиях узлы могут называться иначе; обновите n8n, если импорт показывает неизвестные узлы.

## Учётные данные

Создайте в n8n (Credentials → Add credential) и выберите в подсвеченных узлах.

**Google Sheets** — тип Google Sheets OAuth2 API.
Войдите под аккаунтом, у которого есть доступ к таблице. Совет: отдельный аккаунт Google для автоматизации с доступом только к нужным таблицам.

**Telegram** — тип Telegram API.
Создайте бота через @BotFather (`/newbot`), вставьте токен. Добавьте бота в чат, куда должны приходить сообщения. Чтобы узнать chat id: напишите в чат любое сообщение и откройте `https://api.telegram.org/botТОКЕН/getUpdates` — в ответе будет `chat.id`. У групп он начинается с минуса.

**Ключ модели** — тип Header Auth.
- Name: `Authorization`
- Value: `Bearer ваш-ключ`

Подходит любой сервис с OpenAI-совместимым API: OpenAI, OpenRouter (через него доступны модели Anthropic, Google и другие), Groq, Together, локальный сервер. Адрес и модель задаются в узле Config: `llm.base_url` и `llm.model`.


**WordPress** — тип Basic Auth (только если публикуете в блог).
- User: имя пользователя WordPress с ролью Автор или Редактор.
- Password: пароль приложения — Пользователи → Профиль → Пароли приложений → Добавить. Это не пароль от входа; его можно отозвать в любой момент.

## Бот в чате одобрения

Режим приватности бота не мешает: бот получает нажатия кнопок и ответы на свои сообщения. Сообщения из других чатов «Approvals» игнорирует.

У одного Telegram-бота может быть только один Telegram Trigger. Если бот уже принимает сообщения в другом воркфлоу n8n, создайте для этого набора отдельного бота.

## Config

Полный Config — в «Drafts» и «Weekly Plan»; в «Approvals» и «Publisher» — те поля, которые им нужны. Значения одинаковых полей должны совпадать.

| Поле | Что это |
|---|---|
| `spreadsheet_id` | Идентификатор таблицы — часть адреса между `/d/` и `/edit` |
| `plan_sheet` | Лист плана. По умолчанию `Plan` |
| `approval_chat_id` | Чат одобрения и уведомлений |
| `require_approval` | `true` — каждый черновик ждёт кнопки; `false` — публикуется без одобрения |
| `draft_ahead_hours` | За сколько часов до публикации писать черновик |
| `max_attempts` | Сколько раз пробовать написать черновик, прежде чем отметить сбой |
| `max_late_hours` | Насколько можно опоздать с публикацией. Позже — пост не выходит, команда получает сообщение |
| `notify_published` | Сообщать в чат о каждой публикации |
| `llm` | Адрес API, модель, режим JSON, температура (0.7 — живее текст, 0.3 — ровнее) |
| `brand` | Название, о компании, аудитория, голос, правила, призыв к действию |
| `pillars` | Рубрики: название и что в них публикуется |
| `channels` | Каналы: тип, адрес, формат, предел длины (`docs/03-channels.md`) |
| `slots` | Расписание недели: день (`mon`…`sun`), время, канал, рубрика по желанию |
| `ideas_lookback` | Сколько последних тем показывать модели, чтобы не было повторов |

Пример заполненного Config — `templates/config.example.json`.

Расписание запусков — в первых узлах: **Every Sunday** (план), **Every 15 Minutes** (черновики), **Every 5 Minutes** (публикация).

## Какую модель выбрать

Здесь модель пишет тексты, которые увидят ваши читатели, — экономить на ней не стоит. Возьмите сильную модель у любого провайдера с OpenAI-совместимым API и сравните 5–10 черновиков на ваших темах, прежде чем решить.

- Модель должна уметь отвечать в формате JSON. Если провайдер не поддерживает режим JSON, поставьте `llm.json_mode: false` — воркфлоу найдёт JSON в ответе.
- `llm.temperature`: 0.7 — живее и разнообразнее, 0.3 — ровнее и предсказуемее.
- Стоимость: черновик поста — пара тысяч токенов, статья — около десяти тысяч. Цены смотрите у провайдера; десятки публикаций в месяц обычно обходятся в единицы долларов.
- Что уходит провайдеру модели: бренд, рубрики, темы и брифы. Не кладите в бриф конфиденциальное.

## Если что-то не работает

| Что видите | Где смотреть | Частая причина |
|---|---|---|
| Ничего не приходит | n8n → Executions | Воркфлоу не включён или используется Test URL вместо Production URL |
| Ошибка 401 или 403 у Google | Учётные данные Google | Истёк доступ — переподключите учётные данные |
| Ошибка 400 у Google: Unable to parse range | Config → `sheet_name` | Лист с таким названием не создан |
| Сообщения не приходят в Telegram | Чат | Бот не добавлен в чат или неверный chat id |
| Ошибка 401 у модели | Учётные данные модели | Неверный ключ или нет слова `Bearer ` перед ним |
| Модель отвечает, но оценки странные | Config → описание бизнеса | Слишком общее описание: опишите, кто идеальный клиент |
| Черновики не появляются | Лист Plan → `status`, `publish_at` | Статус не `idea` или до публикации больше `draft_ahead_hours` часов |
| Статус `failed`: не понял дату | Колонка `publish_at` | Формат: `2026-10-28 10:00` или ячейка с датой |
| Ошибка Telegram «chat not found» | Config → `channels.telegram.chat_id` | Неверный @username канала или бот не администратор |
| Ошибка 401 у WordPress | Учётные данные WordPress | Нужен пароль приложения, а не пароль от входа |
