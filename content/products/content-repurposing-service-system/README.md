# Content Repurposing Service System

Готовая услуга: из одного длинного видео клиента вы делаете 5 коротких видео, 3 поста, письмо, статью и план публикаций. В наборе — описание услуги, порядок работы, цепочка промптов, анкета клиента, порядок согласования, проверка качества и таблица цен.

## Файлы

- `service-overview.md` — что продаёте, кому, как устроена неделя
- `workflow.md` — порядок работы над комплектом: 11 шагов с временем
- `prompt-chain.json` — цепочка из 7 промптов: от карты видео до проверки фактов
- `client-intake.md` — анкета клиента и карточка голоса
- `approval-flow.md` — статусы, правила, готовые сообщения клиенту
- `quality-checklist.md` — проверка перед отправкой
- `pricing-sheet.csv` — три пакета с расчётом дохода за час
- `production-tracker.csv` — таблица производства

## С чего начать

1. Прочитайте `service-overview.md` и `workflow.md`.
2. Сделайте пробный комплект из любого открытого видео по `prompt-chain.json` — так вы узнаете своё реальное время.
3. Впишите это время в `pricing-sheet.csv` и поправьте цены.
4. Отправьте образец потенциальному клиенту. После согласия — анкета из `client-intake.md`.

## Лицензия

Можно использовать в своей работе и в проектах для клиентов. Нельзя перепродавать или выкладывать набор целиком.
