# CRM Automation Kit

Лёгкая CRM для малого бизнеса и агентств на n8n, Google Таблице и Telegram. Заявки из всех источников попадают в одну таблицу без дублей, сами распределяются между менеджерами, а менеджеры ведут сделки кнопками в Telegram. Бот напоминает о следующем шаге, поднимает тревогу, если заявку никто не взял, и раз в неделю присылает отчёт по воронке.

Подходит, когда платная CRM — это слишком, а таблица без автоматизации уже не справляется: 2–15 менеджеров, десятки и сотни заявок в месяц.

## Что делает

- **Один вход для всех заявок.** Формы сайта, Tilda, Make, Zapier, наборы Lead Generation и WhatsApp Sales Bot, ваш сервер — один адрес с токеном. Названия полей распознаются сами: `Name`, `Телефон`, `Comments`, `budget`…
- **Без дублей.** Телефон приводится к международному формату, почта — к нижнему регистру. Клиент с открытой сделкой пишет снова — запись в историю той же сделки. Клиент после закрытой сделки — новая сделка тому же менеджеру с отметкой «повторный».
- **Справедливое распределение.** Новая сделка — менеджеру с наименьшим числом открытых сделок; при равенстве — тому, кто дольше не получал заявку. Выключить менеджера (отпуск) — одно поле.
- **Сделки из Telegram.** Карточка с кнопками: Связались, Встреча, КП, Выиграна, Проиграна, Завтра. Ответ на карточку — заметка; «сумма: 1500»; «напомнить: завтра 15:00 перезвонить»; «причина: дорого». Команда /my — мои сделки и шаги.
- **Ничего не забыто.** Наступил следующий шаг — карточка менеджеру. Новую заявку два часа никто не взял — сообщение в чат команды. Сделка застряла на этапе — напоминание. Только в рабочее время, без повторов.
- **Отчёт по понедельникам.** Новые, выигранные и проигранные с суммами, конверсия, причины проигрышей, воронка по этапам, просроченные шаги, строка по каждому менеджеру.
- **Заявка не теряется**, если таблица недоступна: источник получает 503 и может повторить, команда — заявку целиком.

## Чем отличается от шаблона из интернета

Воркфлоу запускались в n8n 2.44 на подменных Google Таблицах и Telegram: неверный токен, тестовый запрос Tilda, форма Tilda, распределение, повторное обращение, кнопки этапов, напоминание ответом, выигрыш с уведомлением, /my, чужой чат, эскалация, отсутствие повторов, отчёт, недоступная таблица. Логика узлов Code проверена 9 сценариями, включая рабочие часы и часовой пояс. Подробности — `tests/scenarios.md`.

## Что нужно

- n8n с адресом в интернете по https.
- Google Таблица с листом `Deals`.
- Telegram-бот, чат команды; каждый менеджер один раз пишет боту /start.

Модель (AI) не нужна: набор работает на правилах и не отправляет данные клиентов сторонним сервисам, кроме Google и Telegram.

## С чего начать

1. `QUICKSTART.md` — запуск за 45 минут.
2. `CONTENTS.md` — что где лежит.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
