# Установка

## Импорт

1. В n8n: Workflows → Import from File. Импортируйте файлы по одному:
   - `workflows/crm-intake.n8n.json` — один адрес для заявок из всех источников: очистка, дедупликация, ответственный, карточка в Telegram
   - `workflows/crm-telegram.n8n.json` — кнопки этапов, заметки, суммы, напоминания и /my из Telegram
   - `workflows/crm-reminders.n8n.json` — напоминания о следующих шагах, эскалация и застрявшие сделки
   - `workflows/crm-weekly-report.n8n.json` — отчёт по воронке и менеджерам по понедельникам
   - `workflows/error-alert.n8n.json` — сообщение в Telegram о любом сбое
2. После импорта узлы, которым нужны учётные данные, подсвечены красным — их нужно выбрать (раздел ниже).
3. Откройте каждый воркфлоу → Settings → Error Workflow → выберите «Error Alert». Без этого о сбое вы узнаете от клиента.
4. Включите воркфлоу переключателем Active (Publish) вверху справа. Используйте Production URL, а не Test URL.

Воркфлоу проверены на n8n 2.44. На более старых версиях узлы могут называться иначе; обновите n8n, если импорт показывает неизвестные узлы.

## Учётные данные

Создайте в n8n (Credentials → Add credential) и выберите в подсвеченных узлах.

**Google Sheets** — тип Google Sheets OAuth2 API.
Войдите под аккаунтом, у которого есть доступ к таблице. Совет: отдельный аккаунт Google для автоматизации с доступом только к нужным таблицам.

**Telegram** — тип Telegram API.
Создайте бота через @BotFather (`/newbot`), вставьте токен. Добавьте бота в чат, куда должны приходить сообщения. Чтобы узнать chat id: напишите в чат любое сообщение и откройте `https://api.telegram.org/botТОКЕН/getUpdates` — в ответе будет `chat.id`. У групп он начинается с минуса.


## Менеджеры

Каждый менеджер один раз пишет боту в личку `/start`. Бот отвечает: «Ваш chat id: 123456789». Впишите его в `owners`:

```json
"owners": [
  { "name": "Олег", "chat_id": "123456789", "active": true },
  { "name": "Аня", "chat_id": "987654321", "active": true }
]
```

Имя должно совпадать во всех воркфлоу — по нему сделка связана с менеджером в таблице.

У одного Telegram-бота может быть только один Telegram Trigger. Если бот уже принимает сообщения в другом воркфлоу n8n, создайте для CRM отдельного бота.

## Config

Config есть в каждом воркфлоу; значения одинаковых полей должны совпадать.

| Поле | Что это |
|---|---|
| `spreadsheet_id` | Идентификатор таблицы — часть адреса между `/d/` и `/edit` |
| `deals_sheet` | Лист сделок. По умолчанию `Deals` |
| `intake_token` | Токен для источников заявок. Случайная строка |
| `team_chat_id` | Чат команды: новые сделки, выигрыши, брошенные заявки, отчёт |
| `report_chat_id` | Отдельный чат для отчёта. Пусто — чат команды |
| `currency` | Валюта в отчёте |
| `phone` | `country_code` — код страны без плюса; `national_prefix` — с чего начинаются местные номера (в Украине `0`) |
| `owners` | Менеджеры: имя, chat id, `active` |
| `first_action / first_contact_minutes` | Первый шаг для новой сделки и через сколько минут |
| `escalate_after_minutes` | Через сколько минут необработанная новая сделка уходит в чат команды |
| `remind_time` | Время для «Завтра» и «напомнить: завтра» без часа |
| `working_hours` | Рабочие дни и часы. Напоминания — только в это время |
| `stages` | Этапы воронки (`docs/01-how-it-works.md`) |

Пример заполненного Config — `templates/config.example.json`.

## Если что-то не работает

| Что видите | Где смотреть | Частая причина |
|---|---|---|
| Ничего не приходит | n8n → Executions | Воркфлоу не включён или используется Test URL вместо Production URL |
| Ошибка 401 или 403 у Google | Учётные данные Google | Истёк доступ — переподключите учётные данные |
| Ошибка 400 у Google: Unable to parse range | Config → `sheet_name` | Лист с таким названием не создан |
| Сообщения не приходят в Telegram | Чат | Бот не добавлен в чат или неверный chat id |
| Ошибка 401 у модели | Учётные данные модели | Неверный ключ или нет слова `Bearer ` перед ним |
| Модель отвечает, но оценки странные | Config → описание бизнеса | Слишком общее описание: опишите, кто идеальный клиент |
| Ответ 403 на заявку | Config → `intake_token` и адрес источника | Токен не передан или не совпадает |
| Ответ 422 | Тело заявки | Нет ни телефона, ни почты |
| Менеджер не получает карточки | `owners` → `chat_id` | Менеджер не писал боту /start или chat id с ошибкой |
| Кнопки не работают | Воркфлоу «Telegram» | Не включён, или тот же бот занят другим воркфлоу |
