# Памятка менеджеру

Распечатайте или закрепите в чате команды.

## Карточка сделки

Приходит в личку от бота: новая сделка, напоминание или «сделка без движения».

| Кнопка | Что происходит |
|---|---|
| Связались | Этап «Связались», следующий шаг — назначить встречу, через 2 дня |
| Встреча | Этап «Встреча», следующий шаг — отправить предложение, завтра |
| КП | Этап «КП отправлено», следующий шаг — узнать решение, через 3 дня |
| Выиграна | Сделка закрыта, команда получает поздравление |
| Проиграна | Сделка закрыта; ответьте на карточку «причина: …» |
| Завтра | Напомнить завтра утром |

## Ответ на карточку

Нажмите на карточку → Ответить, и напишите:

| Что написать | Что будет |
|---|---|
| Любой текст | Заметка в историю сделки |
| `сумма: 1500` | Сумма сделки |
| `напомнить: завтра 15:00 перезвонить` | Следующий шаг и время |
| `напомнить: 28.10 10:00 отправить договор` | Конкретная дата |
| `напомнить: через 3 дня` | Через три дня утром |
| `причина: выбрали дешевле` | Причина проигрыша (и закрытие, если ещё не закрыта) |

## Команды

- `/my` — мои открытые сделки и следующие шаги; ⚠️ — просрочено.
- `/start` — узнать свой chat id.

## Правила, которые делают CRM полезной

1. Связались с клиентом — сразу нажмите кнопку. Иначе через 2 часа о заявке узнает вся команда.
2. После каждого разговора — следующий шаг с датой. Сделка без шага — забытая сделка.
3. Проиграли — напишите причину. По причинам видно, что менять в продукте и цене.
