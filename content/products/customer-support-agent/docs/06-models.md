# Модели

Агенту нужна модель с вызовом инструментов (function calling / tool use). Узел AI Agent работает с любой такой моделью; модель подключается отдельным узлом.

## OpenAI — по умолчанию

Узел **OpenAI Chat Model**, модель `gpt-5-mini`. Её можно поменять в списке узла. Для поддержки по базе знаний обычно хватает модели класса mini; более сильная модель нужна, если база сложная или клиенты пишут длинные запутанные письма.

В узле выключен Responses API (`Use Responses API: off`) — агент ходит в обычный Chat Completions. Так тот же узел работает с OpenAI-совместимыми провайдерами.

## OpenAI-совместимые провайдеры

OpenRouter, Groq, Together, DeepSeek, Mistral, локальные модели через vLLM или Ollama — всё, что понимает формат Chat Completions с инструментами.

1. Создайте ключ типа OpenAI и в поле **Base URL** укажите адрес провайдера, например `https://openrouter.ai/api/v1`.
2. В узле OpenAI Chat Model выберите модель по ID (режим By ID) — так, как она называется в каталоге провайдера.

Проверьте в документации провайдера, что выбранная модель поддерживает tools. Модель без них будет отвечать, не заглядывая в базу знаний, — evals это сразу покажут.

## Claude (Anthropic)

В воркфлоу уже есть узел **Anthropic Chat Model** с моделью `claude-haiku-5-5`; он не подключён.

1. Создайте ключ Anthropic в console.anthropic.com и выберите его в узле.
2. Удалите связь от **OpenAI Chat Model** к входу Chat Model агента.
3. Протяните связь от **Anthropic Chat Model** к этому входу.
4. Опубликуйте и прогоните evals.

Для сложных диалогов поставьте `claude-sonnet-5-5`. Список актуальных моделей — в документации Anthropic.

Мы прогоняли воркфлоу с обоими узлами: инструменты, память и защита работают одинаково.

## Расход токенов

Одно сообщение клиента — обычно 2–3 обращения к модели: вопрос → поиск по базе → ответ. Каждое обращение отправляет:

| Что | Примерно токенов |
|---|---|
| системная инструкция | 1 300 |
| описания четырёх инструментов | 500 |
| память — до 12 последних сообщений | 0–2 000 |
| найденные статьи | 200–800 |

Итого 2 000–5 000 входящих токенов на обращение и 50–300 исходящих. Умножьте на цены своей модели — актуальные цены на сайте провайдера. Самые дорогие диалоги — длинные: уменьшите `Context Window Length` в узле Memory, если клиенты пишут много.

Защита от перерасхода — `daily_agent_runs` в Config. Ещё один предохранитель — месячный лимит в кабинете провайдера.

## Схемы инструментов вне n8n

`agent/tools.openai.json` и `agent/tools.anthropic.json` — те же четыре инструмента в форматах обоих API. Они пригодятся, если вы переносите агента в свой код: передайте массив в параметр `tools` запроса, а системную инструкцию — из `agent/system-prompt.md`, подставив значения вместо `{{company}}` и других полей в фигурных скобках. Тест набора проверяет, что схемы совпадают с инструментами в воркфлоу.
