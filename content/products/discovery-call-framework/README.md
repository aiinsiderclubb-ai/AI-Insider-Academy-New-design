# Discovery Call Framework

Набор для первого звонка с клиентом, которому вы продаёте AI-автоматизацию. Помогает за 30 минут понять процесс, посчитать цену проблемы и выйти с назначенным следующим шагом.

## Файлы

- `call-script.md` — сценарий звонка по минутам с готовыми формулировками
- `question-bank.md` — 60 вопросов по восьми темам
- `objections.md` — 10 возражений и ответы на них
- `follow-up-emails.md` — 6 писем после звонка
- `call-notes.csv` — бланк заметок с расчётом цены проблемы
- `qualification-scorecard.csv` — оценка клиента по 10 критериям

## С чего начать

1. Прочитайте `call-script.md` один раз целиком — он задаёт порядок разговора.
2. Перед звонком выберите 10–12 вопросов из `question-bank.md` под нишу клиента.
3. Во время звонка заполняйте `call-notes.csv` (импортируйте в Google Таблицы: формулы посчитают часы и стоимость).
4. После звонка оцените клиента в `qualification-scorecard.csv` и отправьте первое письмо из `follow-up-emails.md`.

## Лицензия

Можно использовать в своей работе и в проектах для клиентов. Нельзя перепродавать или выкладывать набор целиком.
