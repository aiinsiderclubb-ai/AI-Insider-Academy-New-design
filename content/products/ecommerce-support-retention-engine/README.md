# E-commerce Support & Retention Engine

Система для интернет-магазина на n8n: AI-ассистент отвечает покупателям про заказы и возвраты, а движок удержания возвращает брошенные корзины и собирает отзывы. Работает с Shopify, WooCommerce или с Google Таблицей.

## Что делает

**Ассистент магазина** — чат на сайте и в Telegram:
- **Статус заказа — только владельцу.** Номер заказа и email сверяются с магазином, чужому человеку ассистент не скажет даже, что заказ существует. Отслеживание — из данных перевозчика в заказе.
- **Возвраты по вашим правилам.** Срок, «финальная распродажа», невозвратные типы товаров, «товар был в использовании», дорогие заказы — всё в Config. Решение принимает код, а не модель: подходит, не подходит и почему, или нужен менеджер. Брак и «не тот товар» всегда идут к менеджеру — даже после срока.
- **Заявка на возврат, а не возврат денег.** Ассистент создаёт заявку в листе Returns и присылает её команде в Telegram. Деньги возвращает человек в админке магазина — ассистент не может это сделать и не обещает.
- **Ответы о доставке, оплате и гарантии** — только по правилам магазина из таблицы.
- **Передача человеку** при споре о деньгах, жалобе, несогласии с решением по возврату — с пересказом в чат команды.
- **Защита**: токен, лимиты, вырезание номеров карт, запрещённые обещания («деньги вернутся завтра» не уйдёт клиенту), служебная метка против утечки инструкции.

**Удержание**:
- **Брошенные корзины.** Каждые 30 минут: первое письмо через час, второе — через сутки, с промокодом, если вы его задали. Только тем, кто дал согласие на рассылку, не купил и не отписался. Одна корзина на адрес, тихие часы ночью. Первую фразу письма может написать модель — цены, скидки и ссылки она не пишет, их подставляет шаблон, а фраза с цифрами или скидкой заменяется шаблонной.
- **Отзывы.** Раз в день — просьба оставить отзыв через 7 дней после доставки. Один раз на заказ, не тем, у кого открыта заявка на возврат.
- **Отписка в один клик** по подписанной ссылке: чужой адрес по такой ссылке не отписать.
- **Журнал** всех писем в листе Messages: что, кому, какой шаг, кто написал первую фразу — модель или шаблон.
- **Плейбук удержания** — что измерять, в каком порядке запускать, какие эксперименты ставить.

## Платформы

| | Заказы для ассистента | Брошенные корзины | Отзывы |
|---|---|---|---|
| Shopify | Admin GraphQL API 2026-10 | `abandonedCheckouts` | доставленные заказы |
| WooCommerce | REST API v3 | события с вашего сайта → лист Carts | заказы в статусе «Выполнен» |
| Google Таблица | лист Orders | события → лист Carts | лист Orders |

## Как мы проверяли

Воркфлоу запускался в n8n 2.48 против подменных Shopify GraphQL, WooCommerce REST, Google Таблиц, Telegram, SMTP и моделей — в трёх вариантах: Shopify + OpenAI, WooCommerce + Claude, Google Таблица + OpenAI. Проверки — `docs/08-evals-and-operations.md`. Логика узлов Code покрыта отдельными тестами.

Запросы к Shopify сверены с документацией Admin GraphQL API 2026-10, но на настоящем магазине мы их не запускали. Перед запуском проверьте их на своём магазине по QUICKSTART.

## Что внутри

- `workflows/store-engine.n8n.json` — весь движок одним воркфлоу: ассистент, инструменты, корзины, отзывы, вебхуки.
- `workflows/error-alert.n8n.json` — сигнал в Telegram, если движок упал.
- `agent/system-prompt.md` — инструкция ассистента; `agent/cart-copy-prompt.md` — инструкция для первой фразы письма о корзине.
- `agent/tools.openai.json`, `agent/tools.anthropic.json` — схемы пяти инструментов в форматах обоих API.
- `templates/` — демо-правила магазина, демо-заказы, заголовки листов, чат-виджет.
- `evals/` — 30 случаев и скрипт прогона.
- `docs/` — 8 инструкций, включая плейбук удержания.

## Что нужно

- n8n 2.x с адресом по https.
- Shopify (приложение с Admin API) или WooCommerce (REST-ключ) — или просто Google Таблица.
- Google Таблица для правил, заявок и журналов.
- Почтовый ящик с SMTP для писем.
- Ключ модели: OpenAI, совместимый провайдер или Anthropic.
- Telegram-бот для команды.

## С чего начать

1. `QUICKSTART.md` — запуск за 1,5–2 часа.
2. `CONTENTS.md` — что где лежит.

## Лицензия

Можно использовать в своём магазине и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
