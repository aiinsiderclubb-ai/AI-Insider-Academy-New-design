# Модели

В движке две модели:
- **OpenAI Chat Model** — у ассистента (AI Agent), нужен вызов инструментов;
- **Copy Model** — пишет первую фразу письма о корзине (узел Cart Copy), инструменты не нужны.

Обе по умолчанию — `gpt-5-mini`, Responses API выключен, поэтому подходят OpenAI-совместимые провайдеры: укажите Base URL в ключе OpenAI и модель по ID.

## Claude

Рядом с ассистентом стоит **Anthropic Chat Model** (`claude-haiku-5-5`), не подключённый.
1. Создайте ключ Anthropic и выберите его в узле.
2. Удалите связь OpenAI Chat Model → Chat Model агента.
3. Протяните Anthropic Chat Model → Chat Model агента.

Для Copy Model так же: добавьте узел Anthropic Chat Model и подключите его к Cart Copy вместо Copy Model.

Мы прогоняли ассистента с обоими провайдерами: инструменты, проверка владельца, возвраты и защита работают одинаково.

## Расход

Ассистент — 2–4 обращения к модели на сообщение покупателя: инструкция около 1 500 токенов, описания пяти инструментов около 900, память, данные заказа. Фраза для корзины — одно короткое обращение на письмо, около 400 токенов. Цены — на сайте провайдера; потолок ассистента — `daily_agent_runs`.

Если `ai_personalize: false`, Copy Model не вызывается вообще.

## Схемы инструментов

`agent/tools.openai.json` и `agent/tools.anthropic.json` — пять инструментов в форматах обоих API, если переносите ассистента в свой код. Тест набора проверяет, что они совпадают с инструментами в воркфлоу.
