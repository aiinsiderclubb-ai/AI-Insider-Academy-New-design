# Knowledge Base Agent

AI-агент для n8n, который отвечает на вопросы по вашим документам — регламентам, инструкциям, политикам, справке — и показывает, из какого документа взят каждый факт. Чего в документах нет, он не придумывает: прямо говорит «в документах этого нет», а вопрос записывает в список пробелов базы.

Это RAG на векторном поиске: документы из папки Google Drive и страницы по ссылкам режутся на фрагменты, превращаются в эмбеддинги и ищутся по смыслу, а не по словам.

## Что делает

- **Собирает базу сам.** Папка Google Drive (Google Docs, PDF, TXT, Markdown) и список страниц в Google Таблице. Каждую ночь и по запросу индекс пересобирается: новые документы появляются, удалённые из папки исчезают.
- **Отвечает со ссылками.** Каждое утверждение — со ссылкой на документ, в конце — список источников с адресами. Ссылку на документ, которого поиск не находил, система удаляет из ответа.
- **Говорит «в документах этого нет».** Если поиск не нашёл достаточно близких фрагментов, агент не отвечает по памяти. Такой вопрос попадает в лист `Gaps` — готовый список того, что дописать в базу.
- **Передаёт людям** личные ситуации, исключения из правил, противоречия в документах и просьбы связаться с человеком — в Telegram-чат команды с пересказом.
- **Пускает только своих.** В Telegram — по списку ID; незнакомец получает отказ со своим ID, команда — одно уведомление в сутки. Веб — по токену.
- **Не выполняет команды из документов.** Текст документов — данные. Тестовый документ с «внедрённой» командой входит в набор.
- **Безопасная переиндексация.** Если папка не читается или не прочитан ни один документ, старый индекс остаётся. Итог — в чат команды и в лист `Documents`.
- **OpenAI, совместимые API или Claude** для ответов; эмбеддинги — через OpenAI-совместимый ключ.

## Чем отличается от шаблона из интернета

Воркфлоу запускался в n8n 2.48 против подменных Google Drive, Google Таблиц, Telegram, модели и эмбеддингов — отдельно с OpenAI и с Anthropic. 37 проверок: индексация Google Doc, PDF, Markdown и веб-страницы, пропуск неподдерживаемого файла, реестр документов, ответ со ссылкой и списком источников, удаление выдуманной ссылки, «нет в документах» с записью в `Gaps`, передача человеку, сбой Drive без потери индекса, исчезновение удалённого документа, доступ в Telegram по списку, токен. Логика узлов Code покрыта ещё 20 тестами.

Что не проверено у нас: качество ответов настоящей модели на ваших документах. Для этого в наборе 25 eval-случаев на демо-документах и скрипт прогона.

## Что внутри

- `workflows/knowledge-base-agent.n8n.json` — агент, инструменты и переиндексация в одном воркфлоу.
- `workflows/error-alert.n8n.json` — сигнал в Telegram, если что-то упало.
- `agent/system-prompt.md` — системная инструкция.
- `agent/tools.openai.json`, `agent/tools.anthropic.json` — схемы инструментов в форматах обоих API.
- `templates/demo-docs/` — 6 демо-документов для первого запуска и evals; `templates/*.csv` — заголовки листов.
- `evals/` — 25 случаев и скрипт прогона.
- `docs/` — устройство, настройка, каналы, поиск, production-хранилище, модели, evals, эксплуатация.

## Что нужно

- n8n 2.x — облако или свой сервер с адресом по https.
- Google Drive и Google Таблица.
- Ключ OpenAI или OpenAI-совместимого провайдера — для эмбеддингов (и ответов, если не Claude).
- Telegram-бот для чата команды.

## С чего начать

1. `QUICKSTART.md` — запуск примерно за час.
2. `CONTENTS.md` — что где лежит.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
