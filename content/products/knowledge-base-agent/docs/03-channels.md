# Каналы

## Telegram — основной канал для команды

Бот отвечает только пользователям из `allowed_telegram_ids`. Незнакомцу — «нет доступа» и его ID; в чат команды — одно уведомление в сутки на человека, чтобы его было легко добавить.

В группах бот видит сообщения, только если ему выдать права администратора или выключить Privacy Mode в @BotFather. Помните: все участники группы видят ответы, а значит, и документы.

Ответы уходят как HTML: номера ссылок и список источников со ссылками на документы.

## Веб и API

```
POST https://ВАШ-N8N/webhook/kb-agent
x-agent-token: ВАШ_AGENT_TOKEN          (или поле "token" в теле)

{"session_id": "intranet-48213", "message": "Как оформить командировку?",
 "name": "Анна", "email": "anna@company.com"}
```

Ответ:

```json
{
  "reply": "Командировку согласует руководитель отдела за 5 рабочих дней [1]...\n\nИсточники:\n1. Командировки — https://drive.google.com/...",
  "handoff": false,
  "session_id": "intranet-48213",
  "sources": [{"n": 1, "code": "d1", "title": "Командировки", "url": "https://drive.google.com/..."}]
}
```

`sources` — те же источники отдельно, чтобы ваш интерфейс мог показать их карточками. С заголовком `x-agent-debug` в ответе есть `tools` и `flags`.

**Про токен.** Внутренняя база знаний не должна быть публичной. Не кладите `agent_token` в код страницы, открытой всем: вызывайте вебхук со своего сервера или из интранета, где пользователь уже вошёл.

## Переиндексация по запросу

```
POST https://ВАШ-N8N/webhook/kb-reindex
x-agent-token: ВАШ_AGENT_TOKEN
```

Ответ `202 {"status": "started"}` приходит сразу, итог — в чат команды. Удобно повесить на кнопку в интранете или вызвать после загрузки документов.
