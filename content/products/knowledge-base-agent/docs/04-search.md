# Поиск, форматы и ссылки

## Форматы

| Источник | Как читается |
|---|---|
| Google Docs | экспорт в текст средствами Drive |
| PDF с текстовым слоем | извлечение текста; сканы без распознавания не читаются — в отчёте «в документе нет текста» |
| `.txt`, `.md` | как есть |
| страница по ссылке (лист Sources) | HTML без меню, скриптов, шапки и подвала |
| Word `.docx`, таблицы, презентации | не поддерживаются — откройте `.docx` в Google Docs («Открыть с помощью → Google Документы») и положите в папку получившийся документ |

Читается только сама папка, без подпапок, до 1000 файлов.

## Нарезка

Документ режется на фрагменты до `chunk_size` символов с перекрытием `chunk_overlap`. Режет Recursive Character Text Splitter: сначала по пустым строкам между абзацами, затем по переносам строк, затем по словам. Для старта — 1200 / 200. Если документы — короткие ответы FAQ, попробуйте 600 / 100; длинные юридические тексты — 2000 / 300. Каждое изменение проверяйте прогоном evals.

Хорошо ищутся документы, в которых:
- у разделов есть заголовки;
- один раздел — одна тема;
- цифры и условия написаны рядом с тем, к чему относятся.

## Порог

`min_score` — насколько фрагмент должен быть близок к вопросу, чтобы агент им пользовался. Оценка — косинусная близость эмбеддингов, от 0 до 1.

- Агент говорит «в документах нет», хотя ответ есть → снизьте порог на 0.05 и прогоните evals.
- Агент отвечает по фрагментам «не про то» → поднимите на 0.05.

Подбирайте по листу `Log`: колонка `sources` пустая при пометке `not_found` — значит, ничего не прошло порог. 0.35 — стартовая точка, а не проверенное значение: шкала близости у каждой модели эмбеддингов своя, поэтому порог настраивается по evals на ваших документах.

## Ссылки

Каждый фрагмент приходит модели с кодом документа: `[d3]`. Модель ставит коды после утверждений. Guard Out:

1. удаляет коды документов, которых поиск в этом ответе не возвращал (`bad_citation`);
2. заменяет коды номерами `[1]`, `[2]` по порядку появления;
3. добавляет «Источники:» — название и адрес каждого документа.

Адреса пишет система, а не модель, поэтому выдуманной ссылки в ответе быть не может. Но модель может поставить верную ссылку к утверждению, которого в документе нет, — это ловят только evals и выборочная проверка журнала.
