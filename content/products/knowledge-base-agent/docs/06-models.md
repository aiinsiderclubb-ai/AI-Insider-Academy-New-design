# Модели

Агенту нужны две модели: **чат-модель** с вызовом инструментов — для ответов, и **модель эмбеддингов** — для индекса и поиска.

## Эмбеддинги

Узел **Embeddings** — OpenAI `text-embedding-3-small`. Один узел подключён и к индексации, и к поиску: вопрос и документы должны превращаться в векторы одной и той же моделью.

- Сменили модель эмбеддингов — обязательно переиндексация: старые векторы с новыми несравнимы.
- OpenAI-совместимые провайдеры — через ключ OpenAI с Base URL, если провайдер поддерживает `/v1/embeddings`.
- Другие провайдеры — замените узел на Embeddings Cohere, Mistral, Google Gemini, Ollama и т. д. и переиндексируйте.
- Порог `min_score` настраивается под модель эмбеддингов — `docs/04-search.md`.

У Anthropic своих эмбеддингов нет, поэтому даже с Claude для ответов нужен ключ провайдера эмбеддингов.

## Чат-модель

По умолчанию — **OpenAI Chat Model**, `gpt-5-mini`, Responses API выключен, чтобы работали совместимые провайдеры (Base URL в ключе).

**Claude:** в воркфлоу есть **Anthropic Chat Model** (`claude-haiku-5-5`). Удалите связь от OpenAI Chat Model к агенту, протяните от Anthropic Chat Model, опубликуйте, прогоните evals. Для длинных регламентов и сложных вопросов — `claude-sonnet-5-5`.

Воркфлоу прогонялся на стенде с обоими узлами — инструменты, ссылки и защита работают одинаково.

## Расход

**Индексация:** каждый фрагмент — один раз через модель эмбеддингов при каждой переиндексации. Ночная переиндексация пересчитывает всё. 100 документов по 10 страниц — порядка нескольких тысяч фрагментов; у моделей эмбеддингов это обычно дёшево, но посчитайте по цене своей модели: символов в документах ÷ 4 ≈ токенов. Если документы меняются редко — переиндексируйте реже.

**Вопрос:** один эмбеддинг запроса на каждый поиск и 2–3 обращения к чат-модели. Во входе каждого обращения — инструкция (~1 000 токенов), описания инструментов, память диалога и найденные фрагменты (до 5 × 1 200 символов). Актуальные цены — на сайте провайдера. Предохранитель — `daily_agent_runs`.
