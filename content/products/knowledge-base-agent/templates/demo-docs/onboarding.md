# Онбординг нового сотрудника

## Первый день
Новому сотруднику выдают ноутбук в первый рабочий день. Учётные записи в почте, чатах и HR-портале создаёт служба IT-поддержки до 12:00 первого дня.

## Наставник
За каждым новым сотрудником закрепляется наставник на испытательный срок — 3 месяца.

## Удалённая работа
В испытательный срок можно работать удалённо до 3 дней в неделю по согласованию с наставником.
