# Политика удалённой работы

Сотрудники после испытательного срока могут работать удалённо 2 дня в неделю. Дни согласуются с руководителем на месяц вперёд.

Полностью удалённая работа возможна только по решению директора по персоналу.

Для работы из дома компания компенсирует интернет — 300 грн в месяц, по заявлению в HR-портале.
