# Информационная безопасность

## Пароли
Пароль должен быть не короче 12 символов и меняться раз в 90 дней. Один пароль нельзя использовать в разных сервисах.

## Двухфакторная аутентификация
Двухфакторная аутентификация обязательна для почты, HR-портала и облачных хранилищ.

## Потеря ноутбука или телефона
О потере рабочего устройства сообщите в IT-поддержку немедленно, по телефону 1234 или в канал #it-help. IT заблокирует устройство удалённо.
