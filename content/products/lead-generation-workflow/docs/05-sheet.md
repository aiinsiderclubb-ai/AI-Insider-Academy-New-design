# Таблица заявок

Лист `Leads`. Заголовки воркфлоу пишет сам с первой заявкой. Не меняйте порядок столбцов и не вставляйте столбцы между ними: воркфлоу пишет по позициям. Свои столбцы добавляйте справа, после `notes`.

| Столбец | Поле | Что это |
|---|---|---|
| A | `id` | Номер заявки, например `L261026-YQXN1` |
| B | `created_at` | Когда пришла первая заявка (UTC) |
| C | `source` | Источник: tilda, site, google-forms, form |
| D | `form` | Форма |
| E | `name` | Имя |
| F | `phone` | Телефон в международном виде |
| G | `email` | Почта |
| H | `message` | Текст и прочие поля формы |
| I | `utm_source` | Метка |
| J | `utm_medium` | Метка |
| K | `utm_campaign` | Метка |
| L | `page` | Страница без параметров |
| M | `score` | Оценка 1–5 |
| N | `intent` | Намерение |
| O | `summary` | Кратко от модели |
| P | `status` | Статус — меняет менеджер |
| Q | `owner` | Ответственный — вписывает менеджер |
| R | `touches` | Сколько раз человек обращался |
| S | `last_touch_at` | Последнее обращение (UTC) |
| T | `reminded_level` | Служебное: сколько напоминаний отправлено |
| U | `notes` | Что уточнить, повторные сообщения |

## Статусы

| Статус | Когда ставить | Что происходит |
|---|---|---|
| `new` | Ставит воркфлоу | Напоминания идут, пока статус не изменится |
| `in_progress` | Менеджер связался | Напоминания прекращаются |
| `won` | Сделка | — |
| `lost` | Отказ | Если человек напишет снова — статус вернётся в `new` |
| `spam` | Ставит воркфлоу или менеджер | Повтор от этого контакта не считается повтором |

Договоритесь с командой об одном правиле: **связался — поменял статус**. Иначе напоминания будут приходить по уже обработанным заявкам.

## Удобные настройки таблицы

- Закрепите первую строку и столбцы A–F.
- Для столбца `status` — Данные → Проверка данных → раскрывающийся список из пяти статусов.
- Условное форматирование: `score` ≥ 4 — зелёный фон; `status` = `new` — жирный шрифт.
- Фильтр по `status` = `new` — список того, что нужно сделать.

## Если таблица выросла

Google Таблицы работают быстро до десятков тысяч строк. Раз в квартал переносите закрытые заявки (`won`, `lost`, `spam`) на лист `Archive`: воркфлоу читает только лист `Leads`.

Шаблон заголовков — `templates/leads-sheet-header.csv`.
