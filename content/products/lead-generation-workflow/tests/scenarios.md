# Как проверены воркфлоу

## Логика узлов Code — 11 сценариев

1. Неверный токен — 403; тестовый запрос конструктора — 200 без записи; нет контактов — 422; нечитаемый телефон — 422.
2. Форма Tilda: поля распознаны, телефон и почта приведены к одному виду, таблица получила заголовок, горячая заявка ушла в горячий чат, письмо клиенту подготовлено.
3. Двойной клик в течение двух минут не создаёт ничего.
4. Тот же человек позже обновляет свою строку: счётчик обращений, заметки, сообщение «Повторное обращение».
5. Спам получает обычный ответ, пишется со статусом spam, никому не сообщается, в модель не уходит.
6. Модель не ответила — оценка по правилам; модель ответила не JSON — оценка по правилам; инструкция модели запрещает выполнять команды из текста заявки.
7. Вложенный JSON, список полей и токен в заголовке; метки UTM из адреса страницы.
8. Конверт Webflow: поля из payload.data, название формы не становится именем человека.
9. Модель выключена — правила.
10. Напоминания: первое через 15 минут, руководителю через час, каждое один раз, ночью — никаких.
11. Отчёт: считает вчерашние заявки, не считает спам, показывает, кто ждёт.

## Запуск в n8n 2.44

Воркфлоу импортированы в n8n и вызваны по HTTP. Google Таблицы, модель, Telegram и почта заменены локальным сервером, который отвечает так же, как настоящие API.

- Неверный токен → 403.
- Тестовый запрос Tilda → 200 «ok».
- Нет контактов → 422.
- Форма Tilda в формате url-encoded → 200; запрос к модели; новая строка с заголовком; сообщение в горячий чат; письмо клиенту.
- Повтор того же человека → PUT в его строку, «Повторное обращение (2-е)».
- Спам → строка spam, без модели и сообщений.
- Модель вернула не JSON → оценка по правилам, строка записана.
- SLA Reminder → одно сообщение по двум заявкам, отметка в таблице.
- Daily Report → отчёт с источниками, кампанией, спамом и списком ждущих.

## Что не проверялось

- Работа с настоящими Google Таблицами, Telegram и почтой под вашими учётными данными — это проверяют запросы из `test-requests.md`.
- Качество оценки конкретной моделью на ваших заявках — это настраивается в первую неделю.
- Отдельные конструкторы форм: формат Tilda проверен; остальные описаны по их документации.
