# Lead Qualification Agent

AI-агент квалификации входящих заявок для n8n. Принимает заявки с любых форм, находит дубли, изучает сайт компании, оценивает лида по вашей рубрике с понятными причинами, назначает менеджера по кругу и присылает ему карточку в Telegram — за минуту после отправки формы.

## Что делает

- **Принимает заявки откуда угодно.** Своя форма, Tilda, Webflow, WordPress, Google Forms, CRM, Make — поля распознаются сами. Форма получает ответ сразу, оценка идёт после.
- **Чистит вход.** Телефон к международному виду, ловушка для ботов, двойной клик, обязательный контакт.
- **Находит дубли** по почте, телефону и домену компании за 90 дней: повторная заявка — в ту же строку и тому же менеджеру.
- **Изучает компанию.** Модель открывает до трёх страниц сайта лида: чем занимается, сколько людей, есть ли смысл звонить. Открывать можно только сайт самого лида.
- **Оценивает честно.** Модель отвечает на узкие вопросы с вариантами из списка: подходит ли под идеального клиента, ясен ли запрос, размер, сроки, красные флаги. Баллы 0–100 по вашей рубрике считает код — у каждого балла есть причина.
- **Отсеивает мусор:** соискателей, студентов, спам, конкурентов и тех, кто продаёт вам. Такие лиды остаются в CRM, но никому не назначаются.
- **Распределяет** по сегментам (малый бизнес и крупные компании) и по кругу между активными менеджерами. Отпуск — одна галочка.
- **Карточка менеджеру:** баллы с причинами, суть в двух предложениях, вопросы для первого звонка. Горячие и спорные — ещё и в чат отдела.
- **По желанию — письмо лиду** с уточняющими вопросами, чтобы менеджер звонил уже с ответами.
- **Не теряет заявку:** если CRM недоступна или модель не ответила, лид всё равно приходит в Telegram.
- **OpenAI, любой OpenAI-совместимый API или Claude.**

## Чем отличается от шаблона из интернета

Воркфлоу запускался в n8n 2.48 против подменных Google Таблиц, Telegram, почты и моделей — отдельно с OpenAI и с Anthropic, с локальным «сайтом лида»: 26 проверок — от изучения страниц и исправления неверной оценки до защиты от запросов к внутренним адресам и сбоя CRM. Логика узлов Code покрыта 22 тестами. Подробнее — `docs/07-evals.md`.

Что не проверено у нас: насколько точно настоящая модель оценивает ваших лидов. Для этого — 16 eval-случаев и скрипт прогона.

## Что внутри

- `workflows/lead-qualification-agent.n8n.json` — приём, дубли, агент с двумя инструментами, рубрика, маршрутизация, CRM, уведомления.
- `workflows/error-alert.n8n.json` — сигнал в Telegram, если воркфлоу упал.
- `agent/system-prompt.md` — инструкция модели.
- `agent/tools.openai.json`, `agent/tools.anthropic.json` — схемы инструментов для обоих API.
- `templates/` — HTML-форма заявки, заголовки листа CRM.
- `evals/` — 16 тестовых заявок и скрипт прогона.
- `docs/` — устройство, настройка, формы, рубрика и маршрутизация, защита, модели, evals, эксплуатация.

## Что нужно

- n8n 2.x с адресом по https.
- Google Таблица.
- Ключ модели: OpenAI, совместимый провайдер или Anthropic.
- Telegram-бот, которому менеджеры написали `/start`.
- По желанию — SMTP для уточняющих писем.

## Чем отличается от наших наборов

- **Lead Generation Workflow** собирает заявки и оценивает их одной подсказкой модели 1–5; этот агент сам изучает сайт, считает баллы по вашей рубрике с причинами и распределяет по сегментам и кругу.
- **Sales Agent** разговаривает с клиентом в чате; этот агент работает с заявками с форм и клиенту не пишет, кроме уточняющего письма.
- **CRM Automation Kit** ведёт сделки менеджеров; квалифицированных лидов отсюда можно передавать туда вебхуком.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
