# Модели

Агенту нужна модель с вызовом инструментов (function calling / tool use). Узел AI Agent работает с любой такой моделью; модель подключается отдельным узлом.

## OpenAI — по умолчанию

Узел **OpenAI Chat Model**, модель `gpt-5-mini`. Её можно поменять в списке узла. Для оценки заявок обычно хватает модели класса mini; более сильная модель точнее различает отрасли и размер компании по сайту.

В узле выключен Responses API (`Use Responses API: off`) — агент ходит в обычный Chat Completions. Так тот же узел работает с OpenAI-совместимыми провайдерами.

## OpenAI-совместимые провайдеры

OpenRouter, Groq, Together, DeepSeek, Mistral, локальные модели через vLLM или Ollama — всё, что понимает формат Chat Completions с инструментами.

1. Создайте ключ типа OpenAI и в поле **Base URL** укажите адрес провайдера, например `https://openrouter.ai/api/v1`.
2. В узле OpenAI Chat Model выберите модель по ID (режим By ID) — так, как она называется в каталоге провайдера.

Проверьте в документации провайдера, что выбранная модель поддерживает tools. Модель без них не сдаст оценку — каждый лид получит флаг «проверьте вручную».

## Claude (Anthropic)

В воркфлоу уже есть узел **Anthropic Chat Model** с моделью `claude-haiku-5-5`; он не подключён.

1. Создайте ключ Anthropic в console.anthropic.com и выберите его в узле.
2. Удалите связь от **OpenAI Chat Model** к входу Chat Model агента.
3. Протяните связь от **Anthropic Chat Model** к этому входу.
4. Опубликуйте и прогоните evals.

Для сложного B2B поставьте `claude-sonnet-5-5`. Список актуальных моделей — в документации Anthropic.

Мы прогоняли воркфлоу с обоими узлами: инструменты и оценка работают одинаково.

## Расход токенов

Одна заявка — 2–5 обращений к модели: чтение заявки → 0–3 страницы сайта → оценка → «готово». Каждое обращение отправляет:

| Что | Примерно токенов |
|---|---|
| системная инструкция с описанием предложения и идеального клиента (около 4 000 символов) | 1 000–1 500 |
| описания двух инструментов | 300–500 |
| заявка | 100–800 |
| страницы сайта — до `page_chars` символов каждая | 0–4 000 на страницу |

Итого обычно 3 000–15 000 входящих токенов на заявку. Оценка по объёму текста, а не замер у провайдера. Дешевле — уменьшить `max_pages` и `page_chars` или выключить `research_website`.

## Схемы инструментов вне n8n

`agent/tools.openai.json` и `agent/tools.anthropic.json` — те же два инструмента в форматах обоих API. Они пригодятся, если вы переносите агента в свой код: передайте массив в параметр `tools` запроса, а системную инструкцию — из `agent/system-prompt.md`, подставив значения вместо `{{company}}` и других полей в фигурных скобках. Тест набора проверяет, что схемы совпадают с инструментами в воркфлоу.
