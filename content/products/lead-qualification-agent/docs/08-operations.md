# Эксплуатация

## Каждый день

Менеджеры работают по карточкам в Telegram и ведут `status` в листе `Leads`: `new` → `contacted` → `meeting` → `won` / `lost`. Чат отдела показывает горячих, лидов без менеджера и «проверьте вручную».

## Раз в месяц — калибровка

Отфильтруйте `Leads` за месяц и сравните `tier` с исходом:
- горячие, которые не купили, — что общего? Уменьшите вес этого критерия;
- купившие холодные — чего не увидела рубрика? Добавьте критерий или уточните `ideal_customer`;
- `disqualified`, которые оказались клиентами — уточните описание флага в `ideal_customer`.

После правки — evals.

## Приватность

- В лист `Leads` и в модель попадают данные формы. Текст сайта лида — публичный.
- Укажите обработку данных в политике конфиденциальности и в чекбоксе формы.
- Срок хранения — ваш; дубли ищутся только за `dedupe_days`.
- Уточняющее письмо — ответ на заявку, а не рассылка. Не включайте его для купленных или чужих баз.

## Изменения

- **Рубрика, менеджеры, сегменты** — в Config, действуют сразу.
- **Инструкция** — правьте `agent/system-prompt.md`, затем перенесите в узел AI Agent → Options → System Message, не трогая ссылки на Config в двойных фигурных скобках.
- **Новое поле формы** — добавьте его в узел Intake (функция `pick`) и, если нужно, в рубрику.

## Неполадки

| Симптом | Причина |
|---|---|
| 401 на всё | заглушка в `agent_token` или токен не передан |
| 404 | воркфлоу не опубликован |
| у всех лидов «проверьте вручную» | модель без tools или ключ модели не работает — откройте выполнение в n8n |
| дубли не находятся | неверный `spreadsheet_id` или нет листа `Leads`; в карточке будет «CRM не прочиталась» |
| все лиды одному менеджеру | у остальных `active: false` или не тот сегмент; воркфлоу не опубликован — счётчик не сохраняется |
| карточки не приходят | менеджер не писал боту `/start`, неверный `chat_id` |
| модель не видит сайт | сайт закрыт от роботов, отдаёт ошибку или собран без текста в HTML |
