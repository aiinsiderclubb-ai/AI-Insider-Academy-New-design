# Marketing Prompt Vault

50 промптов. Текст в [квадратных скобках] замените своим.

## Стратегия и аудитория

С кем говорим и что обещаем. Без этого реклама и тексты стреляют наугад.

### 1. Сегменты аудитории

```
Продукт: [что]. Покупатели сейчас: [описание]. Раздели аудиторию на 3–4 сегмента по ситуации, а не по возрасту. Для каждого: что происходит в жизни перед покупкой, главный мотив, главное сомнение, где его найти.
```

### 2. Путь клиента

```
Продукт: [что], цикл покупки: [сколько]. Опиши путь от первого касания до повторной покупки по этапам. На каждом: что человек думает, что ему мешает двинуться дальше, какой материал или действие помогает.
```

### 3. Сообщение под сегмент

```
Сегмент: [описание]. Продукт: [что]. Напиши ключевое сообщение для этого сегмента: одна главная мысль, три подтверждения, одно слово, которое нельзя использовать, потому что оно их отпугивает.
```

### 4. Маркетинговый план на квартал

```
Бизнес: [что], бюджет: [сумма], цель: [заявки / продажи в цифрах]. Составь план на 12 недель: 3 канала, для каждого — что делаем, сколько тратим, какой результат ждём, по какому признаку через месяц поймём, что канал не работает.
```

### 5. Гипотезы для проверки

```
Сейчас заявки стоят [сумма], конверсия [процент]. Предложи 10 гипотез улучшения. Оцени каждую по влиянию, уверенности и трудоёмкости. Выбери 3 для проверки в этом месяце и опиши, как именно проверять.
```

### 6. Анализ конкурентной рекламы

```
Вот объявления конкурентов: [тексты]. Что они обещают, на какую боль давят, чем доказывают. Какие углы используют все, а какой никто. Предложи 3 угла, которые выделят меня.
```

### 7. Бриф для подрядчика

```
Нужно [задача: лендинг / реклама / видео]. Напиши бриф: цель в цифрах, аудитория, главное сообщение, что обязательно должно быть, чего быть не должно, примеры того, что нравится, срок, как принимаем работу.
```

### 8. Позиционирование одной фразой

```
Продукт: [что], для [кто], в отличие от [альтернатива]. Дай 6 вариантов позиционирования по формуле «для кого — что это — чем отличается — почему верить». Отметь тот, который легко повторить вслух.
```

### 9. Запуск нового продукта

```
Запускаю [что] через [срок]. Аудитория: [размер и где]. Составь план запуска: что делаем за 3 недели до, в неделю запуска, в две недели после. Для каждого шага — канал, материал, цель.
```

### 10. Разбор воронки

```
Этапы воронки и цифры: [показы, клики, заявки, продажи]. Найди этап с наибольшей потерей относительно обычных значений для [ниша]. Дай 3 причины и по одному тесту на каждую.
```

## Реклама

Объявления, которые не обещают лишнего и говорят с одним человеком.

### 11. Объявления для поиска

```
Продукт: [что], запрос: [ключ], посадочная: [что на ней]. Напиши 5 объявлений: заголовки до 30 знаков, описания до 90. В каждом — другой угол: цена, срок, результат, гарантия, отличие. Обещание должно совпадать с посадочной.
```

### 12. Объявления для соцсетей

```
Продукт: [что], сегмент: [кто]. Напиши 4 объявления: первая строка, текст до 60 слов, заголовок, призыв. Углы: проблема, результат, история клиента, вопрос. Без «устали от…» и «хотите…».
```

### 13. Идеи креативов

```
Продукт: [что], аудитория: [кто]. Предложи 8 идей креативов: 4 статичных и 4 видео до 20 секунд. Для каждой: что в кадре, текст на картинке, почему это остановит прокрутку. Без стоковых улыбающихся людей.
```

### 14. Сценарий рекламного ролика

```
Продукт: [что], длина: 20 секунд. Напиши сценарий по секундам: крючок 0–2, проблема 2–7, решение 7–15, призыв 15–20. Что в кадре, что звучит, что написано. Должно работать без звука.
```

### 15. Тест объявлений

```
Вот объявление: [текст]. Создай 5 вариаций для теста, меняя по одному элементу: заголовок, первая строка, выгода, призыв, формат. Для каждой — какую гипотезу проверяем.
```

### 16. Разбор результатов кампании

```
Кампании и цифры: [таблица с расходом, кликами, заявками]. Что отключить, что масштабировать, что переписать. Для каждого решения — на какую цифру опираешься. Не делай выводов по объявлениям с малым числом показов.
```

### 17. Ретаргетинг

```
Человек был на странице [что] и не оставил заявку. Напиши 3 объявления для ретаргетинга с интервалом в несколько дней: ответ на сомнение, кейс, ограниченное по смыслу предложение. Без «вы забыли» и чувства слежки.
```

### 18. Аудитории для таргетинга

```
Продукт: [что], клиент: [описание]. Предложи 6 аудиторий для рекламы в [площадка]: по интересам, по поведению, похожие, по должности. Для каждой — почему она подойдёт и что в объявлении сказать именно ей.
```

### 19. Посадочная под объявление

```
Объявление: [текст]. Что человек ожидает увидеть после клика? Составь структуру посадочной, продолжающей обещание объявления слово в слово в первом экране. Что убрать, чтобы не отвлекать от одного действия.
```

### 20. Бюджет на тест

```
Хочу протестировать [канал] для [продукт], средний чек [сумма]. Сколько нужно потратить, чтобы получить вывод, а не шум? Объясни расчёт через стоимость клика и ожидаемую конверсию. Что считать успехом.
```

## Лендинги и конверсия

Одна страница — одно действие.

### 21. Структура лендинга

```
Продукт: [что], аудитория: [кто], источник трафика: [откуда]. Составь структуру лендинга по блокам в порядке вопросов посетителя: что это, для меня ли, как работает, почему верить, сколько стоит, что делать. Для каждого блока — задача.
```

### 22. Заголовки для теста

```
Продукт: [что], результат: [что получает клиент]. Напиши 10 заголовков первого экрана: 3 про результат, 3 про проблему, 2 с цифрой, 2 от лица клиента. До 9 слов каждый.
```

### 23. Блок социального доказательства

```
У меня есть: [отзывы, цифры, логотипы, кейсы]. Как расположить это на странице, чтобы работало. Что поставить рядом с кнопкой, что — после цены. Чего из этого лучше не показывать и почему.
```

### 24. Форма заявки

```
Форма сейчас: [поля]. Что можно убрать, чтобы повысить конверсию, не потеряв нужное для продаж. Напиши заголовок формы, подписи, текст кнопки и сообщение после отправки с понятным следующим шагом.
```

### 25. Страница благодарности

```
После заявки на [что] человек видит страницу «спасибо». Напиши её: что будет дальше и когда, чем заняться, пока ждёт, одно дополнительное действие. Не оставляй тупик.
```

### 26. Аудит конверсии

```
Вот текст лендинга по блокам: [текст]. Конверсия [процент]. Найди 5 мест, где посетитель теряется или сомневается. Для каждого — что именно мешает и как переписать. По убыванию влияния.
```

### 27. Лид-магнит

```
Аудитория: [кто], продукт: [что]. Предложи 6 идей лид-магнита, которые решают маленькую задачу за 10 минут и подводят к продукту. Для каждой: название, формат, что внутри, почему после неё логично купить.
```

### 28. Квиз

```
Продукт: [что]. Составь квиз из 5 вопросов, который помогает человеку подобрать вариант и одновременно квалифицирует заявку. Варианты ответов, логика результата, текст финального экрана.
```

### 29. Попап без раздражения

```
Сайт: [о чём]. Нужен попап для сбора контактов. Когда его показывать, что предложить, какой текст. Дай 3 варианта и правила: кому и когда не показывать вовсе.
```

### 30. План A/B-тестов

```
Страница: [описание], трафик [посетителей в месяц], конверсия [процент]. Составь очередь из 5 тестов по убыванию ожидаемого эффекта. Для каждого: гипотеза, что меняем, сколько ждать результата при моём трафике.
```

## Email и удержание

Клиент, который уже купил, дешевле нового.

### 31. Карта писем

```
Продукт: [что], цикл: [покупка разовая / подписка]. Составь карту автоматических писем: после регистрации, после покупки, при бездействии, перед окончанием, после отзыва. Для каждого — триггер, цель, одно действие.
```

### 32. Серия прогрева

```
Подписчик скачал [лид-магнит]. Продукт: [что]. Напиши серию из 5 писем на 10 дней: польза, ошибка, кейс, ответ на возражение, предложение. Тема, первая строка, тезисы и призыв для каждого.
```

### 33. Письмо-предложение

```
Предложение: [что, цена, срок]. Аудитория уже знает продукт. Напиши письмо до 150 слов: зачем сейчас, что входит, для кого это, как купить. Одна ссылка, повторённая дважды.
```

### 34. Реактивация

```
Подписчики не открывают письма [срок]. Напиши 2 письма: первое — что нового и вопрос, интересно ли им это; второе — честное «отпишем, если не ответите». Темы писем — без уловок.
```

### 35. Сегментация базы

```
В базе [число] контактов, знаю о них: [поля]. Предложи 5 сегментов, для которых стоит писать разное. Для каждого — чем отличается сообщение и какое первое письмо отправить.
```

### 36. Письмо после первой покупки

```
Клиент купил [что] впервые. Напиши письмо: как получить первый результат за 15 минут, типичная ошибка новичков, куда писать с вопросом. Цель — чтобы он воспользовался покупкой, а не забыл о ней.
```

### 37. Программа рекомендаций

```
Продукт: [что], чек [сумма]. Спроектируй программу рекомендаций: что получает тот, кто рекомендует, что — новый клиент, когда и как об этом сказать. Напиши письмо-приглашение до 90 слов.
```

### 38. Сбор отзывов

```
Клиент пользуется [что] уже [срок]. Напиши письмо с просьбой об отзыве: в какой момент его слать, 3 вопроса-подсказки, куда оставить. И письмо-благодарность после отзыва.
```

### 39. Возврат брошенной корзины

```
Человек добавил [что] и не оплатил. Напиши 3 письма: через час, через день, через три. Первое помогает, второе отвечает на сомнение, третье напоминает в последний раз. Без скидки в первом письме.
```

### 40. Разбор рассылки

```
Показатели письма: открытия [процент], клики [процент], отписки [процент]. Тема и текст: [текст]. Что сработало, что нет, какие 3 изменения попробовать в следующем письме.
```

## Контент и бренд

Что говорить регулярно, чтобы вас узнавали и вам верили.

### 41. Темы на месяц

```
Бренд: [что], аудитория: [кто]. Дай 16 тем контента на месяц в четырёх рубриках: польза, закулисье, мнение, клиенты. Для каждой — формат и какую мысль о бренде она закрепляет.
```

### 42. Голос бренда

```
Бренд: [что], клиенты: [кто]. Опиши голос бренда: 4 характеристики, каждая с примером «так говорим — так не говорим». Список из 10 слов, которые используем, и 10, которые запрещены.
```

### 43. История бренда

```
Факты: [как появился, что было трудно, что изменилось]. Напиши историю бренда до 200 слов: с какой проблемы началось, что решили делать иначе, для кого работаем. Без пафоса и «миссии».
```

### 44. Кейс из интервью

```
Вот расшифровка разговора с клиентом: [текст]. Собери кейс: ситуация до, почему выбрал нас, что сделали, результат, цитата из его слов. Не придумывай цифр и не улучшай цитаты.
```

### 45. Пресс-релиз

```
Новость: [что произошло]. Напиши пресс-релиз: заголовок-факт, первый абзац отвечает на «что, кто, когда, зачем», цитата руководителя по делу, справка о компании. До 250 слов.
```

### 46. Ответ на кризис

```
Произошло: [ситуация]. Что известно точно: [факты]. Напиши публичное заявление: что случилось, что мы уже сделали, что сделаем и когда, куда обращаться. Без «приносим извинения за доставленные неудобства».
```

### 47. Коллаборация

```
Мой бренд: [что]. Хочу совместный проект с [кто]. Чем мы полезны друг другу? Предложи 4 формата коллаборации и напиши первое письмо с предложением до 100 слов.
```

### 48. Экспертная статья

```
Тема: [тема], моя позиция: [что я думаю, вопреки общему мнению]. Составь план колонки: тезис, три аргумента с примерами, главное возражение и ответ на него, вывод. Заголовок — утверждение, а не вопрос.
```

### 49. Подкаст или интервью

```
Иду гостем в [подкаст / издание], тема: [тема]. Подготовь: 3 истории из практики, которые стоит рассказать, 5 коротких формулировок главных мыслей, ответ на неудобный вопрос [какой].
```

### 50. Итоги месяца

```
Что делали в маркетинге за месяц: [список]. Цифры: [результаты]. Собери итог на одну страницу: что дало результат, что нет, что повторим, от чего откажемся, план на следующий месяц из 3 пунктов.
```
