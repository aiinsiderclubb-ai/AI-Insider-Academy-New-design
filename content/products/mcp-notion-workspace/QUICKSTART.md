# Запуск примерно за час

## 1. База знаний и таблица (15 минут)

**База знаний** — база данных Notion, где одна строка — одна статья. Нужны:
- название (колонка типа Title) — вопрос или тема: «Сроки доставки»;
- текстовые колонки, по которым искать: «Ответ», «Теги».

Можно несколько баз — например, «FAQ клиентов» и «Регламенты».

**Таблица для записи** — база, куда агент добавляет строки: заявки, вопросы без ответа, обращения. Пример из `config/notion.example.json`:

| Колонка | Тип | Кто заполняет |
|---|---|---|
| Название | Title | агент, обязательно |
| Тема | Select: Доставка, Возврат, Другое | агент, обязательно, только из списка |
| Email | Email | агент |
| Комментарий | Text | агент |
| Статус | Status: Новая, В работе… | сервер ставит «Новая» |
| Ответственный | Person | никто: колонка не в списке — агент её не видит |

## 2. Подключение Notion (10 минут)

1. Откройте app.notion.com/developers/connections → создайте внутреннее подключение для своего рабочего пространства.
2. Capabilities: **Read content** и **Insert content**. **Update content** не нужен — сервер не меняет страницы.
3. Скопируйте токен (начинается с `ntn_`).
4. В каждой базе знаний и в таблице: `•••` → **Add connections** → выберите подключение. Только в эти базы — больше никуда.
5. ID источника данных: в базе `•••` → **Manage data sources** → **Copy data source ID**.

## 3. Настройки (10 минут)

1. `config/notion.example.json` → `config/notion.json`.
2. `knowledge` — для каждой базы знаний: `name`, `data_source_id`, `text_properties` (колонки для поиска, кроме названия).
3. `target` — ID таблицы и колонки, которые может заполнять агент. Подробно — `docs/02-notion-setup.md`.
4. Заполните `config/allowed-databases.md`: что разрешено и кем. Это не для сервера — для вас и вашей службы безопасности.

## 4. Проверка (5 минут)

```bash
export NOTION_TOKEN=ntn_...
python3 server/notion_workspace_mcp.py --config config/notion.json --http 8766
```

Строка `notion-workspace: http://127.0.0.1:8766/mcp` — сервер запустился. Ctrl+C.

## 5. Клиент (10 минут)

- **Claude Code:** `clients/claude-code.mcp.json` → `.mcp.json` в корне проекта; `export MCP_KIT_DIR=/путь/к/набору NOTION_TOKEN=...`; `claude`.
- **Claude Desktop:** Settings → Developer → Edit Config → блок из `clients/claude-desktop.json` с полными путями и токеном.
- **Cursor:** `~/.cursor/mcp.json` ← `clients/cursor.mcp.json`.
- **n8n:** режим HTTP и узел MCP Client — `docs/03-clients.md`.

## 6. Проверочные вопросы (10 минут)

Пройдите `checks/test-questions.md`: вопросы, ответы на которые есть в базе; вопросы, ответов на которые нет; просьбы записать строку с нарушением правил. Каждая строка таблицы — ожидаемое поведение.
