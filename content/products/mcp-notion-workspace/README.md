# MCP: Notion Workspace

MCP-сервер, с которым AI-агент отвечает только по вашей базе знаний в Notion и записывает строку только в одну согласованную таблицу.

Официальный MCP Notion даёт агенту всё, к чему у вас есть доступ: читать любые страницы, создавать и менять их где угодно. Для внутреннего ассистента это удобно. Для агента, который отвечает клиентам или сотрудникам, это лишний риск. Этот сервер сужает доступ до двух вещей.

## Что делает

- **Ищет только в разрешённых базах.** Список баз знаний — в настройках. Страницы из других баз агент не найдёт и не прочитает, даже если узнает их id.
- **Говорит «в базе этого нет».** Если в разрешённых базах ничего не нашлось, агент получает `found: false` и прямое указание не отвечать по памяти.
- **Читает статью целиком** в Markdown — только из разрешённых баз.
- **Пишет только в одну таблицу и только в разрешённые колонки.** Тип каждой колонки и допустимые варианты берутся из самой таблицы Notion. Неизвестная колонка, вариант не из списка, пустое обязательное поле — отказ с понятной причиной.
- **Ставит служебные значения сам.** Например, «Статус = Новая»: агент не может записать «Готово».
- **Не создаёт дубли** по колонке, которую вы выберете, например по названию заявки или email.
- **Ничего не удаляет и не меняет** существующие страницы: таких инструментов в сервере нет.

## Что внутри

- `server/notion_workspace_mcp.py`, `server/mcp_lite.py` — сервер. Python 3.8+, без пакетов. API Notion версии 2026-03-11.
- `config/notion.example.json` — базы знаний и таблица для записи.
- `config/allowed-databases.md` — шаблон списка разрешённых баз: что, кто разрешил, зачем.
- `checks/test-questions.md` — проверочные вопросы перед запуском.
- `clients/` — конфиги для Claude Code, Claude Desktop и Cursor.
- `docs/` — устройство, настройка Notion, клиенты, безопасность.

## Как мы проверяли

Сервер проверен против подменного API Notion, через stdio и HTTP: 13 сценариев. Среди них поиск с пагинацией, статьи в корзине, база не из списка, чтение чужой страницы, запись в неразрешённую колонку, вариант не из списка, пустое обязательное поле, служебный статус, дубль, заголовок версии API. Официальный MCP Inspector (v2) подключался к серверу по stdio и по HTTP и вызывал поиск.

**Что мы не проверяли:** работу с настоящим рабочим пространством Notion — подменный API собран по справочнику Notion 2026-03-11; качество ответов конкретной модели по вашей базе — для этого `checks/test-questions.md`; интерфейсы Claude Desktop и Cursor.

## Что нужно

- Python 3.8 или новее.
- Notion с правом создавать подключения (internal connection) в рабочем пространстве.
- MCP-клиент: Claude Desktop, Claude Code, Cursor, n8n.

## С чего начать

1. `QUICKSTART.md` — запуск примерно за час.
2. `CONTENTS.md` — что где лежит.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
