# Разрешённые базы Notion

Список того, к чему у агента есть доступ. Сервер не читает этот файл: доступ задают `config/notion.json` и подключение, добавленное к базам в Notion. Файл нужен людям — чтобы через полгода было видно, что разрешено, кем и зачем.

Правило: база попадает в `notion.json` только после строки здесь. Подключение Notion добавляется только к базам из этого списка.

## Чтение (база знаний)

| База | data_source_id | Колонки для поиска | Кто разрешил | Дата | Зачем |
|---|---|---|---|---|---|
| FAQ клиентов | `…` | Ответ, Теги | | | ответы клиентам в чате |
| | | | | | |

Не добавляйте в чтение:
- базы с персональными данными клиентов и сотрудников (CRM, кадры, зарплаты);
- финансы, договоры, пароли и доступы;
- черновики и внутреннюю переписку — агент процитирует их клиенту.

## Запись (одна таблица)

| Таблица | data_source_id | Колонки для агента | Ставит сервер | Защита от дублей | Кто разрешил | Дата |
|---|---|---|---|---|---|---|
| Заявки от агента | `…` | Название*, Тема*, Email, Комментарий | Статус = Новая | Название | | |

`*` — обязательные.

## Пересмотр

Раз в квартал проверяйте:
1. Подключение в Notion добавлено только к базам из таблиц выше. Notion → Settings → Connections → ваше подключение → список страниц.
2. В `notion.json` нет баз, которых нет здесь.
3. Колонки таблицы записи не поменяли тип: сервер откажется писать, если колонка из настроек пропала из Notion.
