# Как это работает

```
агент ──MCP──► notion-workspace ──API Notion──► базы знаний (только чтение, только из списка)
                                              └► одна таблица (только добавление строки)
```

## Инструменты

| Инструмент | Что делает |
|---|---|
| `search_knowledge` | ищет статьи по словам вопроса во всех разрешённых базах, до 5 результатов с оценкой 0–1 |
| `read_page` | текст статьи в Markdown — только если статья из разрешённой базы |
| `describe_target` | колонки таблицы записи: тип, обязательность, допустимые варианты |
| `append_row` | добавляет строку в таблицу записи |

`search_knowledge`, `read_page` и `describe_target` помечены как «только чтение»: клиенты MCP могут разрешить их без вопроса. `append_row` меняет данные — Claude Desktop и Claude Code по умолчанию спрашивают перед его вызовом.

## Поиск

Сервер читает строки разрешённых баз (до `max_rows_per_source`, по умолчанию 500 на базу) и держит их в памяти `cache_minutes` минут. Поиск идёт по названию статьи и по колонкам из `text_properties`, с учётом окончаний русских и английских слов. Совпадение в названии весит больше, редкие слова — больше частых.

Оценка — доля слов вопроса, найденных в статье. Ниже `min_score` (0.3) — «ничего не найдено». Агент получает это прямо: «не отвечай по памяти».

Поиск не векторный. Для баз до нескольких сотен статей это работает предсказуемо, и видно, почему статья нашлась или нет. Если статьи не находятся по синонимам — добавьте синонимы в колонку «Теги».

Статьи из корзины и архива не показываются. Правки в Notion видны через `cache_minutes` минут или после перезапуска сервера.

## Запись

`append_row` перед каждой записью читает схему таблицы из Notion и проверяет:

1. колонка есть в `target.columns` и не служебная;
2. обязательные колонки заполнены;
3. значение подходит к типу: Select и Status — только существующий вариант, Email — адрес, Date — `ГГГГ-ММ-ДД`, Number — число, URL — `http(s)://`;
4. если задан `dedupe_column` — строки с таким значением ещё нет.

Служебные колонки (`fixed`) сервер заполняет сам, агент их не видит.

Можно писать колонки типов Title, Text, Number, Select, Multi-select, Status, Date, Email, Phone, URL, Checkbox. Person, Relation, Files и формулы — нельзя: сервер откажется их записывать, даже если они в настройках.

## Чего в сервере нет

- поиска по всему рабочему пространству;
- изменения и удаления страниц;
- создания баз, страниц вне таблицы записи, комментариев.

Если что-то из этого нужно — это другой уровень доверия. Подключите официальный MCP Notion (`https://mcp.notion.com/mcp`) отдельному внутреннему агенту.
