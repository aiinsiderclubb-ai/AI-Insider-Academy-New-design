# MCP: что нужно знать до подключения

**MCP (Model Context Protocol)** — стандарт, по которому AI-агент вызывает инструменты внешних систем: «найди сделки», «выполни SQL», «прочитай канал». Сервер MCP — переходник между агентом и системой. Клиент MCP — программа, где работает агент: Claude Desktop, Claude Code, Cursor, n8n.

## Два вида серверов

| | Удалённый (remote) | Локальный (stdio) |
|---|---|---|
| Где работает | у вендора: HubSpot, Slack, GitHub | на вашем компьютере или сервере |
| Как подключается | адрес `https://…` | клиент запускает команду (`npx …`, `docker run …`) |
| Вход | OAuth в браузере или токен в заголовке | токен или пароль в переменной окружения |
| Обновления | вендор обновляет сам | вы обновляете версию |
| В наборе | HubSpot, Slack, GitHub | Postgres (DBHub), GitHub в Docker |

## Права агента = права учётной записи

Сервер MCP действует от имени того, кто вошёл: ваш пользователь HubSpot, ваш Slack, ваш токен GitHub, роль Postgres. Агент видит и может сделать то же, что эта учётная запись, в пределах инструментов сервера. Поэтому в наборе:
- Postgres — отдельная роль только для чтения;
- GitHub — токен с минимальными правами и адрес `/readonly`;
- HubSpot и Slack — права вашего пользователя. Агенту лучше выдавать отдельного пользователя с ограниченными правами, если это позволяет тариф.

## Подтверждение действий

Клиенты MCP по-разному спрашивают разрешение:
- **Claude Desktop, Claude Code** — спрашивают перед вызовом инструментов, если вы не разрешили их навсегда. Инструменты чтения можно разрешать навсегда, запись — нет.
- **Cursor** — спрашивает, если не включён автозапуск инструментов.
- **n8n** — не спрашивает: агент работает без человека. Там важнее всего ограничения самого сервера и учётной записи.

HubSpot сам показывает предлагаемые изменения и требует явного подтверждения перед записью — так устроен его инструмент `manage_crm_objects`.

## Архивные серверы

В 2025 году часть эталонных серверов из `modelcontextprotocol/servers` перенесли в архив `servers-archived`. Для них больше нет исправлений безопасности, а их npm-пакеты помечены как устаревшие:

| Архивный пакет | Чем заменить |
|---|---|
| `@modelcontextprotocol/server-postgres` | DBHub — `docs/03-postgres.md` |
| `@modelcontextprotocol/server-slack` | официальный `https://mcp.slack.com/mcp` — `docs/04-slack.md` |
| `@modelcontextprotocol/server-github` | официальный `github/github-mcp-server` — `docs/05-github.md` |

`scripts/check_mcp_config.py` находит эти и другие архивные серверы в ваших конфигах.

## Где лежат конфиги

| Клиент | Файл |
|---|---|
| Claude Code | `.mcp.json` в корне проекта (общий для команды) или `claude mcp add --scope user` (только у вас) |
| Claude Desktop | Settings → Developer → Edit Config → `claude_desktop_config.json`; удалённые серверы — Settings → Connectors |
| Cursor | `~/.cursor/mcp.json` (все проекты) или `.cursor/mcp.json` (проект) |
| n8n | узел MCP Client Tool в воркфлоу с AI Agent |

Переменные окружения: Claude Code понимает `${ИМЯ}` в `.mcp.json`, Cursor — `${env:ИМЯ}`, Claude Desktop — не подставляет, значения пишутся прямо в `env`.
