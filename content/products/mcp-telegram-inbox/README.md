# MCP: Telegram Inbox

MCP-сервер, через который AI-агент читает рабочий Telegram-чат и заводит из сообщений клиентов лиды в CRM. Спорное — жалобы, возвраты, срочное, крупных клиентов — агент не трогает, а передаёт менеджеру в его чат.

Работает с Claude Desktop, Claude Code, Cursor и n8n. Сервер — один файл на Python без внешних пакетов.

## Что делает

- **Читает только разрешённые чаты.** Бот видит сообщения всех групп, куда его добавили, но сервер сохраняет только чаты из списка в настройках. Сообщения ботов, команды и «ок/спасибо» отбрасываются.
- **Лид — только с настоящим контактом.** `create_lead` принимает телефон или email, только если они есть в тексте этих сообщений. Номер, который модель придумала или перепутала, сервер не примет.
- **Без дублей.** По одному сообщению лид заводится один раз. Повторный разбор ничего не дублирует.
- **Не больше 5 лидов за 10 минут** (настраивается) — защита CRM от ошибки модели.
- **Правила эскалации.** Слова «верните деньги», «жалоба», «срочно», «тендер» и ваши собственные ставят на сообщение пометку. Агент передаёт такое сообщение менеджеру с причиной, пересказом и ссылкой на оригинал, а лид не заводит.
- **CRM — через вебхук.** Лид уходит POST-запросом с именем, телефоном, email, суммой, источником и ссылкой на сообщение. Подходит наш CRM Automation Kit, любой воркфлоу n8n, Make, Zapier. HubSpot подключается вторым MCP-сервером — `docs/04-crm.md`.
- **Если CRM не ответила**, сообщение остаётся необработанным и попадёт в следующий разбор.

## Что внутри

- `server/telegram_inbox_mcp.py`, `server/mcp_lite.py` — сервер. Python 3.8+, без пакетов. Режимы stdio и HTTP.
- `config/inbox.example.json` — чаты, чат менеджера, CRM, правила эскалации.
- `clients/` — готовые конфиги для Claude Code, Claude Desktop, Cursor и воркфлоу n8n для разбора каждые 15 минут.
- `rules/escalation-rules.md` — правила эскалации и как их настраивать.
- `prompts/agent-request.md` — запрос агенту и тестовые сообщения.
- `docs/` — устройство, настройка бота и чатов, подключение клиентов, CRM, безопасность.

## Как мы проверяли

Сервер проверен против подменного Telegram Bot API и подменной CRM, через stdio и HTTP: 13 сценариев разбора. Среди них чужой чат и сообщения ботов, повтор разбора, лид с телефоном, которого нет в сообщении, выдуманный id сообщения, повторный лид, недоступная CRM, двойная эскалация, неверный токен HTTP и чужой Origin.

Отдельно воркфлоу из `clients/` запускался в n8n 2.48. Там AI Agent через узел MCP Client вызвал сервер по HTTP, завёл лид и передал жалобу менеджеру. Модель в этой проверке была подменной: скрипт решал, какие инструменты вызвать.

**Что мы не проверяли:** настоящий Telegram и вашу CRM; как конкретная модель (Claude, GPT) разбирает ваши сообщения — для этого есть тестовые сообщения в `prompts/agent-request.md`; работу в интерфейсах Claude Desktop и Cursor. Конфиги для них собраны по их документации.

## Что нужно

- Python 3.8 или новее (на macOS и Linux уже есть).
- Telegram-бот (бесплатно, @BotFather) в рабочем чате.
- Куда заводить лиды: адрес вебхука CRM или HubSpot.
- MCP-клиент: Claude Desktop, Claude Code, Cursor или n8n.

## С чего начать

1. `QUICKSTART.md` — запуск за 30–40 минут.
2. `CONTENTS.md` — что где лежит.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
