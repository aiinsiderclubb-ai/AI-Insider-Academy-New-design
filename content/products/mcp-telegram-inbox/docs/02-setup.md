# Настройка

## inbox.json

| Поле | Что это |
|---|---|
| `chats` | чаты, которые читает агент: `id` и `name`. Сообщения остальных чатов не сохраняются |
| `manager_chat_id` | чат, куда приходят эскалации. Бот должен быть в нём |
| `lead_sink` | куда заводить лиды — `docs/04-crm.md` |
| `escalation` | правила эскалации — `rules/escalation-rules.md` |
| `ignore_patterns` | сообщения, которые не сохраняются: команды, «ок», «спасибо» |
| `max_leads_per_10_minutes` | предохранитель от массовых ошибок, по умолчанию 5 |
| `retention_days` | сколько дней хранить сообщения, по умолчанию 14 |
| `data_dir` | папка состояния, относительно файла настроек |

## Переменные окружения

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота — обязательно |
| имя из `lead_sink.token_env` (по умолчанию `CRM_WEBHOOK_TOKEN`) | токен вебхука CRM |
| `MCP_HTTP_TOKEN` | ключ доступа в режиме HTTP |
| `MCP_HTTP_HOST` | адрес, на котором слушает HTTP; по умолчанию `127.0.0.1` |
| `MCP_ALLOWED_ORIGINS` | список Origin через запятую, если сервер вызывают из браузера; обычно не нужен |

Токены не пишутся в `inbox.json`: файл можно показать коллеге или положить в репозиторий.

## Бот

1. @BotFather → `/newbot`.
2. `/setprivacy` → бот → **Disable**: без этого в группе бот видит только команды и ответы себе.
3. Добавьте бота в рабочие чаты и в чат менеджера. Права администратора не нужны.
4. Если вы выключили Privacy Mode уже после добавления в группу — удалите бота из группы и добавьте снова: Telegram применяет настройку при входе.

## ID чатов

Напишите сообщение в каждый чат и откройте `https://api.telegram.org/botТОКЕН/getUpdates`. В ответе `message.chat.id` и `message.chat.title`. У групп ID отрицательный, у супергрупп начинается с `-100`.

Обычная группа становится супергруппой (например, когда включают историю для новых участников) — тогда ID меняется. Если сообщения перестали приходить, проверьте ID заново.

## Несколько чатов

В `chats` можно перечислить сколько угодно чатов. В отчёте агента и в сообщении менеджеру указывается название чата из `name`.
