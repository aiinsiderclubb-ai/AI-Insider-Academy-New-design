# Запрос агенту: разбор рабочего чата

Этот текст — задание агенту. Его можно вставить в чат Claude или Cursor как есть, а в n8n он уже стоит в узле AI Agent воркфлоу `clients/n8n-inbox-triage.n8n.json`. Правила эскалации — в `rules/escalation-rules.md`; агент видит подсказки из них в поле `escalation_hints` каждого сообщения.

```text
Разбери новые сообщения рабочего Telegram-чата.

1. Вызови fetch_new_messages, затем list_messages.
2. Для каждого сообщения со статусом new реши, что это:
   а) обращение клиента с контактом (телефон или email есть в тексте) и понятной потребностью → create_lead.
      Имя — как клиент представился, need — суть запроса в 1–2 предложениях своими словами,
      amount — только если клиент сам назвал сумму. Если клиент написал несколькими сообщениями подряд —
      передай все их id одним вызовом.
   б) у сообщения есть escalation_hints (жалоба, возврат, срочно, крупный клиент) → escalate,
      даже если контакт есть. Лид в этом случае не заводи — решит менеджер.
   в) клиент интересуется, но контакта в тексте нет → escalate с причиной «нет контакта».
   г) внутреннее общение команды, приветствия, «спасибо», реклама → mark_messages со статусом ignored.
3. Не придумывай телефоны, email, суммы и имена. Не заводи лид по сообщению сотрудника.
4. В конце дай короткий отчёт: сколько лидов заведено (с номерами CRM), что передано менеджеру и почему,
   что пропущено. Если сообщений не было — так и скажи одной строкой.
```

## Как проверить на тестовых сообщениях

Напишите в рабочий чат с другого аккаунта (не с аккаунта бота):

| Сообщение | Ожидаемое действие |
|---|---|
| «Здравствуйте, нужен сайт для студии, бюджет 3000, мой телефон +380671234567» | create_lead: телефон, сумма 3000 |
| «Добрый день! Интересует ваша услуга» | escalate: нет контакта |
| «Верните деньги за прошлый заказ, иначе пишу жалобу. anna@example.com» | escalate: жалоба или возврат, лид не заводится |
| «Коллеги, обед в 13:00» | mark_messages → ignored |
| Повторный запуск разбора | ничего нового: всё уже разобрано |
