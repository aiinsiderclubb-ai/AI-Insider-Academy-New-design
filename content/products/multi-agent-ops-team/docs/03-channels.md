# Каналы

## Сайт и любые системы

`templates/chat-widget.html` — чат-виджет: впишите адрес вебхука и `agent_token`. Токен виден в коде страницы — он отсекает случайные запросы, но не секрет; бюджет защищают лимиты (`rate_limit_*`, `daily_agent_runs`, `agent_budgets`).

**Запрос**

```
POST https://ВАШ-N8N/webhook/ops-team
Content-Type: application/json
x-agent-token: ВАШ_AGENT_TOKEN        (или поле "token" в теле)

{"session_id": "crm-48213", "message": "Нужен бот для записи клиентов",
 "name": "Анна", "email": "anna@salon.ua", "phone": "+380501112233"}
```

`session_id` обязателен (6–100 символов: буквы, цифры, `: . _ -`), остальные поля — нет. Один `session_id` — один диалог.

**Ответ 200**

```json
{"reply": "Спасибо! Передал ваш запрос команде…", "handoff": false, "session_id": "crm-48213"}
```

С заголовком `x-agent-debug: ВАШ_DEBUG_TOKEN` добавляются `tools`, `trace` и `flags`. Ошибки: `401` — токен, `400` — `session_id`.

## Команда

Тот же вебхук, но заголовок `x-team-token: ВАШ_TEAM_TOKEN`. Команде доступны все четыре агента, включая отчёты: «Отчёт за неделю», «Сколько горячих лидов за месяц». Лимиты сообщений к команде не применяются.

Чтобы спрашивать отчёты прямо из Telegram, сделайте отдельный маленький воркфлоу: Telegram Trigger вашего служебного бота → HTTP Request на этот вебхук с `x-team-token` → ответ в чат. Чат команды основной бот не слушает — это сделано, чтобы его сообщения не уходили в оркестратор как клиентские.

## Telegram клиентов

Telegram Trigger подключается при публикации. Нужен https и отдельный бот: у одного бота — один адрес для обновлений. Ответы уходят как HTML с экранированием.

## Почта

Email Trigger проверяет ящик по IMAP и отмечает письма прочитанными. Каждое письмо:

1. Guard In отбрасывает роботов (`no-reply`, `mailer-daemon`, автоответы, `Auto-Submitted`) и ваши адреса из `own_emails`, отрезает цитату и подпись.
2. Оркестратор отдаёт письмо агенту разбора почты, а заявку нового клиента — затем агенту по лидам.
3. Разбор с черновиком ответа — строка в `Inbox`. Срочные и важные — в Telegram команды.
4. Клиенту ничего не отправляется. Черновик отправляет человек из своей почты.

Почта не нужна — отключите узел Email Trigger (Deactivate).

## Расписание

Узел **Daily Report** запускает отчёт каждый день в 9:00 по часовому поясу воркфлоу (Settings → Timezone). Отчёт за вчера уходит в чат команды. Время и дни меняются в узле.
