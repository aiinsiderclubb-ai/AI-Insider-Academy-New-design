# Эксплуатация

## Журналы

- `Log` — каждое сообщение: канал, вопрос, ответ, вызванные агенты, передача, пометки, трасса.
- `Leads`, `Tickets`, `Inbox` — что сделали агенты; `session_id` связывает строку с диалогом.
- Ежедневный отчёт собирает их сам. Раз в неделю посмотрите вручную:
  - `flags` с `agent_not_allowed` — оркестратор звал недоступного агента;
  - `forbidden_promise`, `injection` — где агентов тянуло обещать лишнее и кто пытался их сломать;
  - `service_error` — сбои таблицы и Telegram;
  - лиды со статусом `повтор` — клиенты, которые пишут второй раз.

## Память

Память диалога (узел Memory) — только у оркестратора, в памяти процесса n8n: после перезапуска диалоги начинаются заново, а в queue mode с несколькими воркерами сообщения одного диалога могут попасть на разные воркеры. Для production с очередью замените Memory на Postgres Chat Memory или Redis Chat Memory с тем же Session Key.

## Приватность

- В модель уходят тексты сообщений и писем, контакты клиентов, найденные статьи. Проверьте условия провайдера модели и укажите обработку в политике конфиденциальности.
- Журналы хранят тексты сообщений и черновики ответов на письма. Номера карт вырезаются до записи. Определите срок хранения и чистите листы.

## Изменения

- **Инструкции** — правьте `agent/prompts/*.md` и переносите текст в узел **Prompts** (строки в `TEXTS`). Ключи в двойных фигурных скобках подставляются из Config.
- **Лимиты** — `agent_budgets` в Config и Max Iterations в узлах агентов.
- **Правила балла** — узел Lead Row.
- После любой правки — evals.

## Неполадки

| Симптом | Причина |
|---|---|
| 401 на всё | в Config заглушки `agent_token` / `team_token` или токен не совпадает |
| 404 на Production URL | воркфлоу не опубликован |
| письма не разбираются | узел Email Trigger выключен, нет ключа IMAP, письмо от робота или с адреса из `own_emails` |
| отчёт не приходит | не опубликован; неверный `team_chat_id`; лимит `reports_agent` исчерпан командой за день |
| отчёт «нет данных» | неверные имена листов или колонок; часовой пояс `timezone` |
| агент «недоступен» | исчерпан его дневной лимит или канал ему не разрешён — см. `docs/05-guardrails-and-limits.md` |
| сигнал «Ошибка инструмента» | таблица недоступна: ID, имя листа, доступ Google-ключа |
| оркестратор отвечает сам, не зовя агентов | модель без tools или слабая модель — `docs/06-models.md` |
