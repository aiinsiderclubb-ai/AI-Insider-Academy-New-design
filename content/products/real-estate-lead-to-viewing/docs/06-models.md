# Модели

Агенту нужна модель с вызовом инструментов.

## OpenAI — по умолчанию

**OpenAI Chat Model**, `gpt-5-mini`, Responses API выключен — обычный Chat Completions, поэтому тот же узел работает с OpenAI-совместимыми провайдерами (OpenRouter, Groq, Together, DeepSeek, Mistral, vLLM, Ollama): Base URL в ключе типа OpenAI и модель по ID из каталога провайдера.

## Claude

Узел **Anthropic Chat Model** (`claude-haiku-5-5`) стоит рядом, не подключён:
1. ключ Anthropic в узле;
2. удалите связь OpenAI Chat Model → AI Agent;
3. протяните связь Anthropic Chat Model → вход Chat Model агента;
4. опубликуйте, прогоните evals.

Мы прогоняли воркфлоу с обоими узлами — инструменты, память и защита работают одинаково.

## Расход

Сообщение клиента — обычно 2–3 обращения к модели: понять → вызвать инструмент → ответить. Каждое отправляет инструкцию (около 1 300 токенов), описания пяти инструментов (около 1 500), память до 16 сообщений и результат инструмента (подборка — 300–700). Диалог от первого сообщения до записи — обычно 6–12 сообщений клиента. Цены — на сайте провайдера; предохранители — `daily_agent_runs`, лимит сообщений и месячный лимит у провайдера.

## Схемы инструментов вне n8n

`agent/tools.openai.json` и `agent/tools.anthropic.json` — пять инструментов в форматах обоих API, с той же инструкцией из `agent/system-prompt.md`. Тест набора проверяет, что схемы совпадают с узлами воркфлоу.
