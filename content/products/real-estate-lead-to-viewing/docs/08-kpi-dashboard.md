# KPI-дашборд

Все данные для дашборда агент уже пишет в таблицу: `Leads` (каждый клиент, источник, балл, риелтор, этап), `Viewings` (каждый просмотр и его итог), `Log` (каждое сообщение и ответ). Ниже — два варианта: лист с формулами в той же таблице и отчёт в Looker Studio.

## Что считать

| KPI | Формула смысла | Зачем |
|---|---|---|
| Новые лиды за неделю | строки `Leads` по `created` | поток |
| Доля горячих | `segment = hot` / все | качество трафика по источникам |
| Лид → подборка | `stage` ≥ `matched` / все | агент доводит до показа объектов |
| Лид → просмотр | `viewing_id` не пусто / все | главный показатель агента |
| Просмотр состоялся | `Viewings.status = done` / все просмотры | дисциплина и напоминания |
| Просмотр → сделка | `stage = deal` / с просмотром | работа риелторов |
| Лиды и просмотры по риелторам | по `agent_id` | нагрузка и результат |
| Лиды по источникам | по `source`: site, portal, crm, telegram | откуда клиенты |
| Передачи людям | `Log.handoff = да` / сообщения | что агент не тянет |
| Пометки защиты | `Log.flags` не пусто | `unknown_listing`, `forbidden_promise` — повод править базу и инструкцию |

Этапы `visited`, `offer`, `deal`, `lost` и статусы просмотров `done`, `no_show` ставят риелторы — без них нижняя часть воронки пустая.

## Вариант 1: лист «Dashboard» в той же таблице

Создайте лист `Dashboard`. В A1 — дату начала периода (например, `2026-11-01`), в B1 — дату конца. Формулы ниже — для локали с запятой-разделителем аргументов (английская); в русской и украинской локали Google Таблиц замените `,` между аргументами на `;`.

Колонки в `Leads`: `created` — A, `source` — E, `segment` — S, `agent_id` — T, `stage` — U, `viewing_id` — W. В `Viewings`: `created` — A, `agent_id` — E, `status` — J. В `Log`: `time` — A, `handoff` — G, `flags` — H.

Даты пишутся как текст ISO (`2026-11-19T08:12:03.000Z`), поэтому сравниваем первые 10 символов:

```
Лиды за период
=SUMPRODUCT((LEFT(Leads!A2:A,10)>=TEXT(A1,"yyyy-mm-dd"))*(LEFT(Leads!A2:A,10)<=TEXT(B1,"yyyy-mm-dd")))

Горячих
=SUMPRODUCT((LEFT(Leads!A2:A,10)>=TEXT(A1,"yyyy-mm-dd"))*(LEFT(Leads!A2:A,10)<=TEXT(B1,"yyyy-mm-dd"))*(Leads!S2:S="hot"))

С просмотром
=SUMPRODUCT((LEFT(Leads!A2:A,10)>=TEXT(A1,"yyyy-mm-dd"))*(LEFT(Leads!A2:A,10)<=TEXT(B1,"yyyy-mm-dd"))*(Leads!W2:W<>""))

Конверсия лид → просмотр (в ячейке с форматом «процент»)
=IFERROR(B5/B3,0)

Просмотры состоялись / всего
=COUNTIF(Viewings!J2:J,"done")
=COUNTA(Viewings!B2:B)

Сделки
=COUNTIF(Leads!U2:U,"deal")

Лиды и просмотры по риелторам (таблица, начиная с D3)
=QUERY(Leads!A2:W,"select T, count(A), count(W) where A is not null group by T label T 'Риелтор', count(A) 'Лиды', count(W) 'С просмотром'",0)

Лиды по источникам
=QUERY(Leads!A2:S,"select E, count(A) where A is not null group by E label E 'Источник', count(A) 'Лиды'",0)

Доля передач людям за всё время
=IFERROR(COUNTIF(Log!G2:G,"да")/COUNTA(Log!A2:A),0)

Ответы с пометками защиты
=COUNTIF(Log!H2:H,"*unknown_listing*")
=COUNTIF(Log!H2:H,"*forbidden_promise*")
```

В формулах ссылки вида `B3`, `B5` — на ячейки, где у вас стоят «Лиды за период» и «С просмотром»; поставьте свои.

Графики: Вставка → Диаграмма по таблицам «по риелторам» и «по источникам».

## Вариант 2: Looker Studio

1. lookerstudio.google.com → Создать → Источник данных → Google Таблицы → ваша таблица → лист `Leads`. Добавьте ещё два источника: `Viewings` и `Log`.
2. В источнике `Leads` создайте поля:
   - `Дата` = `PARSE_DATE("%Y-%m-%d", SUBSTR(created, 1, 10))`
   - `С просмотром` = `CASE WHEN viewing_id != "" THEN 1 ELSE 0 END`
   - `Горячий` = `CASE WHEN segment = "hot" THEN 1 ELSE 0 END`
   - `Сделка` = `CASE WHEN stage = "deal" THEN 1 ELSE 0 END`
   - `Конверсия в просмотр` = `SUM(С просмотром) / COUNT(lead_id)`
3. Страница «Воронка»: показатели — `COUNT(lead_id)`, `SUM(Горячий)`, `SUM(С просмотром)`, `SUM(Сделка)`, `Конверсия в просмотр`; фильтр периода по `Дата`.
4. Таблица «Риелторы»: измерение `agent_id`, показатели — лиды, с просмотром, конверсия.
5. Столбчатая диаграмма «Источники»: измерение `source`, показатель `COUNT(lead_id)`, разбивка по `segment`.
6. Источник `Viewings`: `Дата просмотра` = `PARSE_DATE("%Y-%m-%d", SUBSTR(slot_start, 1, 10))`, таблица «Просмотры по дням и риелторам», доля `status = "done"`.
7. Источник `Log`: доля `handoff = "да"` по неделям и таблица ответов с `flags` — для разбора.

Имена риелторов вместо `agent_id`: добавьте в таблицу лист `Agents` с колонками `agent_id | name` и объедините его с `Leads` в Looker Studio (Ресурс → Управление объединениями данных).

## Что смотреть каждую неделю

- Конверсия лид → просмотр по источникам: где агент теряет клиентов.
- Лиды без этапа `matched` с полной анкетой: в базе нет подходящих объектов — сигнал, что закупать или привлекать.
- `unknown_listing` в журнале: агент пытался назвать несуществующий объект — проверьте, не устарела ли база.
- Просмотры `no_show`: работают ли напоминания follow-up.
