# Эксплуатация

## Каждый день

- Утренняя сводка follow-up в чате агентства: кому позвонить, какие просмотры завтра.
- Риелторы ставят итог просмотра в `Viewings.status` (`done`, `no_show`) и этап в `Leads.stage` (`visited`, `offer`, `deal`, `lost`).

## Каждую неделю

- Дашборд (`docs/08-kpi-dashboard.md`).
- Журнал `Log`: пометки `unknown_listing`, `forbidden_promise`, `injection`, `service_error`.
- Актуальность `Listings`: проданное — в `sold`, сданное — в `rented`. Агент показывает только `active`.

## Память

Узел Memory хранит 16 последних сообщений на диалог в памяти n8n: после перезапуска разговор начинается заново (карточка лида в таблице остаётся — агент найдёт её по `session_id`). Для queue mode с несколькими воркерами замените Memory на Postgres Chat Memory или Redis Chat Memory с тем же Session Key.

## Приватность

- В модель уходят сообщения клиента, его имя и телефон, данные объектов. Проверьте условия провайдера модели и укажите обработку в политике конфиденциальности.
- В календаре риелтора — имя, телефон клиента и адрес объекта. Не делайте календари риелторов публичными.
- `Leads`, `Viewings`, `Log` хранят персональные данные: определите срок хранения и чистите.
- Напоминания follow-up уходят только тем, кто сам написал боту в Telegram.

## Изменения

- Инструкция — `agent/system-prompt.md` и узел AI Agent → System Message (ключи в двойных фигурных скобках не трогать). После правки — evals.
- Правила балла, подбора, окон — узлы Lead Upsert, Match Listings, Slots; параметры — Config.
- Новый риелтор — строка в `agents` и его `agent_id` у объектов.

## Неполадки

| Симптом | Причина |
|---|---|
| 401 на всё | заглушка `agent_token` в Config или неверный токен |
| 404 на Production URL | воркфлоу не опубликован |
| «Ошибка инструмента check_viewing_slots» | у ключа Google Calendar нет доступа к календарю риелтора или неверный `calendar_id` |
| свободного времени нет никогда | `viewing_hours`, `lead_time_minutes`, `booking_window_days`; или календарь риелтора занят круглосуточными событиями |
| объект не находится | статус не `active`, `deal_type` или `property_type` не из списка, цена с пробелами или валютой в ячейке |
| лид у «не того» риелтора | `areas` и `deal_types` в Config; закреплённый лид не переназначается до записи на просмотр |
| follow-up не приходит | воркфлоу не опубликован; клиент не из Telegram — он в списке «Позвонить»; этап уже `viewing_booked` или дальше |
| агент записывает «не на то время» | в evals и журнале — повторяет ли агент дату и время перед «Записываю?» (шаг 6 инструкции) |
