# Модели

Модель подключена к узлу **Assess & Draft**. Вызов инструментов не нужен — подходит любая чат-модель.

## OpenAI

По умолчанию `gpt-5-mini`, Responses API выключен — поэтому подходит и любой OpenAI-совместимый провайдер: Base URL в ключе OpenAI, модель по ID.

## Claude

Рядом стоит **Anthropic Chat Model** (`claude-sonnet-5-5`), не подключённый. Удалите связь от OpenAI Chat Model к Assess & Draft и протяните её от Anthropic Chat Model. Мы прогоняли агента с обоими узлами — черновики, проверки и кнопки работают одинаково.

Для писем клиентам важен тон: берите модель не слабее класса mini/Haiku. Перед сменой модели прогоните evals.

## Расход

Одно обращение на черновик: инструкция около 900 токенов, факты о счёте 150–300, ответ 200–400. Отчёт и кнопки модель не вызывают.

## Инструкция

`agent/draft-prompt.md` — та же инструкция, что в узле Assess & Draft (Messages → System). Правите файл — перенесите текст в узел, не трогая значения в двойных фигурных скобках. Фигурных скобок в тексте инструкции быть не должно: узел воспринимает их как переменные.

После правки — evals: `docs/07-evals-and-operations.md`.
