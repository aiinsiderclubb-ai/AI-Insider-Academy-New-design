# Sales Agent

AI-консультант по продажам для n8n. Ведёт разговор с клиентом в чате на сайте и в Telegram: понимает задачу, подбирает товар из вашего каталога, выясняет бюджет, сроки и кто принимает решение, отвечает на возражения только одобренными формулировками и доводит до следующего шага — ссылки на оплату, коммерческого предложения или звонка с менеджером. Замолчавшим клиентам пишет сам — по правилам, с тихими часами и стоп-листом.

## Что делает

- **Продаёт по каталогу.** Товары, цены, наличие и ссылки на оплату — из Google Таблицы. Если подходящего нет, агент так и говорит.
- **Квалифицирует без анкеты.** Задача, бюджет, сроки, кто решает — по ходу разговора. Баллы 0–100 считает код. Горячий лид сразу приходит в чат продаж карточкой. Крупная сделка — менеджеру.
- **Отвечает на возражения честно.** «Дорого», «а гарантии?», «чем вы лучше…» — только формулировками из листа одобренных ответов. Нет ответа — нет выдуманных кейсов и цифр.
- **Доводит до шага.** Ссылка на оплату ровно из каталога, запрос КП менеджеру с email клиента, ссылка на запись к звонку. Всё с сигналом в чат продаж.
- **Follow-up 24/7.** Через сутки, трое и семь дней тишины — короткое сообщение в Telegram (или на email). Не пишет ночью и в выходные, закрытым сделкам и тем, кто написал «стоп». Не больше трёх касаний.
- **Не давит и не обещает лишнего.** Ответ со скидкой, которой нет, гарантией или «только сегодня» заменяется, команда получает сигнал.
- **Защищён** как все наши агенты: токен, лимиты, вырезание номеров карт, служебная метка против утечки инструкции, журнал.
- **OpenAI, любой OpenAI-совместимый API или Claude.**

## Чем отличается от шаблона из интернета

Воркфлоу запускался в n8n 2.48 против подменных Google Таблиц, Telegram и моделей — отдельно с OpenAI и с Anthropic. 33 проверки, от ссылки на оплату только из таблицы до follow-up, который пишет только тем, кому пора. Логика узлов Code дополнительно покрыта 22 тестами. Подробнее — `docs/07-evals.md`.

Что не проверено у нас: как настоящая модель продаёт ваш продукт. Для этого — 21 eval-случай и скрипт прогона.

## Что внутри

- `workflows/sales-agent-template.n8n.json` — агент, шесть инструментов, стоп-лист, follow-up по расписанию, журнал.
- `workflows/error-alert.n8n.json` — сигнал в Telegram, если агент упал.
- `agent/system-prompt.md` — системная инструкция.
- `agent/tools.openai.json`, `agent/tools.anthropic.json` — схемы инструментов для обоих API.
- `templates/` — демо-каталог на 5 позиций, 10 одобренных ответов, заголовки листов, чат-виджет.
- `evals/` — 21 случай и скрипт прогона.
- `docs/` — устройство, настройка, каналы, квалификация и follow-up, защита, модели, evals, эксплуатация.

## Что нужно

- n8n 2.x с адресом по https.
- Google Таблица.
- Ключ модели: OpenAI, совместимый провайдер или Anthropic.
- Telegram-бот для чата продаж и, по желанию, для клиентов.
- Ссылки на оплату (любая платёжная система) и на запись к звонку — по желанию.

## Чем отличается от наших наборов

- **Lead Qualification Agent** оценивает заявки с форм без разговора; этот агент сам разговаривает и продаёт.
- **WhatsApp Sales Bot** — сценарный бот для WhatsApp; этот — агент с инструментами для сайта и Telegram.
- **CRM Automation Kit** ведёт сделки менеджеров; лиды этого агента можно передавать туда вебхуком.

## Лицензия

Можно использовать в своём бизнесе и внедрять клиентам. Нельзя перепродавать набор и выкладывать его в открытый доступ.
