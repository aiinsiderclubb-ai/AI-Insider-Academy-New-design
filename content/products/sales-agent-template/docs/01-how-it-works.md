# Как это работает

## Путь сообщения

```
клиент ─► Webhook / Telegram Trigger ─► Config ─► Guard In
                                                    │
                    ┌──────────────┬────────────────┼──────────┐
                    ▼              ▼                ▼          ▼
                  модель       заготовка           401        400
                    │          («стоп» → OptOut)
                  AI Agent ◄── Memory (16 последних сообщений)
                    │  ▲
                    │  └── search_catalog · get_sales_facts · save_lead · send_offer · book_call · handoff_to_human
                    ▼
                 Guard Out ─► Alert Team? ─► Log ─► ответ на сайт или в Telegram

Schedule (каждые 30 минут) ─► Config ─► Leads + OptOut + Log + Products ─► Pick Follow-ups ─► Telegram / email ─► счётчик касаний
```

1. **Guard In** — токен, лимиты, номер карты, попытка подмены правил, просьба позвать человека и **«стоп»**: отказ от сообщений записывается в лист `OptOut` без модели.
2. **AI Agent** ведёт разговор: понимает задачу, подбирает товар, выясняет бюджет, сроки и кто решает, отвечает на возражения, предлагает следующий шаг.
3. **Guard Out** не выпускает запрещённые обещания: скидки и бонусы, которых нет, гарантии, ложную срочность («только сегодня», «осталось два места»).
4. **Log** — строка в журнал; ответ — в тот же канал.

## Инструменты

| Инструмент | Откуда данные | Что делает код, а не модель |
|---|---|---|
| `search_catalog` | лист `Products` | цены, наличие, есть ли онлайн-оплата — только из таблицы |
| `get_sales_facts` | лист `Facts` | только одобренные формулировки; нет подходящей — «не придумывай» |
| `save_lead` | лист `Leads` | одна строка на диалог, баллы 0–100, «горячий» лид → сигнал в чат продаж один раз, крупная сделка → совет передать менеджеру |
| `send_offer` | `Products` | ссылка на оплату — ровно из таблицы; нет ссылки — отказ; КП — только с email, запрос уходит в чат продаж |
| `book_call` | Config | ссылка на запись к менеджеру (Cal.com, Calendly, наш Appointment Booking Agent) и сигнал в чат |
| `handoff_to_human` | — | сообщение в чат продаж, бот замолкает в диалоге |

Как и в других наших агентах, инструменты — ветки этого же воркфлоу: узел Call n8n Workflow Tool вызывает его по `$workflow.id`, вызов идёт через Tool Call → Config → Tool Switch. Ответ инструмента всегда содержит `note` — что делать дальше.

## Follow-up

Раз в 30 минут воркфлоу читает одним запросом листы `Leads`, `OptOut`, `Log` и `Products` и решает, кому написать. Модель не участвует: тексты — шаблоны из Config, правила — код. Подробно — `docs/04-qualification.md`.
