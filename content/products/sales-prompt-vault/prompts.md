# Sales Prompt Vault

50 промптов. Текст в [квадратных скобках] замените своим.

## Поиск и первое касание

Холодные сообщения, которые читают: конкретный повод, одна мысль, лёгкий вопрос.

### 1. Профиль идеального клиента

```
Я продаю [что] за [цена]. Лучшие клиенты за последний год: [описания 3–5 клиентов]. Найди общее: размер, ситуация, что их подтолкнуло купить. Опиши профиль идеального клиента и 5 признаков, по которым его видно снаружи — по сайту, вакансиям, соцсетям.
```

### 2. Повод написать

```
Компания: [название, чем занимается]. Что я нашёл о них: [факты с сайта, новости, вакансии]. Предложи 5 поводов для первого сообщения, связанных с моим продуктом [что]. Каждый повод — наблюдение, а не комплимент. Отметь самый сильный.
```

### 3. Холодное письмо в три строки

```
Получатель: [должность, компания]. Повод: [наблюдение]. Продукт: [что]. Напиши письмо из трёх строк: что я заметил; какую проблему это обычно значит; вопрос, на который легко ответить одним словом. Тема до 5 слов, без названия моей компании.
```

### 4. Сообщение в LinkedIn

```
Пишу [кому] после принятия заявки. Общее между нами: [что]. Напиши 3 варианта первого сообщения до 40 слов. Без презентации продукта, без «буду рад сотрудничеству». Цель — получить ответ, а не продать.
```

### 5. Сообщение в Telegram или WhatsApp

```
Пишу владельцу [тип бизнеса]. Видел у них: [наблюдение]. Напиши сообщение до 50 слов в разговорном тоне: кто я одной фразой, что заметил, один вопрос. Без голосовых, без «Добрый день, меня зовут…» на три строки.
```

### 6. Серия из четырёх касаний

```
Первое письмо [кому] про [что] осталось без ответа. Напиши ещё три касания с интервалами 3, 5 и 7 дней. Каждое добавляет новое: кейс, полезный материал, прямой вопрос. Последнее закрывает переписку без обиды. Каждое до 60 слов.
```

### 7. Звонок: первые 20 секунд

```
Звоню [кому] в [тип компании] без предварительной договорённости. Напиши первые 20 секунд разговора: кто я, почему звоню именно им, просьба о 30 секундах. Дай 3 варианта и ответ на «мне некогда» и «пришлите на почту».
```

### 8. Обход секретаря

```
Нужно дойти до [должность] в [компания]. Трубку берёт секретарь. Дай 4 честных формулировки, которые повышают шанс соединения, и что отвечать на «по какому вопросу?» и «отправьте предложение на общую почту». Без обмана.
```

### 9. Персонализация по шаблону

```
Вот мой шаблон письма: [текст]. Вот список компаний с заметками: [таблица]. Для каждой напиши первую строку письма, которая показывает, что я смотрел именно их. Остальной шаблон не трогай. Если заметок мало — напиши «нужен повод».
```

### 10. Рекомендация от клиента

```
Клиент [кто] доволен результатом [что]. Напиши ему сообщение с просьбой порекомендовать меня: кому именно я полезен, что сказать, готовый текст для пересылки в три строки. Просьба — лёгкая, без чувства долга.
```

## Квалификация и выявление задачи

Понять, есть ли здесь сделка, прежде чем тратить на неё неделю.

### 11. Вопросы на первый созвон

```
Продаю [что] для [кто]. Составь план созвона на 30 минут: 2 вопроса о ситуации, 4 о проблеме и её цене, 2 о том, что уже пробовали, 2 о решении и сроках. К каждому — что я хочу услышать и тревожный сигнал.
```

### 12. Сколько стоит проблема

```
Клиент говорит: [как он описывает проблему]. Помоги перевести её в деньги. Какие 5 вопросов задать, чтобы клиент сам посчитал потери в месяц? Покажи пример расчёта на его словах, без моих допущений.
```

### 13. Кто принимает решение

```
Говорю с [должность] в [компания]. Составь 5 вопросов, которые выясняют, кто ещё участвует в решении, как у них согласуют покупки и что нужно каждому участнику. Вопросы не должны звучать как «а вы вообще что-то решаете?».
```

### 14. Вопросы про бюджет

```
Обсуждаем [что]. Дай 5 способов узнать бюджет без прямого «сколько у вас денег»: через диапазон, через прошлые покупки, через стоимость проблемы, через приоритет, через сроки. К каждому — формулировка.
```

### 15. Разбор созвона

```
Вот расшифровка или заметки созвона: [текст]. Вытащи: задачу клиента его словами, цену проблемы, сроки, кто решает, возражения прозвучавшие и непрозвучавшие, следующий шаг. Что из этого я не выяснил — отдельным списком.
```

### 16. Оценка сделки

```
Сделка: [описание, этап, сумма]. Оцени вероятность закрытия по признакам: названа ли проблема, есть ли срок, есть ли бюджет, есть ли доступ к решающему, есть ли следующий шаг с датой. Что сделать на этой неделе, чтобы поднять шанс.
```

### 17. Отказ неподходящему клиенту

```
Клиент [кто] хочет [что], но это не мой профиль, потому что [причина]. Напиши вежливый отказ до 70 слов: почему не возьмусь, кому стоит написать вместо меня, при каких условиях я буду полезен позже.
```

### 18. Резюме потребностей

```
После созвона с [кто] у меня заметки: [текст]. Напиши письмо «правильно ли я понял»: их ситуация, задача, критерии успеха, ограничения — их словами. В конце вопрос: что я упустил? До 130 слов.
```

### 19. Скрытые возражения

```
Клиент на созвоне был вежлив, но уклончив. Его фразы: [цитаты]. Какие 4 возражения могут за этим стоять? Для каждого — вопрос, который мягко его достаёт, и что ответить, если я угадал.
```

### 20. Признаки срочности

```
Клиент описал ситуацию так: [текст]. Есть ли у него причина решать сейчас? Найди в его словах события и даты, которые создают срок. Если их нет — какие 3 вопроса помогут ему самому увидеть цену ожидания.
```

## Предложение и презентация

КП, которое читают: их задача, решение по шагам, цена с логикой.

### 21. Структура КП

```
Клиент: [кто]. Задача: [что]. Собери коммерческое предложение на одну страницу: задача их словами, что изменится, решение в 3 этапах, что входит и что нет, срок, цена, что нужно от клиента, следующий шаг с датой.
```

### 22. Три варианта цены

```
Услуга: [что], базовая цена [сумма]. Спроектируй три пакета для КП: минимальный, рекомендуемый, расширенный. В каждом — что входит и какой результат. Разница между пакетами должна быть в ценности, а не в количестве часов.
```

### 23. Обоснование цены

```
Цена [сумма] за [что]. Клиент потеряет без решения: [оценка]. Напиши блок «Почему столько»: из чего складывается цена, с чем её сравнивать, когда вложение окупится. Только цифры, которые я дал, без придуманной статистики.
```

### 24. Презентация на 10 минут

```
Показываю решение [что] клиенту [кто]. Его главная задача: [что]. Составь план демонстрации: с чего начать, 3 сценария из его жизни, что не показывать, вопрос после каждого сценария, как перейти к следующему шагу.
```

### 25. Кейс под клиента

```
Мои кейсы: [краткие описания]. Потенциальный клиент: [кто, задача]. Выбери самый близкий кейс и перепиши его под этого клиента: что общего в ситуации, что сделали, какой результат. До 120 слов, без цифр, которых нет в описании.
```

### 26. Сопроводительное письмо к КП

```
Отправляю КП [кому] после созвона. Напиши письмо до 80 слов: что внутри, на что обратить внимание в первую очередь, когда я свяжусь, чтобы обсудить. Без «во вложении коммерческое предложение».
```

### 27. Ответы на вопросы до того, как их зададут

```
Моё предложение: [суть, цена, срок]. Какие 7 вопросов клиент задаст, прочитав его? Напиши блок «Частые вопросы» для последней страницы КП — коротко и по делу.
```

### 28. Сравнение с конкурентом

```
Клиент сравнивает меня с [конкурент], который предлагает [что и за сколько]. Составь честное сравнение по 5 параметрам, важным клиенту. Где конкурент сильнее — так и напиши. Вывод: кому подхожу я, кому он.
```

### 29. Пилот вместо большого контракта

```
Клиент [кто] сомневается в проекте на [сумма]. Предложи пилот: что делаем за 2–3 недели, какой измеримый результат, цена, как пилот засчитывается в основной проект. Формулировка для письма до 100 слов.
```

### 30. Проверка КП

```
Вот моё КП: [текст]. Проверь глазами клиента: понятно ли, что он получит; есть ли следующий шаг; что вызывает сомнение; что можно убрать. Верни список правок по важности и переписанный первый абзац.
```

## Возражения и переговоры

Возражение — это вопрос, на который вы ещё не ответили.

### 31. «Дорого»

```
Клиент сказал «дорого» про [что] за [сумма]. Его ситуация: [факты]. Дай 4 ответа: через цену бездействия, через сравнение с тем, что он делает сейчас, через уменьшение объёма, через уточняющий вопрос. Каждый до 3 предложений.
```

### 32. «Нам надо подумать»

```
После КП клиент сказал «надо подумать». Напиши 3 способа выяснить, над чем именно: вопрос о сомнении, вопрос о процессе решения, предложение помочь с внутренним согласованием. И сообщение-напоминание через 4 дня.
```

### 33. «У нас уже есть подрядчик»

```
Клиент работает с [конкурент / своей командой]. Напиши 3 ответа, которые не ругают подрядчика: про второй взгляд, про узкую задачу, про проверку на небольшом куске. И вопрос, который выясняет, всем ли он доволен.
```

### 34. «Пришлите на почту»

```
Собеседник хочет закончить разговор фразой «пришлите предложение». Дай 3 ответа, которые соглашаются, но получают один уточняющий ответ и договорённость о дате следующего разговора.
```

### 35. «Сейчас не время»

```
Клиент откладывает: «вернёмся к этому в следующем квартале». Напиши ответ, который выясняет, что изменится к тому времени, и предлагает маленький шаг сейчас. Плюс напоминание на согласованную дату.
```

### 36. Просят скидку

```
Клиент просит скидку [размер] на [что]. Дай 4 варианта ответа: обмен скидки на объём, на срок оплаты, на отзыв или кейс, и вежливый отказ с объяснением. Скидка без встречного условия — не вариант.
```

### 37. Меняют условия в последний момент

```
Перед подписанием клиент хочет [изменение]. Для меня это значит [последствия]. Напиши ответ: что я могу принять, что нет и почему, что предлагаю взамен. Тон спокойный, без уступок по умолчанию.
```

### 38. Сомнение в результате

```
Клиент спрашивает «а вдруг не сработает?» про [что]. Напиши ответ: от чего зависит результат, что я контролирую, что зависит от него, как мы узнаем на раннем этапе, что идём не туда. Без гарантий, которые я не могу дать.
```

### 39. Сравнение по цене

```
Клиент нашёл [что] дешевле на [разница]. Напиши ответ, который не оправдывается: 3 вопроса, чтобы сравнить состав предложения, и что именно входит у меня. Если после сравнения дешёвый вариант ему подходит — так и сказать.
```

### 40. План переговоров

```
Переговоры с [кто] о [что]. Моя цель: [что]. Минимум, на который соглашусь: [что]. Его интересы: [что]. Составь план: с чего начать, что предложить первым, чем могу уступить и что попросить взамен, когда встать и уйти.
```

## Закрытие и работа с клиентом

Довести до оплаты и сделать так, чтобы клиент вернулся и привёл других.

### 41. Следующий шаг с датой

```
Клиент согласен «в целом», но шаг не назначен. Напиши 3 формулировки, которые превращают «да, интересно» в конкретное действие с датой: подписание, оплата, первая встреча. Без давления и «давайте уже решим».
```

### 42. Письмо со счётом

```
Отправляю счёт на [сумма] за [что]. Напиши письмо до 70 слов: за что счёт, срок оплаты, что происходит сразу после оплаты, к кому обращаться по вопросам.
```

### 43. Старт работы

```
Клиент оплатил [что]. Напиши приветственное письмо: что происходит в первую неделю, что нужно от клиента и к какому числу, как мы общаемся, когда первый результат. До 150 слов.
```

### 44. Запрос отзыва

```
Проект [что] завершён, результат: [цифры]. Напиши сообщение с просьбой об отзыве и 4 вопроса-подсказки, по которым его легко написать: что было до, что сомневало, что получилось, кому порекомендовал бы.
```

### 45. Продление контракта

```
Контракт с [кто] заканчивается через [срок]. Результаты: [цифры]. Напиши письмо о продлении: что сделано, что предлагаю на следующий период, условия, срок ответа. Без «хотели бы уточнить ваши планы».
```

### 46. Дополнительная продажа

```
Клиент пользуется [что], видна следующая задача: [что]. Напиши сообщение до 80 слов: что я заметил в его данных, чем это грозит, что предлагаю, сколько стоит. Одно предложение, не каталог.
```

### 47. Возврат клиента

```
Клиент [кто] перестал покупать [срок] назад, причина неизвестна. Напиши 2 сообщения: первое — прямой вопрос, что пошло не так; второе, через неделю — что изменилось у нас. Без скидки в первом.
```

### 48. Ответ на жалобу

```
Клиент недоволен: [текст жалобы]. Что произошло на самом деле: [факты]. Напиши ответ: признать то, что правда, объяснить без оправданий, что делаем и к какому сроку, как убедимся, что не повторится.
```

### 49. Разбор недели продаж

```
Мои действия за неделю: [числа касаний, созвонов, КП, сделок]. Найди самое узкое место воронки. Дай 3 гипотезы, почему оно там, и по одному действию на следующую неделю для проверки каждой.
```

### 50. Личный скрипт из лучших фраз

```
Вот фразы, которые сработали у меня в разных сделках: [список]. Собери из них личный скрипт: открытие, вопросы, презентация, ответы на 3 частых возражения, закрытие. Сохрани мои формулировки, не приглаживай.
```
