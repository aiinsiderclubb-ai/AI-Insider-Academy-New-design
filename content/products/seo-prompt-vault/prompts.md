# SEO Prompt Vault

50 промптов. Текст в [квадратных скобках] замените своим.

## Семантика и структура сайта

Что люди ищут и какая страница должна на это отвечать.

### 1. Кластеры запросов

```
Тема: [ниша], регион: [где]. Собери 30 запросов и разложи по кластерам. У каждого кластера: общий интент, тип страницы, главный запрос, 4–5 дополнительных. Отметь кластеры, под которые нужна отдельная страница, а не раздел.
```

### 2. Интент запроса

```
Вот запросы: [список]. Для каждого определи интент — узнать, сравнить, купить, найти конкретное — и что человек хочет увидеть в первом экране. Запросы со смешанным интентом пометь отдельно и предложи, как их разделить.
```

### 3. Карта сайта под семантику

```
Бизнес: [что], услуги: [список], города: [список]. Спроектируй структуру сайта: разделы, страницы услуг, страницы под города, блог. Для каждой страницы — главный запрос и чем она отличается от соседних, чтобы не было каннибализации.
```

### 4. Длинный хвост

```
Главный запрос: [ключ]. Дай 25 длинных запросов вокруг него: с уточнением цены, срока, места, сравнения, проблемы. Сгруппируй по тому, на какой странице на них отвечать — на основной или в отдельной статье.
```

### 5. Вопросы аудитории

```
Тема: [тема], аудитория: [кто]. Собери 20 вопросов, которые люди задают до покупки, во время выбора и после. Сформулируй так, как их пишут в поиске. Отметь 5, на которые можно ответить в блоке FAQ, и 5 — на отдельную статью.
```

### 6. Каннибализация

```
Вот страницы сайта и их запросы: [таблица]. Найди пары страниц, которые соревнуются за один запрос. Для каждой пары: какую оставить основной, что сделать со второй — объединить, переписать под другой интент или поставить редирект.
```

### 7. Запросы под услугу и город

```
Услуга: [что], города: [список]. Составь шаблон семантики для страницы «услуга + город»: обязательные запросы, локальные уточнения, вопросы. Что на странице должно быть уникальным для города, чтобы это не был дубль.
```

### 8. Сезонность и приоритеты

```
Запросы: [список с частотностью, если есть]. Разложи по приоритету: что даёт заявки сейчас, что вырастет в сезон [когда], что работает на узнаваемость. Предложи порядок создания страниц на 3 месяца.
```

### 9. Анализ выдачи

```
По запросу [ключ] в топе такие страницы: [заголовки и краткие описания]. Что у них общего: формат, объём, блоки? Чего нет ни у кого? Составь требования к моей странице: что обязательно повторить, чем отличиться.
```

### 10. Минус-слова и мусорные запросы

```
Ниша: [что]. Вот список собранных запросов: [список]. Отфильтруй нерелевантные: не тот интент, не тот регион, запросы про бесплатное, про работу, про конкурентов. Объясни в одну строку, почему убираешь каждую группу.
```

## Статьи и контент

Сначала бриф, потом текст, потом редактура. Три отдельных шага.

### 11. Бриф статьи

```
Запрос: [ключ], интент: [какой]. Составь бриф: обещание заголовка, для кого статья, 6–8 подзаголовков с тезисами, факты, которые нужно проверить, примеры, которые нужны от эксперта, FAQ из 4 вопросов, куда ставим внутренние ссылки.
```

### 12. Заголовки H1 и title

```
Статья о: [тема], главный запрос: [ключ]. Дай 8 вариантов H1 и к каждому title до 60 знаков. Ключ ближе к началу, без «всё, что нужно знать» и «полное руководство», если это не руководство.
```

### 13. Вступление

```
Статья: [тема], читатель пришёл по запросу [ключ]. Напиши вступление до 80 слов: признать его ситуацию, сказать, что он получит из статьи, и сразу дать короткий ответ. Без истории вопроса и «в современном мире».
```

### 14. Раздел по тезисам

```
Подзаголовок: [текст]. Тезисы: [список]. Напиши раздел до 200 слов: по одному абзацу на тезис, с примером или цифрой. Не добавляй фактов от себя — где нужен факт, поставь метку [нужен источник].
```

### 15. Экспертность в тексте

```
Вот черновик статьи: [текст]. Найди места, где нужен опыт практика: пример из работы, оговорка, типичная ошибка, цифра из практики. Составь список вопросов к эксперту — по одному на каждое такое место.
```

### 16. Блок FAQ

```
Статья: [тема]. Напиши FAQ из 6 вопросов, которые остались без ответа в основном тексте. Ответы по 2–3 предложения, начинаются с сути. Формулировки вопросов — как в поиске.
```

### 17. Редактура воды

```
Вот текст: [текст]. Убери всё, что можно вычеркнуть без потери смысла: вводные слова, повторы, общие фразы. Сохрани структуру и ключевые запросы. Покажи, на сколько процентов сократил и что именно убрал.
```

### 18. Обновление старой статьи

```
Статья от [дата]: [текст]. Запрос: [ключ]. Что устарело, чего не хватает по сравнению с тем, что ищут сейчас, какие разделы добавить, какие сократить. Дай план обновления по шагам.
```

### 19. Статья-сравнение

```
Сравниваю [вариант А] и [вариант Б] для [задача]. Составь структуру: кому что подходит в одном абзаце, таблица по 6 параметрам, разбор по сценариям, честные минусы каждого. Вывод — по ситуациям, а не «выбирать вам».
```

### 20. Сниппет для блока ответа

```
Запрос-вопрос: [запрос]. Напиши ответ в 40–50 слов, который можно поставить в начало статьи: определение или прямой ответ, без вступления. И вариант списком из 5 шагов, если вопрос про «как».
```

## Страницы услуг и товаров

Страница, которая и находится, и продаёт.

### 21. Страница услуги

```
Услуга: [что], регион: [где], главный запрос: [ключ]. Составь структуру страницы: первый экран, для кого, что входит, как проходит работа, цена и от чего зависит, сроки, кейсы, FAQ, форма. Для каждого блока — что там написать.
```

### 22. Карточка товара

```
Товар: [название, характеристики], аудитория: [кто]. Напиши описание до 150 слов: для чего товар, главные свойства через пользу, кому не подойдёт, что в комплекте. Характеристики — отдельным списком.
```

### 23. Страница категории

```
Категория: [что], в ней [число] товаров. Напиши текст для страницы категории до 200 слов: как выбрать, чем отличаются подгруппы, ссылки на подкатегории. Текст помогает выбрать, а не перечисляет ключи.
```

### 24. Локальная страница

```
Услуга: [что], город: [город]. Что на странице должно быть действительно про этот город: адрес, районы, сроки выезда, местные примеры. Напиши структуру и текст первого экрана. Без «в городе N мы предлагаем».
```

### 25. Блок цен

```
Услуга: [что], цена зависит от: [факторы]. Напиши блок «Сколько стоит»: диапазон, что в него входит, 3 примера расчёта, что увеличивает цену. Честно, без «цена по запросу».
```

### 26. Отличия от конкурентов на странице

```
Мы: [факты о компании]. Конкуренты в выдаче обещают: [что]. Напиши блок «Почему мы» из 4 пунктов. В каждом — факт, который можно проверить. Без «опытная команда» и «индивидуальный подход».
```

### 27. Микроразметка

```
Страница: [тип — услуга, товар, статья, FAQ, организация]. Данные: [что есть]. Какие типы разметки Schema.org сюда подходят? Напиши JSON-LD с моими данными. Поля, для которых данных нет, не выдумывай — выпиши списком, что нужно добавить.
```

### 28. Alt-тексты изображений

```
Страница о: [тема]. Изображения: [описания]. Напиши alt для каждого до 100 знаков: что на картинке и зачем оно на этой странице. Без перечисления ключей и слова «изображение».
```

### 29. URL и хлебные крошки

```
Структура сайта: [разделы и страницы]. Предложи человекопонятные URL и цепочки хлебных крошек. Правила: латиница, дефисы, без дат и идентификаторов, вложенность не глубже трёх уровней.
```

### 30. Аудит страницы услуги

```
Вот текст страницы: [текст], запрос: [ключ]. Проверь: отвечает ли первый экран на запрос, есть ли цена и срок, хватает ли доказательств, что мешает оставить заявку. Дай 7 правок по убыванию влияния.
```

## Технический и локальный SEO

Проверки, которые можно сделать без программиста, и задачи, которые нужно ему поставить.

### 31. Чек-лист технического аудита

```
Сайт на [платформа], [число] страниц. Составь чек-лист технической проверки по разделам: индексация, скорость, мобильная версия, дубли, редиректы, структура. Для каждого пункта — как проверить бесплатно и что считать проблемой.
```

### 32. ТЗ программисту

```
Проблема: [описание из аудита]. Напиши задачу для разработчика: что не так, где это видно, какой результат нужен, как проверить, что исправлено. Без SEO-жаргона там, где можно сказать проще.
```

### 33. Robots.txt и sitemap

```
Сайт: [структура, что должно и не должно индексироваться]. Напиши robots.txt с комментариями к каждой директиве и перечисли, что должно попасть в sitemap. Отдельно — что нельзя закрывать ни в коем случае.
```

### 34. Редиректы при переезде

```
Старая структура: [URL]. Новая: [URL]. Составь карту редиректов 301. Страницы без пары пометь: объединить с какой, удалить или перенести контент. Что проверить в первую неделю после переезда.
```

### 35. Скорость загрузки

```
Отчёт о скорости показывает: [метрики и замечания]. Объясни простыми словами, что из этого влияет на пользователя. Разложи исправления на три группы: сделать сегодня, поручить разработчику, оставить как есть.
```

### 36. Профиль компании в картах

```
Бизнес: [что, адрес, часы, услуги]. Напиши описание для профиля в картах до 750 знаков, список услуг с короткими описаниями и 5 вопросов-ответов для раздела вопросов. Только факты из моих данных.
```

### 37. Ответы на отзывы

```
Отзывы о компании: [тексты]. Напиши ответ на каждый: на положительные — конкретно и без шаблона, на отрицательные — признать, что правда, объяснить, что сделали. До 60 слов каждый.
```

### 38. Локальные упоминания

```
Бизнес: [что] в [город]. Где компании такого типа стоит быть представленной: каталоги, карты, отраслевые сайты, местные медиа. Составь список типов площадок и единый блок данных для размещения.
```

### 39. Проблемы с индексацией

```
В отчёте поисковой консоли: [статусы и количество страниц]. Объясни каждый статус, какие из них нормальны, а какие нужно исправлять. Порядок действий — от самого влияющего.
```

### 40. Миграция домена или платформы

```
Переезжаем с [откуда] на [куда]. Составь план по дням: что сделать до, в день переезда, в первую неделю, в первый месяц. Что измерить до переезда, чтобы потом было с чем сравнить.
```

## Ссылки, аналитика и планирование

Что работает, а что нет — и что делать в следующем месяце.

### 41. План контента на квартал

```
Сайт: [ниша], цель: [заявки / трафик]. Составь план на 12 недель: 12 тем, для каждой главный запрос, интент, тип страницы, что она должна принести. Чередуй коммерческие и информационные.
```

### 42. Письмо о размещении

```
Хочу получить ссылку с [сайт] на мой материал [что]. Почему он им полезен: [причина]. Напиши письмо до 90 слов: что я заметил на их сайте, что предлагаю, чем это полезно их читателю. Без «предлагаю взаимовыгодное сотрудничество».
```

### 43. Идеи материалов, на которые ссылаются

```
Ниша: [что]. Предложи 8 форматов материалов, на которые другие сайты ссылаются сами: исследование, калькулятор, шаблон, подборка данных. Для каждого — тема под мою нишу и что нужно, чтобы его сделать.
```

### 44. Разбор отчёта за месяц

```
Данные: [трафик, позиции, заявки по страницам]. Что выросло, что упало, какие 3 страницы заслуживают внимания первыми и почему. Отдели изменения от сезонности. Вывод — в трёх предложениях для руководителя.
```

### 45. Страницы почти в топе

```
Вот страницы на позициях 6–20 по своим запросам: [список]. Для каждой предложи 3 улучшения, которые могут поднять её в топ-5: дописать раздел, поправить заголовок, добавить внутренние ссылки.
```

### 46. Внутренняя перелинковка

```
Страницы сайта: [список с темами]. Предложи схему внутренних ссылок: какая страница на какую ссылается и с каким текстом ссылки. Главные коммерческие страницы должны получать ссылки с информационных.
```

### 47. Отчёт для клиента

```
Работы за месяц: [список]. Результаты: [цифры]. Напиши отчёт для клиента-не-специалиста: что сделали, что изменилось в заявках и трафике, что планируем, что нужно от него. Без терминов без пояснения.
```

### 48. Прогноз трафика

```
Сейчас: [трафик, позиции]. План: [что делаем]. Дай осторожный прогноз на 3 и 6 месяцев по трём сценариям. Для каждого — от чего он зависит. Отдельно — чего прогноз не учитывает.
```

### 49. Анализ конкурента

```
Сайт конкурента: [описание структуры, тем, что видно снаружи]. Что он делает хорошо, какие темы закрыл, а какие пропустил. Найди 5 тем, где я могу сделать лучше, и объясни, чем именно.
```

### 50. Приоритеты при малом бюджете

```
Бюджет: [часы или деньги в месяц], сайт: [состояние]. Что делать в первую очередь, чтобы получить заявки, а не отчёты. Дай план на 3 месяца из 3 задач в месяц и то, от чего сознательно отказываемся.
```
