# Viral Hooks Database

База из 240 хуков для коротких видео — Reels, Shorts, TikTok — в 12 категориях. Это шаблоны первой фразы: подставляете свою тему, цифру и аудиторию.

## Файлы

- `hooks.md` — все 240 хуков по категориям, с пометкой, когда какую использовать
- `hooks.csv` — те же хуки таблицей: фильтруйте по категории, добавляйте свои колонки
- `how-to-use.md` — как выбирать, подставлять и тестировать хуки

## С чего начать

1. Прочитайте `how-to-use.md` — там таблица, какую категорию брать под какой материал.
2. Импортируйте `hooks.csv` в Google Таблицы или Notion и заполняйте колонки «моя версия» и «результат».
3. На каждый ролик пишите три варианта хука из разных категорий и выбирайте самый конкретный.

## Лицензия

Можно использовать в своей работе и в проектах для клиентов. Нельзя перепродавать или выкладывать набор целиком.
