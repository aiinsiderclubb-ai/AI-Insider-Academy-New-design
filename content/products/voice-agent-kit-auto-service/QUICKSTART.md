# Быстрый старт

Порядок запуска. На первый раз уходит день; с третьего клиента — два-три часа.

## 1. Бэкенд — 60 минут

По `docs/02-backend-n8n.md`:

1. Импортируйте три воркфлоу из `workflows/`.
2. Создайте учётные данные: секрет вебхука, Google Calendar, Telegram.
3. Заполните узел **Config**: часовой пояс, календарь, часы, услуги, специалисты. Образец — `data/config.example.json`.
4. Назначьте «Error Alert» воркфлоу для ошибок.
5. Включите воркфлоу.

Проверка: запросы 1 и 2 из `tests/tool-payloads.md`. Первый возвращает свободное время из вашего календаря, второй — отказ без секрета.

## 2. База знаний — 30 минут

Заполните `prompts/knowledge-base.md` по анкете `sales/discovery-questionnaire.md`. Пишите так, как это должно звучать.

## 3. Агент — 60 минут

Выберите одного провайдера и идите по его инструкции:

- `docs/03-setup-vapi.md`
- `docs/04-setup-retell.md`
- `docs/05-setup-elevenlabs.md`

Промпт — `prompts/system-prompt.ru.md` (или `.en.md`). Конфигурации — в `providers/`.

## 4. Номер — 30 минут

По `docs/06-telephony.md`. Для первого запуска проще всего купить номер у провайдера, а переадресацию с рабочего номера настроить после тестов.

## 5. Тесты — 90 минут

1. Запросы 3–9 из `tests/tool-payloads.md`.
2. 30 звонков из `tests/test-calls.md`. Результаты — в `tests/test-calls.csv`.
3. `tests/launch-scorecard.md`.

Не пропускайте тесты с пометкой **Б**.

## 6. Запуск

Начните с режима «только пропущенные звонки» или «нерабочее время». Первую неделю читайте каждую сводку — `docs/08-operations.md`.

## 7. Настройка

После 20 реальных звонков — первый круг правок по `docs/09-tuning.md`.

## Если что-то не работает

| Где застряли | Куда смотреть |
|---|---|
| Запрос к бэкенду возвращает ошибку | Последний запуск «Booking Tools» в n8n |
| Агент не вызывает инструмент | Раздел «Частые проблемы» в инструкции провайдера |
| Агент говорит не то | `docs/09-tuning.md`, таблица «Где что править» |
| Перенос и отмена не работают | Так и должно быть со звонка не с номера записи; `tools/tool-contract.md` |
