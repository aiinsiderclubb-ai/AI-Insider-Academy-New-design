# Бэкенд в n8n

Нужен n8n с доступом из интернета по https: облачный или свой сервер.

## 1. Импорт

1. Workflows → Import from File. Импортируйте три файла из `workflows/`:
   - `booking-tools.n8n.json`
   - `call-summary.n8n.json`
   - `error-alert.n8n.json`
2. После импорта узлы с учётными данными подсвечены: их нужно выбрать.

## 2. Учётные данные

Создайте в n8n три набора.

**Секрет вебхука** — тип Header Auth.
- Name: `X-Voice-Secret`
- Value: случайная строка от 32 знаков. Сгенерировать: `openssl rand -hex 32`.

Выберите его в узлах **Voice Tool Webhook** и **Call Ended Webhook**.

**Google Calendar** — тип Google Calendar OAuth2 API. Войдите под аккаунтом, которому доступен рабочий календарь. Выберите в узлах **Calendar Read** и **Calendar Write**.

Совет: заведите для автоматизации отдельный аккаунт Google и дайте ему доступ на изменение только к одному календарю записей. Тогда агент не увидит личные события сотрудников.

**Telegram** — тип Telegram API. Создайте бота через @BotFather, вставьте токен. Выберите в узлах **Notify Staff**, **Send Summary**, **Send Alert**.

Чтобы узнать chat id: добавьте бота в чат администраторов, напишите в чат любое сообщение и откройте `https://api.telegram.org/botТОКЕН/getUpdates` — в ответе будет `chat.id`. Для групп он начинается с минуса.

## 3. Узел Config

Откройте **Config** в «Booking Tools». Это единственное место, где задаются правила бизнеса. Образец с пояснениями — `data/config.example.json`.

| Поле | Что это |
|---|---|
| `timezone` | Часовой пояс бизнеса, например `Europe/Kyiv`. От него считается всё время |
| `locale` | Язык, на котором бэкенд произносит даты: `ru-RU`, `uk-UA`, `en-GB` |
| `calendar_id` | Идентификатор календаря записей. Виден в настройках календаря Google |
| `staff_chat_id` | Chat id администраторов в Telegram |
| `phone` | `country_code` и `national_prefix`: как превращать «050…» в «+38050…» |
| `hours` | Часы работы по дням недели; `null` — выходной |
| `closed_dates` | Отдельные закрытые даты: `["2026-12-25"]` |
| `slot_step_min` | Шаг сетки записи в минутах |
| `lead_time_min` | За сколько минут до начала ещё можно записаться |
| `buffer_min` | Перерыв между записями одного специалиста |
| `booking_window_days` | На сколько дней вперёд открыта запись |
| `offer_slots` | Сколько вариантов времени возвращать агенту |
| `cancel_min_hours` | Порог поздней отмены в часах |
| `late_cancel_note` | Что агент скажет при поздней отмене |
| `require_caller_match` | Разрешать перенос и отмену только с номера записи |
| `address` | Адрес, как его произносить |
| `services` | Услуги: `id`, `name`, `duration_min`, `price` и, если услугу делают не все, `staff` |
| `staff` | Специалисты: `id` и `name` |
| `detail_fields`, `required_details`, `detail_labels` | Дополнительные поля записи для этой ниши |
| `callback_promise` | Когда перезвонят: «в течение рабочего дня» |

Цены и адрес пишите словами, как их должен произнести агент: «от тридцати евро», «улица Примерная, дом один».

Тот же chat id впишите в узел **Config** воркфлоу «Call Summary» и в узел **Send Alert** воркфлоу «Error Alert».

## 4. Воркфлоу для ошибок

Откройте «Booking Tools» → Settings → Error Workflow → выберите «Error Alert». Повторите для «Call Summary». Без этого о сбое вы узнаете от клиента.

## 5. Включение

Включите (Publish / Active) все три воркфлоу. Адреса:

- инструменты: `https://ВАШ-N8N/webhook/voice-tools`
- сводка звонка: `https://ВАШ-N8N/webhook/voice-call-ended`

Используйте адрес Production URL, а не Test URL.

## 6. Проверка без телефона

Выполните запросы из `tests/tool-payloads.md`. Первый же запрос на свободное время должен вернуть варианты из вашего календаря. Запрос без секрета должен быть отклонён.

## Данные и журнал

В настройках воркфлоу уже стоит «не сохранять успешные запуски»: в них имена и телефоны клиентов. Ошибочные запуски сохраняются для разбора — ограничьте срок их хранения в настройках n8n.

## Что бэкенд не делает

- Не принимает оплату и не берёт предоплату.
- Не отправляет клиенту SMS с подтверждением. Напоминание можно включить в самом Google Календаре или добавить узлом после **Finish**.
- Не синхронизируется с отраслевыми системами записи. Если расписание ведётся в другой системе, замените два узла Calendar на её API: остальная логика не меняется, если ответ привести к виду списка событий Google.
