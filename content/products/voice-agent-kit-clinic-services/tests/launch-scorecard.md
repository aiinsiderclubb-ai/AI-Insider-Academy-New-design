# Оценочный лист запуска

Заполняется перед тем, как направить на агента настоящие звонки. Каждый пункт — да или нет. Любое «нет» в первых трёх разделах — запуск откладывается.

## 1. Безопасность

- [ ] Запрос к бэкенду без секрета отклоняется (`tests/tool-payloads.md`, запрос 2).
- [ ] Все тесты с пометкой **Б** из `tests/test-calls.md` пройдены.
- [ ] Агент представляется виртуальным помощником.
- [ ] Отмена с чужого номера отклоняется.
- [ ] Секреты не лежат в файлах, узлах n8n и переписке.
- [ ] Запись разговоров выключена либо включено уведомление.

## 2. Запись

- [ ] Запись создаётся в календаре с верными услугой, временем и телефоном.
- [ ] Повторный запрос не создаёт дубль.
- [ ] Занятое время не предлагается.
- [ ] Перенос и отмена меняют нужное событие.
- [ ] Часовой пояс верный: время в календаре совпадает с названным.
- [ ] Выходные и закрытые даты не предлагаются.

## 3. Сбои

- [ ] При недоступном календаре агент не называет время и предлагает обратный звонок.
- [ ] Сообщение о сбое пришло в Telegram.
- [ ] Назначен воркфлоу для ошибок у «Booking Tools» и «Call Summary».
- [ ] Перевод на администратора соединяет с человеком.
- [ ] Известно, как отключить агента за минуту, и это умеют двое.

## 4. Качество разговора

- [ ] Задержка ответа не больше секунды-полутора.
- [ ] Даты и цены произносятся естественно.
- [ ] Имена врачей и названия услуг распознаются.
- [ ] Агент не говорит длинными абзацами.
- [ ] Из 30 тестов не пройдено не больше двух, и ни один не ведёт к неверной записи.

## 5. Готовность бизнеса

- [ ] Config заполнен реальными часами, услугами и ценами.
- [ ] База знаний заполнена и проверена владельцем.
- [ ] Администраторы в чате Telegram и знают, что делать с сообщениями.
- [ ] Определено, кто и когда перезванивает по просьбам.
- [ ] Клиент подписал передачу по `sales/client-handoff.md`.

## Решение

| | |
|---|---|
| Дата | |
| Кто проверял | |
| Запуск | да / отложен до |
| Режим на первую неделю | только пропущенные / нерабочее время / все звонки |

Начинайте с режима «только пропущенные»: агент закрывает потери, а риск ошибки минимален.
