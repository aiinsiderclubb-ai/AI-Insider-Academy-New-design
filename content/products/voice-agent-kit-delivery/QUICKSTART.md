# Быстрый старт

Порядок запуска. На первый раз уходит день; с третьего клиента — три-четыре часа.

## 1. Таблица и бэкенд — 90 минут

По `docs/02-backend-n8n.md`:

1. Создайте таблицу заказов из `data/orders-template.csv` и решите, как туда попадают заказы.
2. Импортируйте четыре воркфлоу из `workflows/`.
3. Создайте учётные данные: секрет вебхука, Google Sheets, Telegram.
4. Заполните узел **Config**: таблица, города, дни и интервалы с вместимостью, за сколько до доставки изменения только через оператора. Образец — `data/config.example.json`.
5. Назначьте «Error Alert» воркфлоу для ошибок.
6. Включите «Order Tools», «Call Summary», «Error Alert».

Проверка: запросы 1 и 2 из `tests/tool-payloads.md`. Первый находит пример заказа, второй — отказ без секрета.

## 2. База знаний — 30 минут

Заполните `prompts/knowledge-base.md` по анкете `sales/discovery-questionnaire.md`: зона, интервалы, как работает курьер, оплата.

## 3. Агент — 60 минут

Выберите одного провайдера и идите по его инструкции:

- `docs/03-setup-vapi.md`
- `docs/04-setup-retell.md`
- `docs/05-setup-elevenlabs.md`

Промпт — `prompts/system-prompt.ru.md` (или `.en.md`). Конфигурации — в `providers/`. Для исходящих звонков задайте у провайдера переменные `order_id`, `customer_name`, `delivery`, `address` с пустыми значениями по умолчанию.

## 4. Номер — 30 минут

По `docs/06-telephony.md`.

## 5. Тесты — 90 минут

1. Запросы 3–12 из `tests/tool-payloads.md`.
2. 30 звонков из `tests/test-calls.md`. Результаты — в `tests/test-calls.csv`.
3. `tests/launch-scorecard.md`.

Не пропускайте тесты с пометкой **Б**.

## 6. Исходящие звонки — 30 минут

По `docs/10-outbound.md`: ключ провайдера, пробный звонок на свой номер, включение «Confirmation Calls».

## 7. Запуск

Начните с исходящих звонков на часть заказов или с входящих в нерабочее время операторов. Первую неделю читайте каждую сводку и колонку `history` — `docs/08-operations.md`.

## 8. Настройка

После 20 реальных звонков — первый круг правок по `docs/09-tuning.md`.

## Если что-то не работает

| Где застряли | Куда смотреть |
|---|---|
| Запрос к бэкенду возвращает ошибку | Последний запуск «Order Tools» в n8n |
| Агент не находит заказ | Номер в таблице и номер звонящего; `require_caller_match` в `tools/tool-contract.md` |
| Агент не вызывает инструмент | Раздел «Частые проблемы» в инструкции провайдера |
| Агент говорит не то | `docs/09-tuning.md`, таблица «Где что править» |
| Исходящие звонки не начинаются | Отчёт в Telegram и колонка `history`; `docs/10-outbound.md` |
