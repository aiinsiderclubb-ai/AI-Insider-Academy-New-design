# Проверка бэкенда

Логика воркфлоу «Order Tools» и «Confirmation Calls» проверена 18 автоматическими тестами на подменной Google Таблице. Затем оба воркфлоу запущены в n8n 2.48 с подменными таблицей, Telegram и API провайдера и приняли запросы в форматах Vapi, Retell и ElevenLabs.

Что это значит для вас: узлы Code можно не читать, но если вы их меняете — повторите проверки из `tool-payloads.md`.

Чего проверка не покрывает: работу с настоящей Google Таблицей под вашими учётными данными, настоящие исходящие звонки у Vapi и Retell и качество распознавания речи. Это проверяется запросами из `tool-payloads.md`, пробным звонком из `docs/10-outbound.md` и звонками из `test-calls.md`.

## Сценарии

1. Поиск возвращает только активные заказы звонящего: дату с интервалом словами, адрес целиком, можно ли ещё менять.
2. С другого номера не видно ничего, а заказ с чужим номером не находится и по номеру заказа.
3. Подтверждение пишется только после «да», один раз; номер заказа понимается с пробелами и в другом регистре.
4. Инструмента для изменения состава нет: такой запрос отклоняется без чтения таблицы, агенту — подсказка передать оператору.
5. Уточнения для курьера записываются, операторам уходит «Уточнение для курьера».
6. Новый адрес в зоне доставки записывается, прежняя квартира стирается; город вне зоны и город без улицы отклоняются.
7. Заказ у курьера: улицу не поменять, а домофон — можно; до интервала меньше `change_cutoff_hours` — только оператор; доставленный заказ не меняется.
8. Предлагаются только интервалы с местом, после порога и в дни доставки; в воскресенье — ближайшие следующие дни.
9. Перенос в заполненный интервал отклоняется с вариантами, прежний интервал сохраняется; перенос в свободный записывается и сообщается операторам.
10. Отказ таблицы и таблица без нужной колонки не превращаются в выдуманный результат; операторам — сообщение с причиной.
11. Просьба связаться уходит оператору с номером заказа, таблица не читается.
12. Исходящий звонок Retell (номер клиента в `to_number`) и формат ElevenLabs распознаются.
13. Для звонков выбираются только завтрашние неподтверждённые заказы с оставшимися попытками и без звонка сегодня.
14. Запрос к Vapi и к Retell собирается с номером клиента и переменными; вне часов звонков не звонит никому.
15. Попытка засчитывается только начатому звонку; время звонка и строка в `history` пишутся всем.

## Запуск в n8n

Проверено в n8n 2.48: поиск заказа; отказ чужому номеру; отказ на «изменить состав»; подтверждение в таблице; смена адреса с сообщением операторам; город вне зоны; заполненный интервал не предлагается и не принимается; перенос интервала через исходящий звонок Retell; отказ таблицы; «Confirmation Calls» выбрал завтрашний неподтверждённый заказ, отправил запрос к Vapi с номером клиента и записал попытку в таблицу.
