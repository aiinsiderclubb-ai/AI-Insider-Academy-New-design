# Оценочный лист запуска

Заполняется перед тем, как направить на агента настоящие звонки. Каждый пункт — да или нет. Любое «нет» в первых трёх разделах — запуск откладывается.

## 1. Безопасность

- [ ] Запрос к бэкенду без секрета отклоняется (`tests/tool-payloads.md`, запрос 2).
- [ ] Все тесты с пометкой **Б** из `tests/test-calls.md` пройдены.
- [ ] Агент представляется виртуальным помощником.
- [ ] С чужого номера заказ не находится.
- [ ] Запрос на изменение состава получает отказ (`tests/tool-payloads.md`, запрос 4).
- [ ] Секреты не лежат в файлах, узлах n8n и переписке.
- [ ] Запись разговоров выключена либо включено уведомление.

## 2. Заказы

- [ ] Заказы попадают в таблицу из вашей системы с верными телефоном, датой и интервалом.
- [ ] Выгрузка из вашей системы не затирает изменения агента.
- [ ] Подтверждение, адрес и интервал меняют нужную строку, в `history` — запись.
- [ ] Заполненный интервал не предлагается.
- [ ] Часовой пояс верный: «завтра» и интервалы совпадают с реальностью.
- [ ] Дни без доставки не предлагаются.

## 3. Сбои

- [ ] При недоступной таблице агент не называет данные заказа и предлагает оператора.
- [ ] Сообщение о сбое пришло в Telegram.
- [ ] Назначен воркфлоу для ошибок у «Order Tools», «Confirmation Calls» и «Call Summary».
- [ ] Пробный исходящий звонок на свой номер прошёл (`docs/10-outbound.md`).
- [ ] Перевод на оператора соединяет с человеком.
- [ ] Известно, как отключить агента за минуту, и это умеют двое.

## 4. Качество разговора

- [ ] Задержка ответа не больше секунды-полутора.
- [ ] Даты, интервалы и адреса произносятся естественно.
- [ ] Улицы, номера домов и квартир распознаются.
- [ ] Агент не говорит длинными абзацами.
- [ ] Из 30 тестов не пройдено не больше двух, и ни один не ведёт к неверному адресу или интервалу.

## 5. Готовность бизнеса

- [ ] Config заполнен реальными городами, днями, интервалами и их вместимостью.
- [ ] База знаний заполнена и проверена владельцем.
- [ ] Операторы в чате Telegram и знают, что делать с сообщениями «Было / Стало» и просьбами связаться.
- [ ] Определено, кто и когда перезванивает по просьбам, особенно об изменении состава до доставки.
- [ ] Клиентов предупреждают об исходящем звонке при оформлении.
- [ ] Клиент подписал передачу по `sales/client-handoff.md`.

## Решение

| | |
|---|---|
| Дата | |
| Кто проверял | |
| Запуск | да / отложен до |
| Режим на первую неделю | исходящие на часть заказов / входящие в нерабочее время / всё |

Начинайте с исходящих звонков на часть заказов: видно, как агент справляется, а оператор подстрахует.
