# Голосовой администратор агентства недвижимости

Набор для запуска голосового агента, который отвечает на звонки, записывает клиентов в Google Календарь, переносит и отменяет записи и передаёт администратору то, с чем не справляется. Работает с Vapi, Retell и ElevenLabs.

Для кого: для тех, кто внедряет таких агентов клиентам, и для владельцев, которые готовы настроить сами.

## Чем набор отличается от промпта с инструкцией

- **Бэкенд записи проверен.** Воркфлоу n8n прошёл 20 сценариев и запускался в n8n 2.42 с запросами в форматах всех трёх провайдеров. Описание — `tests/backend-scenarios.md`.
- **Агент не может выдумать свободное время.** Окна считает программа по календарю; дату из «завтра» и «в пятницу» тоже считает она.
- **Повтор запроса не создаёт вторую запись**, а отказ календаря не превращается в ложный ответ клиенту.
- **Чужую запись нельзя отменить:** перенос и отмена работают только с номера, на который она оформлена.
- **30 тестовых звонков** с ожидаемым поведением, из них отдельно отмечены тесты на безопасность.
- **Комплект для продажи:** аргументы, калькулятор окупаемости, цены, анкета, объём работ, лист передачи, отчёт.

## Что нужно, кроме набора

- Аккаунт у одного из провайдеров голоса: Vapi, Retell или ElevenLabs.
- n8n с адресом в интернете.
- Google Календарь для записей.
- Telegram-бот для уведомлений.
- Номер телефона или переадресация с действующего.

Услуги провайдеров оплачиваются отдельно и в набор не входят.

## Границы

- Это шаблоны и инструкции, а не готовый сервис: настраиваете вы.
- Поля конфигураций сверены с документацией провайдеров 2026-10-08; что именно сверено, а что нет — в `providers/README.md`. Провайдеры меняют API: перед запуском пройдите тесты.
- С настоящим Google Календарём под вашими учётными данными воркфлоу проверяете вы — запросами из `tests/tool-payloads.md`.
- Памятка по данным — не юридическая консультация.
- Материалы на русском; промпт есть и на английском, модули диалога — на русском, украинском и английском.

## Лицензия

Можно использовать в своей работе и внедрять клиентам, менять под себя. Нельзя перепродавать набор и выкладывать его в открытый доступ.
