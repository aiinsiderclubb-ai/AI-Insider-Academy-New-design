# Как это устроено

```
Клиент звонит
     │
Номер телефона ── провайдер голоса (Vapi, Retell или ElevenLabs)
                        │   распознаёт речь, ведёт диалог по промпту, говорит голосом
                        │
                        │  вызов инструмента: «найди свободное время»
                        ▼
                  n8n: Booking Tools ──────► Google Календарь
                        │                    читает события, создаёт и меняет записи
                        ├──► Telegram администратора: новая запись, перенос, отмена, просьба перезвонить
                        ▼
                  ответ агенту: варианты времени или результат

После звонка: провайдер ──► n8n: Call Summary ──► Telegram: сводка звонка
При сбое:     n8n: Error Alert ──► Telegram: что сломалось
```

## Три части

**1. Провайдер голоса.** Отвечает за разговор: слышит, понимает, говорит. Вы даёте ему промпт из `prompts/` и шесть инструментов из `providers/`.

**2. Бэкенд в n8n.** Отвечает за факты: какое время свободно, создана ли запись. Агент не знает расписания и не может «придумать» свободное окно — только спросить у бэкенда.

**3. Календарь.** Одно расписание на бизнес. Каждая запись — событие, в котором скрыто записаны телефон клиента, услуга и агент. Сотрудники продолжают пользоваться календарём как обычно.

## Почему так

- **Агент не называет время по памяти.** Свободные окна считает программа по календарю. Это убирает главную ошибку голосовых агентов — запись на занятое время.
- **Дату считает бэкенд.** Агент передаёт «tomorrow» или «fri», бэкенд возвращает дату и то, как её произнести. Модели ошибаются в днях недели; программа — нет.
- **Одно изменение за запрос.** Единственный узел, который что-то пишет в календарь, — Calendar Write. Его легко найти и проверить.
- **Повтор не создаёт дубль.** Провайдеры повторяют запрос при таймауте. Идентификатор записи выводится из звонка и времени, поэтому вторая запись не появится.
- **Сбой не превращается в ложь.** Если календарь не ответил, агент получает `tool_unavailable` и предлагает обратный звонок, а администратору приходит сообщение.
- **Чужую запись не отменить.** Перенос и отмена работают только с номера, на который оформлена запись.

## Как один календарь вмещает нескольких специалистов

В событии хранится `staff_id`. Время свободно для услуги, если свободен хотя бы один агент, который её выполняет. Событие, созданное вручную без `staff_id` — выходной, обучение, ремонт, — закрывает время для всех. Чтобы закрыть время одному человеку, проще всего создать запись через агента или добавить событию `staff_id` в расширенных свойствах; подробнее — в `docs/08-operations.md`.

## Что входит в набор

| Папка | Что внутри |
|---|---|
| `docs/` | Девять инструкций: от схемы до настройки по записям звонков |
| `prompts/` | Системный промпт на русском и английском, модули диалога на трёх языках, шаблон базы знаний |
| `providers/` | Конфигурации Vapi, Retell и ElevenLabs |
| `tools/` | Контракт и схемы шести инструментов |
| `workflows/` | Три воркфлоу n8n: инструменты записи, сводка звонка, оповещение об ошибках |
| `data/` | Пример настроек бизнеса: часы, услуги, специалисты |
| `tests/` | 30 тестовых звонков, сценарии проверки бэкенда, готовые запросы, оценочный лист запуска |
| `sales/` | Как продать это клиенту: аргументы, калькулятор, цены, анкета, объём работ, передача, отчёт |
| `samples/` | Примеры разговоров |
