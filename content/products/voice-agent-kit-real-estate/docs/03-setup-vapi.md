# Настройка Vapi

Перед началом: бэкенд из `docs/02-backend-n8n.md` включён и отвечает на запросы из `tests/tool-payloads.md`.

## 1. Учётные данные для вебхука

В панели Vapi создайте Custom Credential типа Bearer Token:

- имя заголовка — `X-Voice-Secret`;
- префикс Bearer — выключить;
- значение — тот же секрет, что в n8n.

Запишите идентификатор учётных данных.

## 2. Инструменты

В `providers/vapi-tools.json` — массив из шести объектов. Замените `REPLACE-N8N-HOST` и `REPLACE_WITH_VAPI_CREDENTIAL_ID` и создайте каждый инструмент отдельным запросом:

```bash
curl -X POST https://api.vapi.ai/tool \
  -H "Authorization: Bearer $VAPI_API_KEY" -H "Content-Type: application/json" \
  -d @one-tool.json
```

Ключ API держите в переменной окружения, не вставляйте в файлы. Из ответа на каждый запрос запишите `id`.

То же можно сделать в панели: Tools → Create Tool → Function, поля — из файла.

## 3. Ассистент

1. В `providers/vapi-assistant.json` замените все `REPLACE`: идентификаторы инструментов, модель, голос, распознавание, номер администратора, адрес n8n.
2. В `model.messages[0].content` вставьте текст из `prompts/system-prompt.ru.md` — всё, что ниже черты. Подставьте название, имя агента, язык и базу знаний.
3. Создайте ассистента запросом `POST https://api.vapi.ai/assistant` или в панели.

Если API отклонит поле `model`, `voice` или `transcriber` — создайте ассистента в панели, выберите модель и голос там, а из файла возьмите первое сообщение, промпт и инструменты.

## 4. Голос и распознавание

- Выберите голос, который естественно звучит на языке ваших клиентов; прослушайте на фразах с датами и ценами из `prompts/dialog-modules.md`.
- В распознавании укажите язык. Если клиенты говорят на двух языках — включите многоязычный режим у выбранного провайдера распознавания.

## 5. Номер

Phone Numbers → купите номер или подключите свой, назначьте ассистента. Подробнее — `docs/06-telephony.md`.

## 6. Проверка

Позвоните и пройдите первые пять тестов из `tests/test-calls.md`. Затем остальные.

## Частые проблемы

| Что видите | Причина |
|---|---|
| Агент говорит «не удалось получить результат» | Бэкенд ответил не кодом 200 или не в формате `results`. Проверьте запуск в n8n |
| Инструмент не вызывается | Не привязан к ассистенту: проверьте `model.toolIds` |
| Бэкенд отвечает 403 | Секрет не приложен. Убедитесь, что инструмент сохранён в Vapi, а не передан в запросе на звонок: в этом случае Vapi учётные данные не прикладывает |
| Агент называет время сам | Модель проигнорировала инструмент. Понизьте температуру, проверьте, что промпт вставлен целиком |
| Перенос и отмена отвечают `caller_mismatch` | Звонок не с номера записи — так и задумано. Для веб-звонков из панели номера нет вовсе |
