# Настройка Retell

Перед началом: бэкенд включён и отвечает на запросы из `tests/tool-payloads.md`.

## 1. Модель с промптом и инструментами

1. В `providers/retell-llm.json` замените все `REPLACE`: адрес n8n, секрет в `headers` каждого инструмента, модель, номер администратора, переменные.
2. В `general_prompt` вставьте текст из `prompts/system-prompt.ru.md` — всё, что ниже черты. Переменные в двойных фигурных скобках Retell подставит из `default_dynamic_variables`; базу знаний вставьте текстом.
3. Создайте модель запросом на создание Retell LLM с этим телом. Ключ API держите в переменной окружения. Запишите `llm_id` из ответа.

В панели то же: Create Agent → Single Prompt → вставить промпт → добавить Custom Function на каждый инструмент.

## 2. Агент

В `providers/retell-agent.json` впишите `llm_id`, голос и адрес n8n, создайте агента.

Что уже настроено в файле:

- `language: ru-RU` — смените на свой; для двух языков передайте массив языков;
- `data_storage_setting: everything_except_pii` и хранение 30 дней;
- завершение после 30 секунд тишины, звонок не дольше 10 минут;
- имена специалистов в `boosted_keywords`, чтобы их лучше распознавали.

## 3. Формат вызова инструмента

Retell отправляет `name`, `args` и `call`. Бэкенд берёт номер звонящего из `call.from_number`. Не включайте у инструментов режим «Payload: args only»: без объекта `call` бэкенд не узнает номер и откажет в переносе и отмене.

## 4. Подпись запроса

Кроме вашего заголовка `X-Voice-Secret` Retell добавляет `X-Retell-Signature`. Набор проверяет заголовок с секретом; этого достаточно. Дополнительно можно разрешить входящие запросы только с адреса Retell — он указан в их документации.

## 5. Повторы

У инструмента есть параметр числа повторов. Для `create_booking` повтор безопасен: вторая запись не создаётся. Больше одного повтора не ставьте — клиент ждёт на линии.

## 6. Номер и проверка

Phone Numbers → купите или подключите номер, назначьте агента. Пройдите `tests/test-calls.md`.

## Частые проблемы

| Что видите | Причина |
|---|---|
| Инструмент возвращает ошибку 403 | Не тот секрет в `headers` |
| Параметры не приходят | В схеме параметров нет `"type": "object"` на верхнем уровне — в файле набора он есть, не удаляйте |
| Агент молчит во время проверки | Включите `speak_during_execution` — в файле включено |
| `caller_mismatch` на тестовом веб-звонке | У веб-звонка нет номера; проверяйте с телефона |
