# Контракт инструментов

Шесть инструментов. Один адрес бэкенда для всех: `POST https://ВАШ-N8N/webhook/voice-tools`. Бэкенд сам понимает формат Vapi, Retell и ElevenLabs.

Схемы параметров — в `tools.schema.json`. Здесь — что каждый инструмент делает и что возвращает.

## Общие правила

- Каждый ответ содержит `ok` и поле `say` — подсказку агенту, что делать дальше.
- Ошибка — это `ok: false`, код в `error` и `say`. Агент не зачитывает коды клиенту.
- Запросы без секрета в заголовке отклоняются вебхуком до выполнения.
- За один запрос выполняется один инструмент.

## check_availability

Вход: `service_id`, `date`, необязательно `part_of_day`, `staff_id`.

`date` принимает `ГГГГ-ММ-ДД`, `today`, `tomorrow`, день недели (`mon`…`sun`) и `+N`. Модели ошибаются в датах, поэтому слово в дату превращает бэкенд.

```json
{"ok": true, "available": true, "today": "2026-10-12", "date": "2026-10-13",
 "service": "…", "price": "…", "duration_min": 60,
 "slots": [{"slot_start": "2026-10-13T09:00", "spoken": "вторник, 13 октября в 09:00",
            "staff_id": "…", "staff": "…"}],
 "say": "Предложите клиенту эти варианты, не больше двух за раз…"}
```

Если на дату мест нет: `available: false` и в `slots` — ближайшие варианты в течение недели.

Как считаются окна: часы работы по дню недели → минус закрытые даты → шаг сетки → не раньше, чем через `lead_time_min` от текущего момента → у услуги должен быть свободен хотя бы один подходящий агент. Событие в календаре без отметки о специалисте (выходной, ремонт) закрывает время для всех.

## create_booking

Вход: `service_id`, `slot_start`, `customer_name`, `customer_phone`, `consent: true`, `deal_type`; необязательно `staff_id`, `notes`, `listing_ref`, `area`, `budget`.

```json
{"ok": true, "booking_id": "b5e1cfbd5c2d835f9", "service": "…", "price": "…",
 "slot_start": "2026-10-13T09:00", "spoken": "вторник, 13 октября в 09:00", "staff": "…",
 "say": "Запись создана. Подтвердите клиенту услугу, дату и время…"}
```

- Без `consent: true` возвращает `no_consent`.
- Перед записью время проверяется заново. Если его заняли — `slot_taken` и новые варианты в `slots`.
- Повторный запрос из того же звонка на то же время не создаёт вторую запись: идентификатор события выводится из звонка, времени и услуги.
- Телефон приводится к международному виду по правилам из Config (`phone`).

## find_booking

Вход: `customer_phone`. Возвращает до пяти предстоящих записей этого номера: `booking_id`, услуга, время.

## reschedule_booking

Вход: `booking_id`, `customer_phone`, `new_slot_start`. Запись переносится, только если принадлежит этому номеру и новое время свободно. Иначе прежняя запись остаётся, в ответе — варианты.

## cancel_booking

Вход: `booking_id`, `customer_phone`, необязательно `reason`. Событие помечается отменённым. Если до визита меньше `cancel_min_hours`, в ответе `late_cancellation: true` и напоминание о правилах.

## request_callback

Вход: `customer_name`, `customer_phone`, `topic`, необязательно `urgency`, `details`. В календарь не обращается: отправляет администратору сообщение в Telegram.

## Защита чужих записей

При `require_caller_match: true` перенос и отмена выполняются, только если запись оформлена на номер, с которого звонят. Номер звонящего бэкенд берёт из данных провайдера, а не со слов. Если провайдер номер не передал, агент получит `caller_mismatch` и предложит обратный звонок.

## Коды ошибок

| Код | Что значит | Что делает агент |
|---|---|---|
| `missing_fields`, `missing_details` | Не хватает данных | Уточняет у клиента и повторяет |
| `no_consent` | Нет подтверждения | Повторяет детали, ждёт «да» |
| `bad_phone` | Номер не распознан | Просит продиктовать по цифрам |
| `bad_date`, `date_in_past`, `too_far` | Проблема с датой | Уточняет дату |
| `unknown_service`, `unknown_staff` | Нет в каталоге | Выбирает из списка в ответе |
| `slot_taken`, `outside_hours`, `too_soon`, `off_grid` | Время недоступно | Предлагает `slots` |
| `booking_not_found` | Записи нет на этот номер | Вызывает `find_booking` |
| `caller_mismatch` | Звонят с другого номера | Предлагает обратный звонок |
| `tool_unavailable` | Календарь не ответил | Извиняется, не называет результат, обратный звонок или перевод |

## Форматы провайдеров

**Vapi** присылает `message.type: "tool-calls"` со списком `toolCallList`; бэкенд отвечает `{"results": [{"toolCallId": "…", "result": "…"}]}`, где `result` — строка с JSON. Код ответа всегда 200.

**Retell** присылает `{"name": "…", "args": {…}, "call": {…}}`; бэкенд отвечает объектом JSON.

**ElevenLabs** присылает тело из параметров инструмента; имя инструмента передаётся в адресе: `…/webhook/voice-tools?tool=check_availability`. Ответ — объект JSON.
