# Бэкенд в n8n

Нужен n8n с доступом из интернета по https: облачный или свой сервер.

## 1. Импорт

1. Workflows → Import from File. Импортируйте три файла из `workflows/`:
   - `booking-tools.n8n.json`
   - `call-summary.n8n.json`
   - `error-alert.n8n.json`
2. После импорта узлы с учётными данными подсвечены: их нужно выбрать.

## 2. Учётные данные

Создайте в n8n три набора.

**Секрет вебхука** — тип Header Auth.
- Name: `X-Voice-Secret`
- Value: случайная строка от 32 знаков. Сгенерировать: `openssl rand -hex 32`.

Выберите его в узлах **Voice Tool Webhook** и **Call Ended Webhook**.

**Google Calendar** — тип Google Calendar OAuth2 API. Войдите под аккаунтом, которому доступен календарь броней. Выберите в узлах **Calendar Read** и **Calendar Write**.

Совет: заведите для автоматизации отдельный аккаунт Google и дайте ему доступ на изменение только к одному календарю броней. Тогда агент не увидит личные события сотрудников.

**Telegram** — тип Telegram API. Создайте бота через @BotFather, вставьте токен. Выберите в узлах **Notify Staff**, **Send Summary**, **Send Alert**.

Чтобы узнать chat id: добавьте бота в чат администраторов, напишите в чат любое сообщение и откройте `https://api.telegram.org/botТОКЕН/getUpdates` — в ответе будет `chat.id`. Для групп он начинается с минуса.

## 3. Узел Config

Откройте **Config** в «Booking Tools». Это единственное место, где задаются правила бизнеса. Образец с пояснениями — `data/config.example.json`.

| Поле | Что это |
|---|---|
| `timezone` | Часовой пояс ресторана, например `Europe/Kyiv`. От него считается всё время |
| `locale` | Язык, на котором бэкенд произносит даты: `ru-RU`, `uk-UA`, `en-GB` |
| `calendar_id` | Идентификатор календаря броней. Виден в настройках календаря Google |
| `staff_chat_id` | Chat id администраторов в Telegram |
| `phone` | `country_code` и `national_prefix`: как превращать «050…» в «+38050…» |
| `hours` | Часы работы по дням недели; `close` — время, к которому стол должен освободиться. `null` — выходной |
| `closed_dates` | Отдельные закрытые даты: `["2026-12-31"]` |
| `slot_step_min` | Шаг, с которым предлагается время: 30 — в 19:00, 19:30, 20:00 |
| `lead_time_min` | За сколько минут до прихода ещё можно забронировать |
| `buffer_min` | Время на уборку стола между гостями |
| `booking_window_days` | На сколько дней вперёд открыта бронь |
| `offer_slots` | Сколько вариантов времени возвращать агенту |
| `cancel_min_hours` | Порог поздней отмены в часах |
| `late_cancel_note` | Что агент скажет при поздней отмене (например, о депозите) |
| `require_caller_match` | Разрешать перенос и отмену только с номера брони |
| `address` | Адрес, как его произносить |
| `max_guests` | Самая большая компания, которую агент бронирует сам. Больше — менеджеру |
| `durations` | Сколько держим стол: `{"max_guests": 2, "minutes": 90}` — для компаний до двух человек и так далее |
| `deposit_note` | Короткая фраза про депозит, если он есть: «без депозита» |
| `zones` | Зоны: `id` и `name` — «терраса», «основной зал» |
| `tables` | Столы: `id`, `name`, `seats` (мест), `zone`, необязательно `min_guests` — меньше этого числа гостей за стол не сажать |
| `detail_fields`, `detail_labels` | Что ещё записывать в бронь: повод, пожелания |
| `callback_promise` | Когда перезвонят: «в течение часа в рабочее время» |

Столы перечислите все, которые можно продавать по телефону. Стол, который держите для гостей с улицы или постоянных, в `tables` не вносите.

Адрес пишите словами, как его должен произнести агент: «улица Примерная, дом десять».

Тот же chat id впишите в узел **Config** воркфлоу «Call Summary» и в узел **Send Alert** воркфлоу «Error Alert».

## 4. Воркфлоу для ошибок

Откройте «Booking Tools» → Settings → Error Workflow → выберите «Error Alert». Повторите для «Call Summary». Без этого о сбое вы узнаете от клиента.

## 5. Включение

Включите (Publish / Active) все три воркфлоу. Адреса:

- инструменты: `https://ВАШ-N8N/webhook/voice-tools`
- сводка звонка: `https://ВАШ-N8N/webhook/voice-call-ended`

Используйте адрес Production URL, а не Test URL.

## 6. Проверка без телефона

Выполните запросы из `tests/tool-payloads.md`. Первый же запрос на свободный стол должен вернуть варианты из вашего календаря. Запрос без секрета должен быть отклонён.

## Данные и журнал

В настройках воркфлоу уже стоит «не сохранять успешные запуски»: в них имена и телефоны клиентов. Ошибочные запуски сохраняются для разбора — ограничьте срок их хранения в настройках n8n.

## Что бэкенд не делает

- Не отправляет гостю SMS с подтверждением. Напоминание можно включить в самом Google Календаре или добавить узлом после **Finish**.
- Не берёт депозит и не принимает предзаказ блюд.
- Не объединяет столы для больших компаний: такие брони — у менеджера.
- Не синхронизируется с системами бронирования ресторанов и кассой. Если брони ведутся в другой системе, замените два узла Calendar на её API: остальная логика не меняется, если ответ привести к виду списка событий Google.
