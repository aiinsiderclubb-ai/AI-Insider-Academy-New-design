# Запуск за два часа

Самое долгое — Meta: подтверждение бизнеса и номера. Начните с него, остальное можно делать параллельно.

## 1. Meta и номер — 40 минут (плюс ожидание проверки)

По `docs/02-whatsapp-connection.md`: приложение в Meta for Developers, номер, постоянный токен системного пользователя, App Secret, Phone number ID.

## 2. Таблица — 15 минут

Создайте Google Таблицу с листами `Contacts` (пустой — заголовки бот напишет сам) и `Catalog`. В `Catalog` скопируйте `templates/catalog-starter.csv` и замените строки своими товарами и ценами. Чем точнее каталог, тем точнее ответы.

## 3. Telegram — 10 минут

1. Создайте бота у @BotFather. Если у вас уже есть бот, который принимает сообщения в другом воркфлоу n8n, создайте нового: у одного бота может быть только один вебхук.
2. Создайте чат менеджеров и добавьте туда бота.
3. Узнайте chat id чата (`docs/03-setup.md`).

## 4. Импорт и учётные данные — 20 минут

По `docs/03-setup.md`: импорт пяти воркфлоу, учётные данные Google Sheets, WhatsApp, App Secret, модель, Telegram.

## 5. Config — 20 минут

Заполните Config в «Bot»: таблица, Phone number ID, verify token, chat id, описание бизнеса, что предлагаете и какой следующий шаг для готового клиента. В остальных воркфлоу — короткий Config с теми же значениями.

## 6. Вебхук и проверка — 15 минут

1. Включите «Bot» и «Manager Replies».
2. В приложении Meta: WhatsApp → Configuration → Callback URL — Production URL узла **WhatsApp Webhook**, Verify token — значение `verify_token` из Config. Нажмите Verify and save, подпишитесь на поле `messages`.
3. Напишите на номер со своего телефона. Пройдите `tests/test-requests.md`.

## Дальше

- Первую неделю читайте переписки в листе `Contacts` (колонка `history`) и уточняйте каталог и `business` в Config.
- Отвечайте горячим клиентам быстро: смысл бота в том, что человек получает ответ, пока он ещё выбирает.
