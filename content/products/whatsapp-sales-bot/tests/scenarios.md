# Как проверены воркфлоу

## Логика узлов Code — 11 сценариев

1. Проверка вебхука Meta: верный токен — challenge, неверный — 403.
2. Неверная подпись, статусы доставки, чужой Phone number ID и старый повтор — пропускаются.
3. Первое сообщение: карточка с заголовками, ответ с кнопками, в запросе к модели каталог и запрет выполнять инструкции клиента.
4. Поля, названные клиентом, сохраняются; горячий клиент — одно сообщение менеджерам со строкой `WA:`; дальше бот молчит и пересылает.
5. «СТОП» отписывает, дальше тишина, «старт» возвращает.
6. Просьба позвать менеджера (с окончанием) и сбой модели — ответ клиенту и передача.
7. Нажатая кнопка и фото с подписью превращаются в текст.
8. Ответ менеджера из Telegram уходит в пределах 24 часов и не уходит позже; сообщения не из чата менеджеров игнорируются.
9. Кнопки «Беру» и «Вернуть боту» меняют, кто ведёт клиента.
10. Напоминание: одно, только тому, кто замолчал, не тому, кто написал последним, не вне рабочего времени.
11. Отчёт: число разговоров по стадиям и список горячих.

## Запуск в n8n 2.44

Воркфлоу импортированы в n8n и вызваны по HTTP запросами в формате Meta, подписанными HMAC-SHA256, — проверку подписи выполнял сам узел Crypto. Google Таблицы, модель, Graph API и Telegram заменены локальным сервером с теми же форматами запросов и ответов; триггер Telegram — вебхуком с тем же содержимым.

- Проверка вебхука GET → `777`; неверный токен → 403.
- Запрос с неверной подписью → 200 для Meta, ничего не отправлено и не записано.
- Первое сообщение → отметка о прочтении, ответ с двумя кнопками, строка в таблице.
- Бюджет и срок → ответ клиенту, карточка «Горячий клиент» в Telegram, поля в таблице, статус `manager`.
- Сообщение клиента у менеджера → бот молчит, сообщение в чат менеджеров.
- Ответ менеджера на карточку в Telegram → сообщение клиенту в WhatsApp, имя менеджера в таблице.
- «Вернуть боту» → статус `bot`, подтверждение в чате.
- Сообщение из чужого чата Telegram → ничего.
- «СТОП», затем вопрос → одно подтверждение отписки, дальше тишина.
- Сбой модели → резервный ответ и передача менеджерам.
- WhatsApp отказал в доставке → «не доставлено» в чате менеджеров.
- Таблица недоступна → сообщение клиента целиком в чате менеджеров.
- Follow-up → одно напоминание замолчавшему клиенту и отметка в таблице.
- Daily Report → отчёт с горячим клиентом.

## Что не проверялось

- Настоящие WhatsApp Business Platform, Telegram и Google Таблицы под вашими учётными данными — проверьте по `test-requests.md`.
- Качество ответов конкретной модели по вашему каталогу — неделя чтения переписок.
