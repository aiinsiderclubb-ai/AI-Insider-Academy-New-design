# Проверка после запуска

## 1. Вебхук

Откройте в браузере (подставьте свои адрес и токен):

```
https://ваш-n8n/webhook/whatsapp?hub.mode=subscribe&hub.verify_token=ВАШ_VERIFY_TOKEN&hub.challenge=12345
```

Должно показать `12345`. С неверным токеном — `forbidden`.

## 2. Подпись без Meta

`tests/send-test-message.sh` отправляет сообщение в формате Meta и подписывает его App Secret. Секрет передаётся через переменную окружения, а не аргументом. Текст сообщения — без кавычек.

```
APP_SECRET=ваш_app_secret ./tests/send-test-message.sh https://ваш-n8n/webhook/whatsapp 380501112233 "Сколько стоит" ВАШ_PHONE_NUMBER_ID
```

Ответ `HTTP 200`, в листе `Contacts` появилась строка. Ответ бота уйдёт на номер из второго аргумента — укажите свой.

## 3. Живой разговор

С личного телефона напишите на номер бота:

| Напишите | Что должно произойти |
|---|---|
| Здравствуйте, сколько стоит …? | Ответ по каталогу, вопрос, возможно кнопки |
| Нажмите кнопку | Бот понял ответ |
| Расскажите бюджет и срок, согласитесь на следующий шаг | Карточка «Горячий клиент» в Telegram с кнопками |
| Ещё одно сообщение | Бот молчит, сообщение пришло в чат менеджеров |
| В Telegram ответьте на карточку | Ответ пришёл вам в WhatsApp |
| В Telegram нажмите «Вернуть боту», напишите снова | Бот отвечает |
| Дайте менеджера | «Передаю менеджеру» + сообщение в чат |
| стоп | Подтверждение отписки, дальше тишина |
| старт | Бот снова на связи |

## 4. Сбой

Временно впишите неверный `spreadsheet_id` и напишите боту. В чат менеджеров должно прийти «Таблица недоступна — бот не ответил» с текстом сообщения. Верните значение.
