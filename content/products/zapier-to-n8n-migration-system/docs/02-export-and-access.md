# Экспорт и доступы

Интерфейсы Zapier и Make меняются — названия пунктов меню ниже на момент выпуска набора.

## Make

1. Откройте сценарий → меню «…» внизу редактора → **Export Blueprint**. Получите `.json`.
2. Повторите для каждого сценария, сложите в одну папку `make/`.
3. Попросите у клиента: список Data stores с примерами данных, расписание каждого сценария (blueprint хранит не всё), список подключений (Connections).

Инструмент читает blueprint целиком, включая ветки Router.

## Zapier

Варианты по убыванию полноты:

1. **Экспорт данных zap'ов** (Settings → Data management / Export, доступность зависит от тарифа). Получите JSON — инструмент читает `zaps[]` со шагами `nodes` или `steps` и полями `selected_api`, `action`. Формат экспорта Zapier меняется: если инструмент сообщит «формат не распознан», переходите к варианту 3.
2. **Доступ к аккаунту клиента** как участнику команды — откроете каждый zap и заполните опись.
3. **Опись на созвоне** — `templates/inventory-template.csv`: название, платформа, триггер, шаги через `;`, запусков в месяц. 30–60 минут с клиентом на 20 zap'ов.

Заодно попросите: страницу Usage (задачи в месяц по zap'ам), список подключённых приложений (My Apps), содержимое Zapier Tables и Storage, если используются.

## Опись вручную

```csv
name,platform,trigger,steps,runs_per_month,status,notes
Оплата Stripe → счёт,Zapier,Stripe: new charge,QuickBooks: create invoice; Gmail: send email,420,on,
```

`trigger` и `steps` — в формате `Сервис: действие`. Инструмент узнаёт сервис по названию: «Google Sheets», «Gmail», «Formatter», «Paths», «Webhooks»…

## Доступы

`templates/client-access-checklist.md` — для клиента. Правила:

- Учётные данные создаёт клиент или они создаются на его аккаунты. Пароли — только через менеджер паролей или напрямую в n8n, не в мессенджере.
- Для Google — отдельный аккаунт автоматизации с доступом к нужным таблицам и папкам.
- Для API-ключей — отдельный ключ «n8n», чтобы потом отозвать его, не трогая остальное.
- Адреса вебхуков: составьте список всех мест, куда сейчас прописан адрес Zapier/Make (формы, платёжные системы, CRM) — их придётся переключить.
